# uHand とガイスターの駒の 1 枚（生成画像の構図を実モデルで描き直す）

参照は AI の生成画像（黒いロボットハンドが斜め上から見え、親指と人差し指で白いおばけの駒に触れている）。
同じ構図を、`models/hiwonder-uhand`（実寸・サーボ 6 量）と `exports/geister-ghost/ghost_blue.glb`（実寸）で描く。

## 手順

```bash
B="C:/Program Files/Blender Foundation/Blender 5.1/blender.exe"
D=<作業用のフォルダ>
py -3.11 tools/uhand_geister_shot/ref_masks.py --ref <参照 1920x1200> --crop 0,0,960,560 --out $D    # 参照を 960x560 に切るとき
"$B" --background --python tools/uhand_geister_shot/posesearch.py -- --out $D/scene.json             # 手の姿勢と駒の位置（約 5 分）
"$B" --background --python tools/uhand_geister_shot/camsearch.py -- --scene $D/scene.json \
    --ref-hand $D/ref_hand.npy --ref-ghost $D/ref_ghost.npy --out $D/cams.json --work $D/cs --el 35,40,45,50,55
"$B" --background --python tools/uhand_geister_shot/shot.py -- --cams $D/cams.json --out $D/final/shot.png \
    --sil $D/final/sil.png --size 1920x1120 --samples 256 --lift 1.0 --bg 0.48 --world 0.3 --light 0.25 --spec 0.3 \
    --view AgX --look "AgX - Punchy"
py -3.11 tools/uhand_geister_shot/compare.py --ref $D/ref.png --ref-hand $D/ref_hand.npy --ref-ghost $D/ref_ghost.npy \
    --shot $D/final/shot.png --sil $D/final/sil.png --out $D/final
```

- `scene.py` 場面の部品（手の向き・駒の高さごとの半径・隙間・駒の見え）。Blender の中で import する
- `posesearch.py` 手の姿勢と傾きを格子で探す。駒は親指の先と人差し指の先の両方に接する位置へ解く
- `camsearch.py` 場面を固定し、カメラの仰角と方位を格子で探す。距離とレンズのシフトは、手の頂点を投影した外接枠が参照の枠に合うよう詰める
- `shot.py` Cycles で描く。面どうしの当たり判定で接触と食い込みを印字する
- `compare.py` 左右反転して参照と並べ、シルエットの IoU を出す

参照は左手、模型は右手。右手で描いて最後に反転する（反転した絵は左手の uHand に見える）。

## 目標の決め方（2026-11-26）

最初は参照の点（関節・指先・板の四隅・駒）やシルエットに、姿勢・手の向き・カメラを全部まとめて合わせた。
数値は合っても絵が別物になり、2 回続けて行き詰まった。

- **生成画像の手は比率が実物と違う。** 手首の板と指の付け根のあいだに長いサーボの区画があり、手のひらが約 2 倍長い。
  指も駒に対して約 1.5 倍長い。合わせ切れないぶんを、最適化はカメラを寄せて手を立てることで吸収してしまう
- そこで、比率に依らない記述を目標にした。甲が見える。親指の側がカメラに近い。駒が手の外、親指の先と人差し指の先のあいだに立ち、
  斜め上から 9 割以上見える。そのうえで、場面（姿勢）を先に固定し、カメラだけを探す
- 「駒が見える」は加点ではなく硬い条件にする。加点だと、駒が手のひらの下に隠れた解が選ばれる
- 外接枠は描画から測らない。画面からはみ出した部分が測れず、枠合わせが狂う。頂点を投影して測る

2026-11-26 の結果: 人差し指 0.70、中指 0.5、薬指 0.3、小指 0.1、親指 1.0、pitch -10、roll 20。
カメラは仰角 35・方位 180。手の IoU 0.551、駒は 98% 見える。駒の画面上の高さは参照の約 1.45 倍（実寸のまま）。

- 中指以下は外ほど浅く曲げ、小指へ向かって開いていく弧にする（`--fix index=0.7,step=0.2,thumb=1,pitch=-10,roll=20`）。
  最初は 0.05 刻みにしていて、4 本がほぼ同じ曲がりに見えた（2026-11-26 に指摘を受けた）。0.10 / 0.15 / 0.20 を並べて 0.20 を選んだ
- 2026-11-26 の v3: 小指を伸ばし切って甲の側へ少し反らせ、人差し指から小指までを直線で補間した
  （`--fix index=0.7,thumb=1,pitch=-10,roll=20,little=-0.15`。中指 0.42・薬指 0.13・小指 -0.15）。
  カメラは同じく仰角 35・方位 180。手の IoU 0.523、駒は 100% 見える。親指と人差し指の隙間は 0.3mm
  - 反りには 0 より小さい量が要る。`scene.py` がこの道具の中だけ指の下限を -0.3 に広げる（連結は -0.4 まで解ける）。
    実物のサーボの可動域（0〜1）の外なので、実機ではこの姿勢を取れない可能性がある
  - 上から見る構図では反りが縮んで見える。-0.05 / -0.10 では読めず、-0.15 で指先が返るのが見えた
- 2026-11-26 の v4: 親指の付け根を少し後ろへ反らせ、先の関節を内へ深く曲げて、駒を下から抱える形にした。
  付け根 28°・先 75°（v3 は量 1.0 で 46°・38°）、人差し指 0.8 から小指 -0.15 まで補間
  （`--fix "index=0.6|0.7|0.8|0.9|1.0,thumb=1,pitch=-10,roll=20,little=-0.15,tprox=20|28|36,ttip=55|65|75"` の候補から目で選んだ）。
  親指と人差し指は駒に接し（隙間 0mm）、食い込みは無い。仰角 20・30・40、方位 140 の 3 枚を焼いた
  - 実物の親指は 1 つのサーボで付け根と先が連動し、先だけを深く曲げることはできない。`scene.py` が
    `thumb_prox_deg` / `thumb_tip_deg` を受け取ったときだけ、この道具の中で別々に曲げる
- 2026-11-26 の v5: 模型の親指を直した（`models/hiwonder-uhand`）。末節の尾が曲げると関節の後ろへ突き出していたので削り、
  関節を付け根側へ寄せて末節を延ばした（基節 48.1 → 36.0mm、末節 16.5 → 28.5mm）。姿勢は探し直して
  付け根 20°・先 55°・人差し指 0.8。親指と人差し指は駒に接し（隙間 0mm）、食い込みは無い
- 2026-11-26 の v7: 駒の上のほうをつまむ形にした。手を床から 10mm 持ち上げ（`lift`）、親指の付け根を 14° に戻して反らせ、
  人差し指 0.9 の第 2 関節を 10°・先の関節を 20° 緩めた（`ipip` / `idip`。この道具の中だけで、実物は 3 関節が連動する）。
  親指は高さ 15mm、人差し指は 45mm（駒の高さ 50mm）で接する。
  `--fix "index=0.8|0.9|1.0,thumb=1,pitch=-10,roll=20,little=-0.15,tprox=14,ttip=65,ipip=10,lift=6|10|14,idip=10|20|30" --thumb-z 12,32 --index-z 32,48`
- 2026-11-26 の v8: 人差し指の先の関節を 45° 緩めた（`idip=45`）。指先が駒に届かなくなるので人差し指を 1.0 へ上げた。
  親指は高さ 15mm、人差し指は 43mm で接する
- 2026-11-26 の v9: v7 の候補のうち先 30°（人差し指 0.9）を本人が選び、そこから先の関節だけをさらに 15° 開いた（`idip=45`）。
  ほかは変えない。親指は高さ 15mm、人差し指は 37mm で、どちらも隙間 0.6mm で接する
- 2026-11-26 の v10: 先の関節をさらに 15° 開いて 60° にした（`idip=60`）。人差し指 0.9 のままだと指先が駒から 2.15mm 離れるので
  0.94 へ深めた（0.92 で 0.94mm、0.94 で 0mm）。親指は高さ 15mm、人差し指は 41mm で接する
  - 手を持ち上げると駒が手より下へ出て、手だけで構図を合わせると駒の下が切れた。`camsearch.py --frame-all` で手と駒を合わせた枠を参照に合わせる
- 2026-11-26 の仕上げ: v10 の仰角 30・方位 140 を本人が採用。面光源を 2 倍に広げて影の縁を柔らかくし（`--light-size 2.0`）、
  明るさを `--light 0.32` に上げた。F8 の被写界深度でピントを駒のつまんでいる高さ（28mm）に合わせ、奥の指先だけ少しぼかした。
  `--zoom 0.82` で中心を保ったまま引き、手と駒のまわりに余白を取った。金属のねじの白い点は `sample_clamp_indirect = 5` で抑える。
  3840x2240・512 spp で焼いて左右反転した
  - F4 では指の大半がぼけて機構が読めなくなった。F8 なら駒と親指はくっきりしたまま、奥が少し引く
- uHand の指は付け根で横に開く関節が無い。参照の扇のような横の広がりは作れないので、曲げの段差で表す

## 明るさ

黒い材質の色を下げても手は明るいままだった。効いたのは表示変換（AgX の既定の look は暗部を持ち上げる）。
参照の背景 200・手の中央値 42 に対し、`AgX - Punchy` で背景 207・手 82（甲の板の上面が上からの光を受けるぶん高い）。
