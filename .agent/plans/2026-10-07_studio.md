# model-lab Studio（共同モデリング UI）設計書

2026-10-07。旧ビューワー `viewer/index.html` を置き換える新 UI。旧版は `/legacy` で残す（未コミットの他作業を含むので触らない）。

## ⚠ 改訂（design-critic 指摘を反映。本文と食い違うときはここが正）

1. 面の塗り広げは**種の面の法線との角**で止める（隣どうしの角だと滑らかな形で全体が選ばれる）
2. server は **127.0.0.1 だけで待ち受け**、POST と WS は Origin が `http://localhost:<port>` / `http://127.0.0.1:<port>` 以外を拒否。POST は `Content-Type: application/json` 必須。依頼で許す操作は models/<model>/ の編集とビルドに限る（スキルに書く）
3. STL の単位はファイルごとに推定（bbox 最大寸法 < 2 なら m とみなす）し、依頼に unitScale・bbox を残す。`print` `plate` `split` を名前に含む STL は配置版の可能性ありとして `placed:true`、UI で警告
4. **通知の正本はファイル**。WS の role=shubie は作らない。`tools/requests.py watch` が起動時に未対応分を先に出し、以後は requests/ をポーリングして新規・追記ごとに 1 行出す。待ち受け中は `requests/.listener.json` に `{agent, pid, at}` を 10 秒ごとに書く（心拍）。server は `/api/listener` と WS `listener` で在席を UI に渡す（at が 30 秒以内なら待ち受け中）
5. 着手時に `reply --status working --claim <agent>` で thread に claim を書き、二重着手を防ぐ（既に他が claim していたら警告して止まる）
6. 依頼に出どころを残す: gitHead、STL の sha1・mtime・size、params の実際の値（params.py の解析値＋ _overrides.json が STL より新しければその中身）。厚く・薄くは side（外・内・両側）、面の summary に今の肉厚（内向き raycast）
7. 幾何: STL は非 index のまま即表示。BVH は indirect。溶接と隣接は Worker で遅延構築。faceId = STL の三角形順
8. 座標変換は `frames.js` 1 か所＋数値テスト。キーは app.js が一括。undo は store に 1 本
9. **v1 で作らない**: 自動履歴 20 版（比較は依頼時の before.stl と今の版）、preview モジュールへの指示（STL 表示に切り替えてもらう）、2D の寸法道具
10. 依頼が届いたらシュビーは**すぐ着手する**（連携が目的なので）。requests/ は git に入れない（画像・STL を含む）
11. 担当は 4 体: A backend / B 3D（viewport・picking・section・frames・worker）/ C 2D sketch / D 殻

## 0. 目的

ユーザーがモデルを見ながら「ここをこうしたい」をシュビー（Claude Code）へ**座標つきで**伝え、シュビーが直して返す往復を 1 画面で回す。

- 3D で面を選んで「ここを 1.5mm 厚く」と指示する（Blender の面選択に近い操作）
- 任意の位置で断面を切り、2D で見る。その上に Figma のように線・曲線・図形を描いて「この線に沿って滑らかに」と指示する
- ピン（点にコメント）と寸法計測
- 指示をまとめて「シュビーに送る」。シュビーの返信と変更前後の比較が同じ画面に戻る

## 1. 全体構成

```
ブラウザ (viewer/studio/*)  ──HTTP──>  server.js  ──書く──>  requests/<model>/<id>/
          ^   WS(3001) 通知                │  WS(?role=shubie) 1 行テキスト
          │                                v
          └──────── exports/*.stl ──── Claude Code セッション（Monitor の ws で受信）
                                            └ tools/requests.py show / reply
```

- ビルドなし ES modules。three@0.170.0 と three-mesh-bvh を jsdelivr の importmap で読む（旧版と同じ方式）
- **座標の正本は「Blender ワールド mm（Z 上）」= STL の生の座標**。export_stl が ×1000 で書くので STL の値はそのまま Blender の mm になる。ビューワー内では STL を `modelRoot` グループ（rotation.x=-90°, scale=0.001, 位置オフセット）に生のまま入れ、ピック結果は `modelRoot.worldToLocal` で mm に戻す。指示 JSON の座標はすべてこの系
- preview モジュール（eye/horn/pixar-lamp/sg92r）は three の m・Y 上で組まれる。これらに付けた指示は `frame: "preview-m-yup"` と明記する。STL があれば STL 表示に切り替えられる

## 2. 画面

```
┌ topbar ─ [モデル名 ▾ (Ctrl+K)] [パーツ ▾] ─────────── [● 接続] [状態] [シュビーに送る (3)] ┐
├ rail ┬ 3D viewport ─────────────┬ 2D 断面エディタ（断面がある時だけ出る・幅可変）┬ inspector ┤
│ V 見る │ 右上: 視点ボタン         │ 上: V P L B R O A T D ／ 意図: 目標 削る 足す メモ │ [指示][パラメータ][履歴] │
│ F 面   │ 下: 操作ヒント 1 行       │ 下: 座標 mm・倍率・スナップ                     │                        │
│ P ピン │                          │                                                │                        │
│ M 測る │                          │                                                │                        │
│ S 断面 │                          │                                                │                        │
└──────┴──────────────────────────┴────────────────────────────────────────────────┴────────────────────────┘
```

- **見た目は新規に作る**（ユーザー指示 2026-10-07「既存のデザインに縛られずに」。旧ビューワーにもハウススタイルにも合わせない）。方向は「制作ツール」: 暗いグラファイトの作業面、1px の罫、角丸 6px、彩度の高いアクセント 1 色。トークンは `CONTRACT.md` §デザイン
- 指示の色は意図ごとに固定（`CONTRACT.md`）。選択中はアクセント色
- **操作ヒント行**が常に今のツールの使い方を出す（例「クリックで滑らかにつながった面を選ぶ。Shift で追加、Alt で外す。B でブラシ」）。直感性はここで担保する
- モデル選択はコマンドパレット（Ctrl+K）。検索・カテゴリ見出し・↑↓ Enter
- ショートカット: V/F/P/M/S（3D）。2D 側は V 選択 P ペン L 直線 B 曲線 R 四角 O 楕円 A 矢印 T 文字 D 寸法。Ctrl+Z / Ctrl+Shift+Z、Delete、Esc（ツール解除・選択解除）。テキスト入力中は無効

### 2.1 面を選ぶ（F）

- クリック: そのファセットから、隣接面との法線の角度差が閾値（既定 20°、ヒント行のスライダーで 5〜60°）以内の面を塗り広げる＝滑らかにつながった一枚を選ぶ
- B を押している間・ブラシ切替時: ドラッグで半径 r mm 内（`[` `]` で増減）かつ法線がこちらを向く面を塗る。曲面の一部だけを指したい時用
- Shift 追加 / Alt 除外。選択はマゼンタで重ね描き
- 選択がある間、選択の重心付近に**ポップオーバー**: 動作チップ「厚く 薄く 丸める 滑らかに 平らに 削る 足す 穴 その他」＋量（mm、±）＋メモ。Enter/「追加」で指示カードになり、3D 上の色はそのカードの色で残る

### 2.2 ピン（P）・測る（M）

- ピン: 面をクリック → 番号付きマーカー + メモ入力ポップオーバー
- 測る: 2 点クリック → 線と mm ラベル。Shift で軸に揃える（X/Y/Z のうち差が大きい軸）

### 2.3 断面（S）

- 面をクリック → その点を通る平面を作る。向きはヒント行のトグル「X / Y / Z / 視線」（Blender 軸。既定は視線に最も近い軸）
- 3D: 半透明の平面、断面の輪郭線（太線）、オプションで片側を隠す（clipping）
- 2D の基底は軸平面なら固定（X 面: u=Y, v=Z ／ Y 面: u=X, v=Z ／ Z 面: u=X, v=Y）。正面図・側面図・上面図と同じ向きに見える。視線平面は u=カメラ右, v=カメラ上
- 2D エディタの上部に「位置」mm 入力とスライダー（法線方向オフセット）。動かすと再スライス（ドラッグ中は間引き）
- 複数の断面を作れる。各断面が 1 枚の指示カードで、描いた図形はその断面に属する

### 2.4 2D 断面エディタ（Figma 風）

- SVG。単位は mm（u 右、v 上）。ホイールでズーム（カーソル中心）、Space+ドラッグ / 中ボタンでパン、`F` で全体表示
- 表示: 適応グリッド（1/5/10/50mm）、断面の材料部分を塗り（even-odd）＋輪郭線、比較版の輪郭（点線 --mute）、ユーザーの図形
- 道具: 選択（移動・点編集・Shift 複数）、ペン（手書き → 間引き → 滑らかな曲線に変換）、直線、曲線（Figma のペン: クリック=角、ドラッグ=ハンドル、始点クリックで閉じる、Enter/Esc で終了）、四角、楕円、矢印、文字、寸法（2 点、mm 自動表示）
- 輪郭へのスナップ（頂点・線上。Alt で一時解除）
- 意図: 図形ごとに 目標の線（この形にしたい）/ 削る（囲った範囲を除く）/ 足す（囲った範囲を盛る）/ メモ。色と線種で区別（削る・足すは斜線塗り）
- 選んだ図形にメモを書ける（右クリック or 選択時の小パネル）

### 2.5 インスペクタ

- **指示**: 下書きの指示カード一覧（色・種類・要約「面 120 枚 · 厚く +1.5mm」・メモ欄・削除・視点を合わせる）、全体メッセージ、送るボタン。その下に過去の依頼スレッド（状態バッジ 送信済み/対応中/完了/質問、シュビーの返信、追記入力、「変更前と重ねる」ボタン、閉じる）
- **パラメータ**: 旧版の機能そのまま（params.py のスライダー＋数値、既定に戻す、コピー、STL 生成、preview モジュール即時反映）
- **履歴**: その STL の過去版一覧（server が保存）。「重ねて比べる」で 3D は半透明ゴースト、2D は点線輪郭

下書きは localStorage にモデル単位で保存（再読込で消えない）。

## 3. データ

### 3.1 下書きの指示（store.draft.items）

```js
{ id, type: "faces"|"pin"|"measure"|"section", color, note: "",
  file,                       // どの STL に付けたか
  // faces
  action: "thicken"|"thin"|"round"|"smooth"|"flatten"|"cut"|"add"|"hole"|"other", amount: 1.5|null,
  faceIds: [...],             // ビューワー内だけで使う（送信時は落とす）
  summary: { faceCount, area, centroid:[x,y,z], normal:[x,y,z], bbox:{min,max}, samples:[[x,y,z,nx,ny,nz],...≤300] },
  // pin
  point:[x,y,z], normal:[x,y,z],
  // measure
  a:[x,y,z], b:[x,y,z], distance,
  // section
  plane: { axis:"x"|"y"|"z"|"view", origin:[x,y,z], normal:[x,y,z], u:[x,y,z], v:[x,y,z] }, offset: 0, clip: false,
  shapes: [ Shape ] }
```

### 3.2 Shape（2D、単位 mm、断面の (u,v)）

```js
{ id, kind: "pen"|"line"|"curve"|"rect"|"ellipse"|"arrow"|"text"|"dim",
  intent: "target"|"remove"|"add"|"note",
  nodes: [{ p:[u,v], in:[u,v]|null, out:[u,v]|null }],   // curve/pen はベジェ節点。line/arrow/dim は 2 節点。rect/ellipse は対角 2 節点
  closed: false, text: "", note: "" }
```

送信時に各 shape へ `polyline`（0.5mm 間隔の (u,v)）と `polyline3d`（Blender mm）を足す。シュビーは目標の線をそのまま幾何として使える。

### 3.3 依頼（requests/<model>/<id>/）

- `request.json`: `{ id, model, createdAt, frame: "blender-mm"|"preview-m-yup", message, stl:{file, mtime}, camera:{position,target,up,fov}（Blender mm）, items:[3.1 から faceIds を除いたもの、section には loops（2D 輪郭）・image・svg を付ける] }`
- `view.png`（3D のスクショ、指示の重ね描き込み）、`section-<n>.png` / `.svg`
- `before.stl`: 送信時点の STL のコピー（変更前との比較用）
- `thread.jsonl`: 追記専用。1 行 `{at, from:"user"|"shubie", kind:"message"|"status", text, status}`。最初の行は server が書く `{kind:"status", status:"open"}`。現在の状態は最後の status 行
- id は `YYYYMMDD-HHMMSS-<4hex>`

## 4. サーバー API（server.js に追加。既存 API は互換維持）

| | |
|---|---|
| `GET /` | studio。`GET /legacy` が旧 index.html |
| `GET /viewer/studio/*` | 静的 |
| `GET /api/params` | 既存＋ `viewer`（`models/<name>/viewer.json` があれば中身。カメラ・材質・smoothNormals） |
| `GET /api/stls` | `[{name, mtime, size}]` 新しい順 |
| `GET /api/history?file=` | `[{id, mtime, size, url}]`。server が exports/*.stl の変化を検知して `exports/.history/<file>/<id>.stl` へ保存（書き込み完了をサイズ安定で待つ。1 ファイル 20 版まで） |
| `POST /api/requests` | `{model, request, images:{name: dataURL or svg 文字列}}` → 保存・before.stl コピー・thread 初期化。`{id}` |
| `GET /api/requests?model=` | 一覧（request.json の要約＋thread 全体＋画像 URL） |
| `POST /api/requests/<id>/messages` | `{text}` → user の message 行を追記 |
| `POST /api/requests/<id>/status` | `{status}` → user の status 行（closed 等） |
| `GET /requests/...` | 画像の静的配信 |

WS（既存ポート）:
- 通常クライアント: 既存 `init`/`update` ＋ `{type:"history", file}` ＋ `{type:"requests", model, id}`（requests/ 配下の変化）
- `?role=shubie` クライアント: **1 行の日本語テキスト**だけを受け取る。新規依頼・ユーザー追記・ユーザーが閉じた時。例 `[新しい依頼] laptop-stand-ribbon 20261007-153000-ab12 「付け根を…」 指示 3 件 → py -3.11 tools/requests.py show 20261007-153000-ab12`。シュビー自身の返信では送らない
- 起動時に `.studio.json`（gitignore）へ `{http, ws, pid}` を書く。スキルがこれを読んで Monitor の URL を決める

## 5. シュビー側

- `tools/requests.py`: `list [--all]` / `show <id>`（人が読める要約。各指示の種類・意図・量・メモ、重心・法線・bbox、断面の平面と目標線の要約、画像の絶対パス、スレッド）/ `reply <id> "本文" [--status working|done|question]`。id は前方一致
- スキル `.claude/skills/studio/SKILL.md`: サーバー起動 → `.studio.json` を読む → `Monitor({ws:{url:"ws://localhost:<ws>/?role=shubie"}, timeout_ms: 最大})` で常駐（切れたら張り直す）→ 通知が来たら show → 画像を Read → 着手時に `reply --status working` → 修正・ビルド → `reply --status done` で何をどう変えたか（パラメータ名と値）を返す
- ビューワーは done を受けると通知し、「変更前と重ねる」で before.stl を比較表示する

### 5.1 自動で使われる仕掛け（Claude Code と Codex の両方）

- Claude Code: `.claude/skills/studio-inbox/SKILL.md`（description に発火語）＋ project hook `.claude/hooks/studio-inbox.js` を SessionStart と UserPromptSubmit に登録。未対応の依頼（最後の status が open / ユーザー追記に未返信）があれば件数と show コマンドを文脈に注入する。無ければ何も出さない
- Codex: `.agents/skills/studio-inbox/SKILL.md`（同内容。Monitor が無いので `tools/requests.py wait` で待つ）＋ AGENTS.md に一節
- `tools/requests.py wait [--timeout s]`: 新しい未対応依頼が来るまでブロックし、来たら 1 行出して終了。`watch` は来るたびに 1 行出し続ける（Monitor の command にも使える）
