# モデル一覧と Studio の改善

目的は増えたモデルを用途と関連するモデル群で探せるようにすること。既存のモデルIDと形状を維持する。

- 分類の正本は `models/catalog-groups.json`。用途と関連するモデル群は固定IDで参照する。
- モデルの表示情報は各 `catalog.json`。日本語名と説明を記録する。検索には英語IDとタグも使う。
- 保管済みの判定を名前から推測しない。今回は既存モデルを active とする。
- 読めない台帳は「未整理」で発見できるようにする。別形式で作成したモデルも存在を表示する。
- 一覧は検索と絞り込みで閲覧する。最近開いたモデルとお気に入りはブラウザに保存する。大量一覧は30件ずつ表示する。
- 追加時の分類と検証は `.agents/skills/model-catalog/SKILL.md` に残す。`node tools/catalog.js check` で継続検査する。
- 人が読む改善リストは `reports/2026-10-07-studio-review.html`。操作確認と実装修正を対応付ける。
