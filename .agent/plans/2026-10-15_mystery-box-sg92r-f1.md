# 住人の箱 F1・面ごとに機構を差し替えられる立方体

依頼（原文）:「住人の箱の思想を体現するために、複数の機構を面ごとに持つ１つの立方体のモデルを作ってほしい。なお、C1,C2やタンジブルUIなどを参考にして。なお、これは一個つくって終わりではなく、今後面を違う機構を思いついたときに変えるみたいなことも視野に入れておいてほしい」
「設計とかもAstraにうまく指示出ししてやらせて。」

## 進め方（Claude が決めたこと）

- 設計は Codex gpt-6-astra（xhigh）に 2 方針で並走させた。案 A「面ごとに SG92R を持つ自己完結カセット」、案 B「中心の 1 つの駆動から全部の面へ同じ形の出力」。B は最終回答を出す前に終了した
- 案 A を採用。理由: 今後の差し替えが依頼の条件で、A は面どうしが動力を共有しないので、新しい面が他の面と中心の出力規格に縛られない
- モデル名は住人の箱の系列に合わせて `mystery-box-sg92r-f1`（案 A 本文の `resident-cube-cassettes-a` はこれに読み替える）
- 実装は段階に分ける。段 1 で骨格・交換規格・合成・空の面・テンプレート・正面の蓋。段 2 で旗と 3 画素を別々の Astra に、各自の `faces/<名前>/` の中だけで作らせる（規格だけ読んで面が作れるかの実証を兼ねる）

## 設計（Astra 案 A の全文）

## A. 全体構成

**閉じた外形100 × 100 × 100mm。上面と4側面を交換可能なスロットにし、各可動カセットがSG92Rを1台ずつ持つ構成**にします。初版は3種類の可動面と2枚の空の面を入れます。底面は同じ取付方式の点検蓋です。

以下は設計案です。ファイルは変更していません。リンクの運動学と負荷の概算は計算しましたが、実形状の干渉検査、スライス、実物の適合確認は未実施です。

| スロット | 初版の面 | 動き |
|---|---|---|
| 上面 `top` | 3画素のせり出し | 各画素が面一から外へ0〜3mm |
| 正面 `front` | 小さな蓋 | 4節リンクで0〜60°開く |
| 右面 `right` | 起き上がる旗 | 歯車で0〜60°起こす |
| 背面 `back` | 空の面 | 可動部なし |
| 左面 `left` | 空の面 | 可動部なし |
| 底面 `bottom` | 空の面兼点検蓋 | 机に置く面。機構の搭載は禁止 |

100mmを選ぶ理由は、面の奥行きを37mm確保するためです。SG92R正本では本体底からホーン上端まで32mmあります。面法線方向に置くカム面では、残る5mmをホーン保持と前面の遮蔽に使います。

骨格は上枠と下枠、4本の柱から作ります。内側の配線案内も骨格に持たせます。**サーボ座、軸受け、可動部の抜け止めはすべてカセット側に置きます。** 骨格を外した状態でも、カセット単体で動作と角度合わせができる構造です。

中心には次の空間を残します。

- 中央の予約領域：24 × 24 × 44mm。将来の制御基板用です。内寸20 × 20 × 40mmの着脱トレーを入れられる形にします。
- 底面寄りの配線領域：56 × 40 × 8mm。サーボ線を面別に整理します。
- 初版の電源とPWM源は箱外の試験設備とします。マイコンや電池は部品表に含めません。予約領域への実際の収納可否は、基板と端子の寸法を得てから決めます。

外装は同色PLA、面板は2mm、荷重を受ける腕と軸受けは3mm以上とします。動作中にも、蓋の奥から見えるのは無地の内壁です。リンクと歯車は側面の遮蔽壁の裏に収めます。

100mmは閉状態の寸法です。初版を最大まで動かした概算外形は **122.8 × 124.5 × 103mm** です。将来の面にも、この区別を引き継ぎます。

## B. 面の交換規格

**取付規格だけでなく、動作範囲、配線、引き抜く経路まで規格に含めます。** 新しい面を入れるために、隣の面の寸法や初期角度を変更する設計は受け付けません。

**座標と取付**

各面の中心を原点とし、面内を `u, v`、箱の内側へ向かう深さを `d` とします。外面が `d=0mm` です。

| 項目 | 規格値 |
|---|---|
| 外から見える面板 | 92 × 92mm |
| 骨格の化粧開口 | 92.6 × 92.6mm。周囲の継ぎ目は片側0.3mm |
| 面板の厚さ | 2mm |
| カセットの挿入方向 | 面法線方向のみ。装着時の回転なし |
| 深さの基準 | `d=3mm` にある3個の座面 |
| 座面の中心 | `(u,v)=(-32,-32), (32,-32), (0,32)mm` |
| 座面の大きさ | 各6 × 6mm |
| 横方向の位置決め | Ø4mmの丸ピン1本と、幅4mmの平行二面ピン1本 |
| 受け側 | Ø4.4mmの穴と幅4.4mmの長穴。長穴は一方向の寸法差を逃がす |
| 向きの誤装着防止 | 2本の位置決めを非対称位置に置く。180°逆向きでは入らない |
| 抜け止め | 正面から操作する印刷キー2個 |
| 引き抜き距離 | 外側へ40mm以上。隣の面を外さない |

3個の座面で深さと傾きを決め、丸ピンと長穴で面内位置と回転を決めます。キーは座面へ押さえる役割に限定し、キーのしなりで位置を決めません。

キーの爪は2.4mm掛けます。弾性腕は自由長18mm、厚さ1.6mm、幅5mm、解除時の撓み0.6mmです。装着後は腕が戻り、常時曲げたまま保持しない形にします。

`表面ひずみ ε = 1.5 × 1.6 × 0.6 / 18² = 0.00444 = 0.44%`

キーの頭は12 × 8mmで外面と面一にします。頭の脇に指を掛けるくぼみを残します。電源が切れていても、可動面が途中で止まっていてもキーへ触れる配置です。

**使ってよい空間**

カセットは次の箱の集合の内側だけを使います。寸法にはサーボ本体、保持具、遮蔽壁、動く部品、カセット側の配線を含めます。

| 深さ `d` | 使用可能な面内寸法 `u × v` |
|---|---:|
| 0〜3mm | 92 × 92mm |
| 3〜11mm | 76 × 76mm |
| 11〜17mm | 64 × 64mm |
| 17〜24mm | 50 × 50mm |
| 24〜29mm | 40 × 40mm |
| 29〜34mm | 30 × 30mm |
| 34〜37mm | 24 × 24mm |

箱はすべて面中央に配置します。これは使える体積の上限です。内部を階段状の厚い壁で囲う指定ではありません。深部のSG92Rケースは中央空間へ露出してよく、外からの視線は前方の遮蔽壁で止めます。

各段は次の条件を満たします。

`面内半幅 + 最大深さ ≤ 49mm`

100mm立方体の半幅は50mmなので、隣接する2面の領域は対角の境界から各1mm退きます。公称の最短距離は次の値です。

`隣接領域間の距離 ≥ 2 / √2 = 1.414mm`

形状を片側0.25mm膨らませた製造誤差込みの包絡でも、この割当領域へ収まることを合格条件にします。運動の途中は、サンプル点の検査に加えて回転半径と角度刻みから移動上限を計算します。停止位置だけの確認にはしません。

外へ動く部分は、全姿勢で **76 × 76 × 32mm** の箱に収めます。範囲は `|u|,|v|≤38mm、-32≤d≤0mm` です。隣の面の外部動作域とは、立方体の角を挟んで離れます。

この内側包絡は奥ほど狭くなっています。そのため、カセットを面法線方向へ抜けば、箱内に残る部分はより広い許容領域へ移ります。**40mmの直線抜去を守る限り、交換の途中で隣のカセットへ近づく方向に膨らみません。**

**駆動と配線**

骨格とカセットの間に動力伝達軸は設けません。動力の界面は各カセット内部の「SG92R付属ホーン―印刷した受け」だけです。

- SG92Rとホーンは [正本のparams.py](C:/Users/kouga/Projects/Web/model-lab/models/sg92r-photo/params.py) をimportします。
- 耳の溝は実物成功値の片側0.25mm。耳厚2mmに対して溝幅2.5mmです。
- ホーン受けの初期隙間は片側0.25mm。長腕18mm側と16mm側を区別し、逆向きの装着を拒む形にします。
- 軸方向の遊びは合計0.5mm以下を設計目標とし、付属ホーンの嵌合長より十分小さくします。ねじと印刷スプラインは使いません。
- サーボの向きはカセットごとに選べます。骨格側へ軸位置の調整を要求しません。

配線は幅6mm、深さ3mmの開放溝へ置きます。柱の中を通す閉じた穴にはしません。前面を40mm引き出したときにつかめる位置へ、サーボ付属コネクタを置きます。自由に動かせる線を60mm確保し、固定側の配線を引っ張らずに外せる構成です。

コネクタの仮包絡は台帳の **8.2 × 4.4 × 14mm** を使います。置き場は14 × 8 × 18mmとし、開放状態で横から置きます。これは確定寸法ではありません。線の有効長も含めて試片で確認します。固定側の配線は面別の溝に分け、ある面の交換時に別の面の束をほどかない構造です。

**コードの規格**

モデルIDの案は `resident-cube-cassettes-a` です。構成は次の1ファイルで選びます。

```json
{
  "interface": "resident-face-v1",
  "slots": {
    "top":    {"module": "three_pixels", "rotation_deg": 0},
    "front":  {"module": "link_lid",     "rotation_deg": 0},
    "right":  {"module": "sector_flag",  "rotation_deg": 0},
    "back":   {"module": "blank",        "rotation_deg": 0},
    "left":   {"module": "blank",        "rotation_deg": 0},
    "bottom": {"module": "blank",        "rotation_deg": 0}
  }
}
```

新しい面を作る人は、`faces/template/` を複製して次を用意します。

| ファイル | 書く内容 |
|---|---|
| `module.json` | 規格版、対応スロット、部品ID、質量上限、使用する既製部品、要件、interfaces、allowances |
| `params.py` | 寸法、隙間、角度、ストローク。単位はm |
| `geometry.py` | 局所座標での形状と印刷姿勢 |
| `kinematics.py` | サーボ角から全部品の姿勢を返す純粋な計算 |
| `assembly.py` | 単体の組立経路、90°での組付け、閉状態への復帰、分解経路 |
| `trials.py` | 本体と同じ形状から切り出す試片 |
| `README.md` | 部品表、刷る向き、組立、初期角度、未確認事項 |
| `patterns.json` | カム面だけ。停止角と出力高さの表 |

共通の合成処理がスロットの配置変換を掛け、部品IDへ `front/` などの接頭辞を付けます。面の追加時に骨格や他面のコードを編集する必要はありません。

角度補正はカセット個体ごとに保存します。交換時に読み替えるのは交換した面の設定だけです。

## C. 初版で入れる面の機構

C1からは4節リンクとねじを使わない継ぎ手を引き継ぎます。C2からは可動面と固定面を分ける考え方を使います。**C2の試験サーボ寸法は採用しません。** 画素面はタンジブル画素キューブの「表からカムを作る」方式を引き継ぎ、側面でも戻るように拘束を追加します。

負荷の基準はSG92Rの4.8V時の停動トルク2.5kgf·cmです。[TowerProの製品仕様](https://towerpro.com.tw/product/sg92r-7/)

`許容値 = 2.5 × 9.80665 × 0.01 / 3 = 0.08172N·m`

以下の質量は設計上限です。実装時は中実PLAの体積重心と慣性で置き換えます。

| 面 | 印刷部品数 | 動き | 必要トルクの概算 |
|---|---:|---|---:|
| 正面・蓋 | 9点 | 0〜60° | 0.01053N·m |
| 上面・3画素 | 13点 | 各0〜3mm | 0.04116N·m |
| 右面・旗 | 9点 | 0〜60° | 0.00793N·m |
| 空の面 | 各3点 | なし | ― |

可動カセットの共通5点は、前枠、内側の遮蔽兼支持部、サーボ押さえ、骨格への固定キー2個です。

**正面：4節リンクで開く蓋**

可動面は36 × 30 × 2mmです。C1の全面蓋をそのまま縮小せず、小さな蓋の周囲に固定面を残します。

リンクの計算座標は `(v,d)`、回転軸は `u` 方向です。

- 蓋の回転中心 `H=(-12,3)mm`
- サーボの回転中心 `O=(-3,17.5)mm`
- クランク長 `a=12mm`
- 閉じた蓋のピン位置 `B-H=(12,3)mm`
- 閉じたクランク角 `α=34°`
- 連結リンク長 `L=19.4909mm`
- 蓋の回転範囲 `θ=0〜60°`

`L = |H + (12,3) − {O + 12(cos34°, sin34°)}| = 19.4909mm`

0.1°刻みの計算では、クランク角は34°から−34.6746°へ動きます。最小伝達角は **55.08°**、速度比 `|dθ/dα|` の最大は約1.00です。死点を通りません。

サーボ90°での組立姿勢は蓋27.4775°です。計算上の閉指令は124.337°、開指令は55.663°です。ホーンの山の刻みはソフトの補正で合わせます。

追加4点は蓋、ホーン受け兼クランク、リンク、蝶番ピンです。関節はØ5mmのピンとØ5.4mmの穴、軸方向の隙間0.3mmから始めます。

15g、重心距離20mm、効率0.65、摩擦予算0.005N·m、加速予算0.001N·mとして、

`τ ≤ 0.015 × 9.80665 × 0.020 × 1.00 / 0.65 + 0.005 + 0.001 = 0.01053N·m`

許容値の約13%です。蓋の最大突出量は次の値です。

`30sin60° + 3cos60° − 3 = 24.48mm`

蓋の奥には無地の浅い空間を作ります。リンクを置く側面には固定壁と蓋側の扇形の壁を重ね、全開時にも機構が見えないことを確認します。

**上面：3画素のせり出し**

14 × 14mmの画素を3個置きます。5×5から3個へ減らし、面を交換するための奥行きを確保します。

サーボ軸は面法線方向です。本体中心を面中央、出力軸を `u=+5mm`、本体底を `d=37mm` に置きます。正本寸法から、ホーン上端は `d=5mm` になります。

カムは外径53mmの円筒溝カムです。上側と下側の2部品で従動ピンを挟み、押し出しと引き戻しの両方を行います。重力に頼らないため、側面へ移設できます。

3個の従動子を120°ずつ離して配置します。サーボの使用範囲は60〜120°なので、それぞれが読む60°の区間は重なりません。

| サーボ角 | 画素1 | 画素2 | 画素3 |
|---|---:|---:|---:|
| 60° | 3mm | 0mm | 1.5mm |
| 90° | 0mm | 0mm | 0mm |
| 120° | 0mm | 3mm | 1.5mm |

各停止角の前後5°を一定高さにします。残る20°で五次曲線により接続します。高さ表を変更した場合はカム2部品を刷り直します。3画素を実行時に別々の高さへ指令する機構ではありません。

従動ピンはØ4mm、溝幅4.4mm、案内茎は4 × 4mmです。画素の裏に長さ8mmのスカートを付け、3mmせり出しても穴から内部が見えない形にします。

最大高さ差3mmに対する勾配は、

`|dh/dα|max = 1.875 × 3 / (20π/180) = 16.114mm/rad`

有効半径を25mmとして、圧力角の概算は、

`φmax = atan(16.114 / 25) = 32.8°`

1画素の移動抵抗を0.4N、合計1.2N、効率0.55として、

`τ ≤ 1.2 × 0.016114 / 0.55 + 0.005 + 0.001 = 0.04116N·m`

許容値の約50%です。0.4Nは未実測の設計予算なので、試片で摩擦を測り直します。指で押された状態で持ち上げる能力は含めません。

追加8点はカム上下2点、画素3点、案内板1点、カム結合キー2点です。

**右面：歯車で起き上がる旗**

旗は14 × 28 × 2mmです。閉じたときは面の一部として面一になり、0〜60°起き上がります。

flag-boxの起き上がる板を引き継ぎますが、サーボを旗の回転中心へ直結すると前面の遮蔽が難しくなります。この面ではカセット内部に1対の平歯車を置き、サーボを内側へ下げます。

- 歯車：モジュール1.5、18歯相当、圧力角20°
- ピッチ半径：13.5mm
- 軸間距離：27mm
- 歯幅：3mm
- 旗側：必要部分だけ残す120°の扇形歯車
- 歯先半径：14.6mm。細い歯先を切り詰める
- 接線方向のバックラッシュ：0.2mm

`軸間距離 = 1.5 × (18 + 18) / 2 = 27mm`

歯先半径14.6mmでの計算上の歯先幅は1.47mmです。片歯面0.1mmの逃げを入れても約1.27mm残します。計算上のかみ合い率は約1.18です。

サーボ軸を `(v,d)=(0,17.5)mm`、旗の軸を `(-22.776,3)mm` に置きます。

`水平方向の軸間距離 = √(27² − 14.5²) = 22.776mm`

追加4点はホーン受け兼入力歯車、扇形歯車、旗板、蝶番ピンです。旗板と扇形歯車は別刷りにして、向きが決まる差し込みと解除できる爪で結合します。

可動質量8g、重心距離16mm、効率0.65として、

`τ ≤ 0.008 × 9.80665 × 0.016 / 0.65 + 0.005 + 0.001 = 0.00793N·m`

許容値の約10%です。歯車の分離力は、許容負荷側でも軸受けの遊びが増えないよう両側支持で受けます。噛合部の周囲は固定壁で覆い、旗と一緒に出る扇形部分には旗側の遮蔽壁を付けます。

**共通の動かし方**

全移動は2秒とし、始めと終わりの速度と加速度が0になる五次曲線を使います。

`q(s)=10s³−15s⁴+6s⁵、s=t/2`

60°動作の最大角速度は56.25°/秒です。閉端を押し続けず、実物で当たる位置から指令を戻します。電源断時の位置保持は保証しません。自重で戻っても部品が外れず、隣の面の領域へ入らないことを要求します。

## D. 刷り方と組み方

全体は **印刷48点、SG92R 3台、付属ホーン3個** の計画です。印刷48点には、可動カセット31点、空の面3組で9点、骨格6点、配線整理部1点、中央トレー1点を含みます。

| 部品群 | 印刷姿勢と形の条件 |
|---|---|
| 前枠、空の面、蓋、旗板、画素の頭 | 外から見える面をベッドへ |
| 内側の遮蔽兼支持部 | 見える内壁をベッド側または上向きへ。軸受けの横穴は涙形 |
| リンク、クランク | 広い平面をベッドへ。ピンは上へ立てる |
| 歯車、扇形歯車 | 歯の輪郭をベッドと平行にする |
| カム上下 | 各半体の平らな背面をベッドへ。溝の接触面は上へ成長させる |
| 蝶番ピン | 0.5mmの平面を設けて寝かせる |
| サーボ押さえ、固定キー | 弾性腕が積層面内で曲がる向き |
| 上下枠、柱 | 枠は平置き。柱は長手をベッドと平行にする |

サポートは全点なしを目標にします。見えない内部の橋渡しも10mm以下に制限します。ベッドに接する嵌合口は0.3mm面取りします。

組立順は次の通りです。

1. 下枠へ4本の柱を差し、上枠を付けます。中央トレーと面別の配線案内を取り付けます。
2. 各カセットを箱の外で組みます。SG92Rを90°にしてから付属ホーンを付けます。
3. 蓋面は蓋27.4775°、旗面は旗30°、画素面は全画素0mmを組立基準にします。実物のホーンの刻みに合わせて補正値を記録します。
4. 各カセットを単体で全範囲動かします。その後に閉状態へ戻します。
5. サーボ線を専用の開放溝へ置きます。カセットの位置決めを合わせ、面法線方向へ差し込みます。
6. 固定キー2個を入れます。前面が3個の座面へ着座したことを確認します。
7. 空の面を入れ、最後に底面を閉じます。

面の交換は、電源を切り、対象面のキー2個を外し、40mm引き出し、コネクタをつかんで切り離します。残り4面と底面を外す必要はありません。カセット内部を分解するときは、取り出してからサーボ押さえを外します。

**プレートは4枚に分けます。** 92mm角の面板をベッドへ伏せる指定姿勢では、部品間6mmを取った3列が `92×3+6×2=288mm` となり、X1Cの256mmを超えます。1枚への集約は採用しません。

| プレート | 内容 |
|---|---|
| 1 | 骨格、背面と左面の空の面、その固定キー |
| 2 | 蓋カセット、底面、配線整理部、中央トレー |
| 3 | 3画素カセット |
| 4 | 旗カセット |

各プレートは手前左18 × 28mmの除外域を避けます。この4枚は設計上の割付です。実装時に実STLを配置し、重なりとはみ出しを確認してから3mfを確定します。印刷時間と材料量はスライス後に出します。

**実装順**

1. **共通規格を固定する。** `interface.json`へBの座標、占有箱、取付部、配線域を書きます。空の面と角部試片を先に作ります。
2. **SG92Rを実寸で置く。** 正本をimportし、ホーンを含む全姿勢が占有箱に入ることを確かめます。単純な本体直方体だけでは判定しません。
3. **単体カセットを作る。** `params → kinematics → geometry → assembly`の順に実装します。試片が適合するまで本体の適合を確定扱いにしません。
4. **合成する。** `slots.json`から形状、部品表、運動、組立、仕様を生成します。完成位置へ焼いたSTLに対する局所運動の変換は、スロット変換を`S`として `Tworld = S Tlocal S⁻¹` とします。
5. **交換を検査する。** 他面を据えたまま、キーの解除、40mmの抜去、配線の切離し、再装着を工程に入れます。部品の移動は1mm以下、回転は5°以下の刻みです。
6. **スライスしてゲートを通す。** 標準プロファイルの継承を展開し、X1C／PLA／0.4mm／0.2mm／Textured PEI／初層補正0.15mmで切ります。計器と閾値は変更しません。

**複数サーボの検証方法**

現行ゲートの`servo_deg`と`motion.actuator`は1個です。重力トルクも、その1角度に対する位置エネルギーの変化から計算します。3台を同時に動かす入力では、各サーボの負担を分離できません。これは [現行gate.py](C:/Users/kouga/Projects/Web/model-lab/tools/mechgate_lib/gate.py:324) の制約です。

そこで、次の3ケースを生成します。

- `checks/front`：正面だけを掃引。他面は固定。
- `checks/top`：上面だけを掃引。他面は固定。
- `checks/right`：右面だけを掃引。他面は固定。

各ケースに全組立部品を残し、対象駆動系の`interfaces`を検査します。面同士の任意の角度組合せについては、Bの占有領域から出ないことを別途証明します。数個の同時動作例だけで全組合せを確認した扱いにはしません。

ルートの通常検査は上面を代表駆動系にします。完了には、**3ケースそれぞれの全ゲートと、`tools/mechgate.py check resident-cube-cassettes-a`のexit 0**を要求します。ルートの1回だけでは全3台の検査完了としません。

抜け止めの現行検査は完成時の基準姿勢に対して行われるため、開端と中間姿勢も基準位置へ焼き直した検査ケースを作ります。

**`spec.json`の要件下書き**

| ID | 要件 | 対応する検査 |
|---|---|---|
| R1 | 閉状態100 × 100 × 100mm | `assembly.envelope` |
| R2 | 3種類の機構を各SG92Rで動かす | 各ケースの`interface.coverage`、`interface.drive`、`motion.torque` |
| R3 | 隣の面を変更せず交換できる | `assembly.path`、`interface.retention`、占有領域の補助検査、`manual:他面を残して交換` |
| R4 | 動作中もサーボと伝達部品を見せない | `manual:0°・30°・60°と斜め方向から遮蔽を確認` |
| R5 | 印刷部品とSG92R・付属ホーンだけで組む | 部品表、`assembly.path`、`manual:工具なしで組立と分解` |
| R6 | サポートなしで見える面を仕上げる | `print.slice`、`print.grounding`、`print.slender` |
| R7 | 全動作で干渉しない | `motion.interference`、連続掃引を含む占有領域検査 |
| R8 | 仮値を試片で扱う | `unknowns.resolved`、`manual:実物適合を記録` |
| R9 | 面追加がそのディレクトリ内で完結する | 合成処理の検査、`manual:テンプレート面を別スロットへ追加` |

基本値は`envelope_mm:[100,100,100]`、`uses:["sg92r"]`、`waivers:[]`です。依頼原文は`request`へそのまま入れます。

`interfaces`は次の粒度で生成します。

| 界面 | 宣言 |
|---|---|
| ホーン → クランク／入力歯車／カム | `drive`、`both`、遊び3°以下 |
| クランク → リンク → 蓋 | 各接合を`drive`、`both` |
| 入力歯車 → 扇形歯車 → 旗 | 各接合を`drive`、`both`。歯車段の遊び目標1°以下 |
| 下カム → 各画素 | `drive`、`one_sided`、遊び0.4mm以下 |
| 上カム → 各画素 | 反対側を受ける`drive`、`one_sided`、遊び0.4mm以下 |
| カセット → 骨格 | 外向きの`retention`、自由移動0.5mm以下、掛かり2.4mm |
| ホーンと可動部 | 軸方向両側の`retention`。合計遊び0.5mm以下 |
| サーボ、キー、各ピン | それぞれ外れる方向の`retention` |

上下カムは別部品なので、片方だけを`both`とは宣言しません。上下を合わせて両方向を拘束していることと、出力の合計遊びも確認します。

`allowances`の初期案は次の形です。

```json
[
  {
    "type": "snap",
    "pairs": [["front/key_l", "frame"], ["front/key_r", "frame"]],
    "engage_mm": 2.4,
    "deflection_mm": 0.6,
    "strain_percent": 0.444,
    "basis": "解除腕L18mm・t1.6mm。組付け終端に重なりを残さない"
  }
]
```

サーボ押さえや他の爪は、それぞれの寸法から別に計算して追加します。`reference_internal`はSG92R本体と付属ホーンの正本内部だけに限定し、実測した共通体積を記録します。印刷部品同士の干渉を通すための`static_fit`や一括除外は初期案に入れません。

最後に、現行ゲートは`faces/`内のソースと`slots.json`を自動では鮮度追跡しません。`certify.py`が全入力のハッシュを比較し、変更があれば合成し直してから全ケースを検査する入口にします。試片のSTLが存在することと、実物で適合したことも別の状態として記録します。

**この案の弱点**

- 交換可能な面を100mm角へ収めるため、動く部分は小さくなります。C1の全面蓋や5×5画素の広がりは引き継げません。
- 機構を動作中も隠す遮蔽壁が、最も形状調整を要します。現段階では断面試片と全角度の実形状検査が残っています。
- 3台のサーボと交換部品によって印刷点数は48点になります。共通規格を得る代わりに、1台の箱より組立と配線が増えます。
