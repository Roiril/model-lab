# SG92Rホーンの左右と実物の組立結果

2026-10-10にユーザーが実物で原因を特定した。

- 「サーボホーンの左右の長さが若干違う事」
- 「Bは、左右逆に入れても入ってしまうので、それで回転軸が大きくずれる」
- 「Cは、左右逆に入れることがそもそもできないため合う」
- 「Bも、ホーンを逆にして入れたら組むことが出来た」

最後の「逆にして」は、失敗時から向きを直した結果を指す。Bの正確な版はこの発言だけでは確定しない。Bの回転成功までは報告されていない。

直前にユーザーは、C1を変更せず印刷すると組めて回転したと報告した。

「軸の位置も、確かにちょっとだけ違うと思うけど、それにより組めなくなるほどの大きな差ではなかった」とも報告された。寸法差は残るが、今回の組立不能の主因として扱わない。

## 設計への適用

正本 `models/sg92r-photo/params.py` は長腕の端を -18mm と +16mmに置く。この配分は写真の比率からの推定で、今回の報告で18mmと16mmが実測確認されたわけではない。外形を合わせて左右逆に装着すると、名目形状では中心が2mmずれる。

ホーン受けは正しい向きの挿入だけでなく、180°逆向きの装着も検査する。外形を合わせるために中心を左右差ぶん移した場合も検査する。中心がずれたまま入る形を適合とは扱わない。

組立不能の原因を寸法へ決める前に、ホーンの左右と中心穴の一致を確認する。C1の成功から本体幅12.5〜12.6mmを逆算した旧推測は撤回する。

C2の `c2-drawing-trial` は実物未確認の寸法候補のまま。BとC1の組立結果からこの候補の幅11.8mmを確定も否定もしない。寸法図の出典と実物適合を区別する。
