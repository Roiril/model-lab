# C3とC4の表示経路を使う組立検査

2026-10-11にユーザーが「物理検証と組み立ての感じは、C1を真似してほしい。そしてちゃんと検証して」と指示した。

`tools/lattice_assembly.py` と各モデルの `assembly.py` は、表示する部品位置とBoolean MANIFOLDの検査位置を同じ変換列から作る。既に入れた部品を消さず、移動部品同士も含めて検査する。正負校正と工程間の連続性と最終位置を照合する。逆順は同じ検査済み経路を戻る。離散姿勢の間を含む連続空間全体の証明ではない。

C3はホーンとカムを90°で組む。格子を入れる前に15°へ戻す。C4も90°で組む。10°へ戻してから箱外で組んだ格子一式を入れる。C4の配線は先に出口へ通す。中央カムは+Xへ15mm避けて上げてから横へ差す。中央格子を内環より先に入れる。旧手順の順序では3箇所の途中干渉が見つかった。

正本は各 `build/assembly.json`。結果は `assembly_report.json`。旧 `verify_report.json` の組立検査だけを合格根拠にしない。SG92R正本同士の微小な重なりも無条件で除外せず、体積と接触位置を制限する。

`tools/lattice_simulation.py` と `viewer/lattice/sim.mjs` はC1同様に運動方程式を積分する。質量と慣性はSTLから取る。格子の重さを変える操作でサーボまで重くしない。C3の接触開始は解析した境界角の片側の傾きで測る。時間刻みを半分にした結果とPython/JSの全時刻を照合する。接触時の衝撃と離脱後の自由運動は解かない。

同日の再検査で、非干渉と同回転のモーションを駆動成立の根拠にしていた見落としが見つかった。C3の書き出し形状では受け部だけが残り、Boolean後の歯車出力が欠落していた。簡略参照のサーボとホーンにも出力軸や受け形状が無く、正本との接続を証明できなかった。以後は `drive_report.json` で歯数・歯幅・断面接触、正逆の接触角、保持後の残存差込長、保持具から外装までの各界面の引抜き接触を別に検査する。保持相手無しの負例は当該界面の止まりが消えることだけを示す。残った他部品を除外した検査から機構全体の自由抜けを主張しない。

運動方程式は接続形状が成立した場合の条件付き1自由度計算とする。正本に未収録のスプライン歯と材料強度は合格にせず、実機未確認として残す。

`viewer/lattice` の動作と工程の操作ボタンは読込が終わるまで無効。再生終了後の一時停止ボタンも無効。UI検証は読込表示とボタンの有効状態と経過時間を見て進める。配色切替後は現在のボタン名とURLを取り直す。

同日に「透過とかもC1と同じ仕様で」と指示された。C1の内部表示は半透明ではなく、外装の右側だけを隠す断面表示。内部の部品は切らない。描画と視点操作の共通正本は `viewer/shared/mechanism-view.mjs`。C1実データの `view` は幅70mmに対して断面X=14mm、視点の中心Z=50mm、距離300mm。`lidcube.mjs` の汎用既定値X=6mmと距離250mmをC1の実仕様と取り違えない。C3とC4は外形幅に対して同じ比率を使う。組立中の部品移動では断面位置を変えず、工程全体が画面に入る視点だけを調整する。

実物の印刷とサーボ動作は未検証。コード上の適合から実物の着脱力を確定しない。

印刷用の支えと製品の接続は外接寸法だけで判定しない。C4筐体の細い支えには下端0.257184650mm3と上端0.086429037mm3の接続があった。許可領域を上下2箇所へ分けて共通体積の合計を照合する。上端を省いた負例も不合格になることを確認する。接触面だけが残ったBooleanの境界範囲から材料が連続していると推定しない。支え全体が納品STLに含まれることと、各高さの接続体積と、実G-codeの最上層支持を別々に測る。折り取り力と傷みは実物未確認として残す。

組立STLの連結数と印刷STLの連結数は別の定義。印刷専用の離れた支えを含む場合、組立側にはexpected_assembly_components、印刷側にはexpected_print_componentsを使う。C4の中央格子、外環、ホーン受けは組立1成分と印刷2成分。既知の1成分と2成分の校正を維持する。

空き領域確保では、正本とSHA一致したexportsコピーも検証記録の参照対象になり得る。deliveryのsource_layoutとsource_gcodeを含む全参照を確認する前に削除しない。欠落は監査不成立となる。正本から元のパスへ復元して同じSHA照合を通す。ブラウザ一時profileを整理するときはCommandLineで未使用を確認し、今回作った使い捨てprofileの範囲に限る。

Boolean INTERSECT が零厚みの接触面を残すことがある。開いた面を bm.calc_volume で積分すると、原点から離れた平面にも擬似体積を返す。2026-10-11のC3では Z=17.5mm一定の接触面に19.25mm3を誤計上した。lib/solid_volume.pyで閉境界だけを積分する。開いた平面は零体積とし、開いた非平面は例外で検査を停止する。翻訳面接触0、傾斜面接触0、薄い実重複0.01、空洞7をtools/test_solid_volume.pyで校正する。接触の世界座標は別姿勢のキャッシュを再利用しない。

共通体積の主計器はMANIFOLDとする。入力STLは先に全辺の2面共有と向き、重複面、零面積、非隣接面の自己交差を検査する。EXACTは独立した照合値として残す。自己交差検査は共有頂点を持つ三角形を隣接面として除外するため、共有頂点の内部で起きる折り返しは対象外。この制限を含む結果は `boolean_evidence.json` に保存する。EXACTが空形状を返した体積0を合格根拠にしない。

C3の旧軸端キャップには非隣接面の自己交差が4組あった。共通cut後の0.1mm頂点統合が輪郭を崩したことが原因。キャップ専用のEXACT differenceと1e-7m cleanupへ変更し、自己交差0を確認した。修正後の軸0.25mm移動では独立断面の共通体積下限0.912012mm3に対し、EXACT 1.057644519mm3、MANIFOLD 1.057642811mm3となった。

公称同径のサーボ軸とホーン穴は、引抜き姿勢のEXACTで開いた非平面境界を作る場合がある。計器を緩めず、後端支持だけは実後端面の全三角形重心からX直線で初接触を測る。初接触前後0.01mmの離隔と侵入も校正する。この結果は軸/穴の体積干渉やスプライン嵌合の合格を意味しない。

印刷検査はG-codeの分割線分を連結して未支持区間を測る。累計経路長を橋長にしない。短い分割線分だけを見て長い片持ちを見逃さない。長さだけで支持なしを合格にせず、直下層と両端支持と実STLの下面角度を照合する。形状を変えた後は駆動、組立、スライス、表示の記録を再生成し、SHAの差し替えだけで旧判定を流用しない。

C3の端ハブは半径8mmの外装穴を通る。側壁内面を軸方向の止まりと扱わない。キャップに外径12.6mm・内径6.2mmの内向きカラーを追加した。カラーと端ハブの公称隙間は各0.15mm。内部6隙間を含む積層の遊びは主軸肩の隙間と別に測る。キャップ自身の移動も累積する。歯幅は4.6mm。中央キャリアのX幅は5.6mm。各カムの実円板面と従動面の残存幅から、左右ごとの移動上限を引く。

正本STLとの同一表面検査は、頂点集合だけでは再三角化を誤判定する。Blender BVHの単精度最近傍も、細い三角形では同一形状へ0.006〜0.011mmの偽差を返した。float64で全頂点・全三角形重心から全相手面の射影と三辺へ距離を測る。両方向で測る。同一表面の再三角化と極細面を正例にする。面欠落と移動を負例にする。表面積も照合する。有限のサンプル検査なので、表面全体の厳密な最大距離の証明とは書かない。

組立のfinalStateは、部品が揃い最終変換がidentityかを検査する欄。独立の干渉検査ではない。最終姿勢の干渉は各工程末尾とverifyの全組み合わせ検査で測る。手順のassembly.pyとparams.pyも計器SHAへ含める。

閉じた印刷経路は、始点と終点が近くても支持された橋とは限らない。C3のキャップ爪とC4の複数部品で、短い端点間距離の裏に直下支持も先行同層接続もない輪が残った。各輪の全経路に対する直下支持率と実線幅内の先行経路接続を保存する。先行経路自体が浮いていたら支持とは扱わない。浮いた輪を後から囲む周壁を根拠に合格にしない。印刷向きや印刷専用支持を直し、全4種類のG-codeで再検査する。
