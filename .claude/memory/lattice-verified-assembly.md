# C3とC4の表示経路を使う組立検査

2026-10-11にユーザーが「物理検証と組み立ての感じは、C1を真似してほしい。そしてちゃんと検証して」と指示した。

`tools/lattice_assembly.py` と各モデルの `assembly.py` は、表示する部品位置とBoolean EXACTの検査位置を同じ変換列から作る。既に入れた部品を消さず、移動部品同士も含めて検査する。正負校正と工程間の連続性と最終位置を照合する。逆順は同じ検査済み経路を戻る。離散姿勢の間を含む連続空間全体の証明ではない。

C3はホーンとカムを90°で組む。格子を入れる前に15°へ戻す。C4も90°で組む。10°へ戻してから箱外で組んだ格子一式を入れる。C4の配線は先に出口へ通す。中央カムは+Xへ15mm避けて上げてから横へ差す。中央格子を内環より先に入れる。旧手順の順序では3箇所の途中干渉が見つかった。

正本は各 `build/assembly.json`。結果は `assembly_report.json`。旧 `verify_report.json` の組立検査だけを合格根拠にしない。SG92R正本同士の微小な重なりも無条件で除外せず、体積と接触位置を制限する。

`tools/lattice_simulation.py` と `viewer/lattice/sim.mjs` はC1同様に運動方程式を積分する。質量と慣性はSTLから取る。格子の重さを変える操作でサーボまで重くしない。C3の接触開始は解析した境界角の片側の傾きで測る。時間刻みを半分にした結果とPython/JSの全時刻を照合する。接触時の衝撃と離脱後の自由運動は解かない。

`viewer/lattice` の動作と工程の操作ボタンは読込が終わるまで無効。再生終了後の一時停止ボタンも無効。UI検証は読込表示とボタンの有効状態と経過時間を見て進める。配色切替後は現在のボタン名とURLを取り直す。

実物の印刷とサーボ動作は未検証。コード上の適合から実物の着脱力を確定しない。
