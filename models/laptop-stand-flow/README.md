# laptop-stand-flow — 参考画像を再現したS字ノートPCスタンド

`design/reference.png`（画像生成で作ったコンセプト画像）の左右一対のスタンドを、側面の輪郭ごと再現したモデル。
`laptop-stand-100` は同じ画像から「実用寸法に直した再設計」で、こちらは画像の形そのものを優先している。

## 寸法（SIZE_FACTOR = 1.0）

| 項目 | 値 |
|---|---|
| 1脚の外形 | 幅 85 × 奥行き 247 × 高さ 139.5 mm |
| レール板 | 幅 24 × 厚み 7.5 × 長さ 約215 mm（脚の上面から 139.5 mm） |
| 脚の中心間 | 200 mm（`PAIR_SPACING`） |
| 体積 | 1脚 約550 cm³（中実の値。印刷はインフィルで軽くなる） |

画像1px = 0.75mm で読んだ大きさ。ノートPCの奥行きは約230mmまで載る。全体を縮めるときは `params.py` の `SIZE_FACTOR` を変える。

## 画像から読み取ったこと・決めたこと

- **側面の輪郭は画像から直接トレースした**（`ref_trace.py`。手前の脚がほぼ真横から写っている部分）。`overlay.py` で画像に重ねて確認できる
  - 上端のレール板は水平、前端に下向きの返し
  - 柱は上から下へ細くなってから足に広がり、足先は左へ細く尖る
  - 柱とリボンの間に涙形の抜け、前側は大きく開く。足の前端は丸い
- **幅（X方向）は画像から決められない**。画像は斜めからの1枚で、2脚の見え方も一致していない。柱・リボン・足の半幅を位置ごとに置いて（`shape_field.py` の `SEEDS`）、斜め視点の見た目が近くなるように調整した
  - 柱とリボン: 幅 約38〜40 mm。足の前: 幅 約85 mm
- 画像では左右の脚は同じ向きの複製として写っている。このモデルは各脚を左右対称にした
- 画像の足先は斜め視点で長く見えるが、側面図では約65px（約49mm）。側面図の値を採った

## 作り方

1. `ref_trace.py` の輪郭（外形と抜け）を滑らかな曲線にする
2. 輪郭の内側の深さ `d` から、片側の厚み `h = H · f(d / R)` を決める（`shape_field.py`）。`H` は半幅、`R` は丸みの半径
3. 3D格子（0.6mm）の場 `|x/H|^p + (1 − d/R)^p − 1` と、別に作るレール板・返しの符号付き距離を合わせる
4. surface nets で表面を取り出し、Taubin 平滑化して Blender のメッシュにする（`model.py`）
5. 足の底は z=0 で、柱の上面は板の座で、水平に切る

## ビルドと確認

```bash
./run.sh models/laptop-stand-flow/model.py        # exports/laptop-stand-flow.stl（2脚）と -unit.stl（1脚）
./run.sh models/laptop-stand-flow/verify.py       # 非多様体の辺・連結成分・体積・底面の高さ
./run.sh models/laptop-stand-flow/render_preview.py   # exports/laptop-stand-flow/*.png
py -3.11 models/laptop-stand-flow/overlay.py out.png   # トレースを画像に重ねる
```

検証結果（2026-10-04）: 1脚・2脚とも非多様体の辺 0、連結成分は脚の数どおり、体積は正、底面は z=0。

## 印刷について（未試験）

- 1脚を単体で印刷する場合は `exports/laptop-stand-flow-unit.stl`。長さ約247mmなので、X1C の 256mm 角に対して対角に置く
- 正立で刷るとレール板の下と柱の前面にサポートが要る。サポートの当たる面は曲面なので、取り除いた跡が残る
- レール板は厚み7.5mm、張り出し約160mm（柱の前面から先端まで）。荷重は未計算・未試験。PLA で撓むようなら板の厚みを増やす（`PLANK_THICKNESS`）
- 画像は概念図で、耐荷重や印刷適性の根拠にはならない
