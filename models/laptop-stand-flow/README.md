# laptop-stand-flow — 参考画像を再現したS字ノートPCスタンド

`design/reference.png`（画像生成で作ったコンセプト画像）の左右一対のスタンドを再現したモデル。
`laptop-stand-100` は同じ画像から「実用寸法に直した再設計」で、こちらは画像の形を優先している。

## 画像と同じカメラから見たときの一致（2026-10-04）

画像の手前の脚（左）を、同じ画角のカメラから描いて輪郭を比べた。

| 指標 | 値 |
|---|---|
| 輪郭の食い違い（XOR 面積 ÷ 参考の面積） | **2.33 %** |
| IoU | 97.7 % |
| 比べた範囲 | 手前の脚。後ろの脚と重なる・影で汚れる所は数えない |

`exports/laptop-stand-flow/same-view.png` に、参考画像・同じカメラのモデル・輪郭の重ね（赤がモデル、緑が参考）を並べてある。
`fit/rebuild.sh` を実行すると、同じ数字が `MEASURE` として出る。

**この数字が言えないこと**

- 一致させたのは手前の1脚だけ。画像の中の脚は、同じ形を並べただけでは合わない。2脚目をこのカメラで探した置き場所（間隔・前後・高さ）の最良でも、2脚合わせた食い違いは約20%だった。画像の2脚は形も遠近も食い違っている
- 画像の右の小さなノートPCの図（ほぼ真横）とは比べていない。側面の形は、手前の脚を側面図として読み取った輪郭（`ref_trace.py`）から、次の「歪み」の分だけ動いている
- 輪郭だけを合わせている。陰影・表面の細かい形・奥行きは合わせていない

## 寸法

| 項目 | 値 |
|---|---|
| 1脚の外形 | 幅 92 × 奥行き 248 × 高さ 141 mm（X は歪みで中心から少しずれる。書き出しでは中心へ寄せてある） |
| レール板 | 幅 24 × 厚み 7.5 mm（脚の上面 約140 mm） |
| 脚の中心間 | 200 mm（`PAIR_SPACING`） |
| 体積 | 1脚 約320 cm³（中実の値。印刷はインフィルで軽くなる） |

画像1px = 0.75mm で読んだ大きさ。全体を縮めるときは `params.py` の `SIZE_FACTOR`。

## 作り方

形は3段で決めている。

1. **側面の輪郭を厚み付けする**（`model.py` / `shape_field.py`）
   手前の脚の側面の輪郭（`ref_trace.py`）の内側の深さ d から、断面 `|(x − xc)/H|^p + (1 − d/R)^p = 1` で厚みを決める。H は半幅、xc は中心のずれ、R は丸み。H・xc・R は位置ごとの値（`SEEDS`）を滑らかに補間する。3D格子（0.6mm）の場を surface nets で表面にし、Taubin 平滑化する。足の底は z=0 で、柱の上面は板の座で、水平に切る
2. **カメラと H・xc・輪郭の歪みを、画像の輪郭にあわせる**（`fit/cma_fit.py`、CMA-ES）
   カメラ（方位・仰角・ロール・距離・焦点・主点）、シードの H と xc、側面平面の滑らかな歪み（20点）、レール板の長さと幅を動かす。形は常に「輪郭を厚み付けした形」のままなので、他の角度から見ても崩れない。ここまでで食い違いは約 8〜9%（`fit_state.json`）。穴の縁は、穴から離れるほど広がる幅（トンネル）に絞って、穴が向こうまで見えるようにした
3. **画面と平行な小さな歪みで、残りを寄せる**（`fit/warp_fit.py`、`fit/view_warp.py`）
   カメラから見た輪郭の差を、滑らかな変位場（σ=40px）にして、メッシュの頂点を画面と平行に動かす。これを60回重ねる（`fit/view_warp.npz`）。動いた量は平均 3.6 mm、95%点 10 mm、最大 13 mm。接地面より下へは沈ませない。`model.py` が同じ手順を再生する

最初に歪みを大きく掛けて（元の形から約12mm動かして）輪郭を合わせる方法も試したが、形が裂けて使えなかった。2 で形をなるべく合わせてから、3 の歪みを小さく抑えている。

## ビルドと確認

```bash
./run.sh models/laptop-stand-flow/model.py            # exports/laptop-stand-flow.stl（2脚）と -unit.stl（1脚）
./run.sh models/laptop-stand-flow/verify.py           # 非多様体の辺・連結成分・体積・底面の高さ
bash models/laptop-stand-flow/fit/rebuild.sh          # 歪みを求め直して、STL と一致の数字まで作り直す
./run.sh models/laptop-stand-flow/render_preview.py   # exports/laptop-stand-flow/*.png
```

検証結果: 1脚・2脚とも非多様体の辺 0、連結成分は脚の数どおり、体積は正、底面は z=0。自己交差は調べていない。

最適化をやり直す場合（数十分〜）: `py -3.11 fit/cma_fit.py <out.png>`（`fit/cma_state.json` から続きを回す）→ `py -3.11 fit/export_fit.py` → `bash fit/rebuild.sh`。

## 印刷について（未試験）

- 1脚を単体で印刷する場合は `exports/laptop-stand-flow-unit.stl`。長さ約248mmなので、X1C の 256mm 角に対して対角に置く
- 正立で刷るとレール板の下と柱の前面にサポートが要る
- 柱の細い所は、幅の下限を 18mm（半幅 9mm）にしてある。荷重・たわみは未計算・未試験
- 画像は概念図で、耐荷重や印刷適性の根拠にはならない
