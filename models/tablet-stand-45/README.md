# tablet-stand-45

Redmi Pad SE 11インチを横向きに置く45度固定のスタンド。
ケースを付けない本体専用。左右の細い支えを前後の横棒でつないだ一部品。
返しは左右の2か所。中央を空けて画面下側の操作と持ち上げを妨げにくくした。
端面の縁と返しの角を丸めてある。上から置き、真上へ持ち上げて外せる。

## 印刷

`exports/tablet-stand-45/print.stl` をスライサーへ読み込む。単位は mm。
平らな底面を下にした姿勢を保存してある。使用姿勢と印刷姿勢は同じ。
`exports/tablet-stand-45.stl` も同じ形状。分割や接着は不要。

| 設定 | 開始値 |
|---|---|
| 材料 | PETG |
| ノズル | 0.4 mm |
| 積層高さ | 0.2 mm |
| 外周 | 5周 |
| 上下面 | 各6層 |
| 内部充填 | 100%。形状そのものを細くして材料を削減 |
| サポート | 無しを想定。穴頂部の短い橋渡しは約1.13 mm |
| ブリム | 4 mm |

ブリム込みで約188 × 218 mmの印刷面が必要。高さは約120 mm。
温度と冷却は材料とプリンターの指定に合わせる。
PETGの選定は [Prusaの材料資料](https://help.prusa3d.com/article/petg_2059)を参照。
実際の印刷は未実施。穴頂部と返しの根元をスライサーの層表示で確認する。

## 保護材と展示前の確認

1. 背面の支えと底受けに厚さ0.8 mmの柔らかい保護材を貼る。
2. 底面4か所に14 × 14 × 1 mmの再剥離できる滑り止めを貼る。
3. 左右位置は台の中心から±81 mm。前後位置は前端から2〜16 mmと194〜208 mm。
4. 平らな展示机へ固定する。実機の上端と左右の角を押して滑りや浮きを確認する。
5. 取り外しを繰り返して干渉と保護材の剥がれを確認する。返しの根元も確認する。

台141 gと端末478 gを置き、画面に垂直な10 Nの押下を想定して計算した。
底面の接触範囲は幅174 mm。前後位置は3〜206 mmを使用した。
均一密度で算出した台の重心に後方10 mmの誤差を見込んだ。
後方へ倒れる押下力の概算は17.18 N。横転は18.33 N。
滑りへ1.5倍の余裕を見込む場合は摩擦係数約0.81が必要。
机との摩擦は未測定。再剥離できる粘着材で台と机を保持する前提とした。
強度と繰り返し耐久性は実機で確認する。台へ体重をかける使い方は想定していない。

## 再生成と検査

```powershell
& 'C:/Program Files/Git/bin/bash.exe' ./run.sh models/tablet-stand-45/model.py
py -3.11 models/tablet-stand-45/verify.py
& 'C:/Program Files/Blender Foundation/Blender 5.1/blender.exe' --background --python-exit-code 1 --python models/tablet-stand-45/render_preview.py
```

実測重量で計算し直す例は `py -3.11 models/tablet-stand-45/verify.py --stand-mass 0.141`。
重量の単位は kg。省略時は形状の体積から求めたPETG重量を使用する。
検査は正常な立方体の合格と異常形状3種の不合格で先に校正する。
STLのバイナリから閉じた一部品と寸法と体積を検査する。
本体と保護材を想定した16,968点で真上50 mmの取り外し経路を検査する。
左右の肉厚と穴頂部の短い橋渡しを調べる。実機の取り外し試験ではない。
結果は `exports/tablet-stand-45/verification.json` に保存する。

ビューワーは [tablet-stand-45](http://localhost:3000/?model=tablet-stand-45)。
出力STLは台のみ。画像のタブレットは寸法確認用の参考形状。
画像の緑色は仕上がりイメージ。実物の色は材料に合わせる。
