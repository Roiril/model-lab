# tablet-stand-45

大型タブレットを横向きに置く45度固定のスタンド。
接合部のない一部品。前の落下止めは丸めた垂直壁になっている。
タブレットを真上へ持ち上げて外せる。

## 寸法

| 項目 | 値 |
|---|---|
| 外形 W × D × H | 228 × 240 × 145.42 mm |
| 背面の傾き | 机から45度 |
| 想定する横置き端末 | 横幅280〜340 mm・縦225 mm以内 |
| 想定厚さ | ケース込み16 mm以内 |
| 受け口の底幅 | 22 mm |
| 落下止め | 画面に沿った高さ9 mm・厚さ6 mm |
| 底板と背面の支え | 10 mm |
| 後ろの支え | 16 mm |
| 穴の隅 | 半径15 mm |
| 側面の縁 | 0.8 mmの面取り |

想定寸法は実機との適合を保証する値ではない。
端末の下端にあるボタンやケースの突起は実機で確認する。
充電端子は横置きした端末の左右に出る想定。
前の落下止めは端末の左右移動を固定しない。

## 印刷

スライサーには `exports/tablet-stand-45/print.stl` を読み込む。
側面を下にした姿勢を保存してある。単位は mm。
使用姿勢を表示する `exports/tablet-stand-45.stl` はビューワー用。

| 設定 | 開始値 |
|---|---|
| 材料 | PETG |
| ノズル | 0.4 mm |
| 積層高さ | 0.2 mm |
| 外周 | 5周 |
| 上下面 | 各6層 |
| 内部充填 | 40〜45%のGyroidを開始値とする |
| サポート | 無しを想定 |
| ブリム | 6 mm |
| 完成重量 | 1.0 kg以上を目標に充填率を調整する |

印刷姿勢の外形は145.42 × 240 × 228 mm。
6 mmブリムを含めると約158 × 252 mmの印刷面が必要になる。
高さ228 mm以上も必要。256 mm角の造形範囲を想定している。
造形範囲が小さい機種にはこの出力をそのまま使えない。
温度と冷却は使用するPETGとプリンターの指定に合わせる。
重量はスライサーの材料使用量と印刷後の計量で確認する。

PETGを選ぶ理由は保持具に適した粘りと丈夫さ。
[Prusaの材料資料](https://help.prusa3d.com/article/petg_2059)を参照。
上の印刷設定はこの設計の開始値。実際の印刷は未実施。

## 接触材と展示前の確認

1. タブレット背面と底受けに厚さ1 mmの柔らかい保護材を貼る。
2. 台の底に厚さ1.5 mmの滑り止め帯を前後2本貼る。各帯は幅216 × 奥行14 mm。
3. 幅方向は中央に貼る。前の帯は前端から10〜24 mm。後ろの帯は222〜236 mmに置く。
4. 完成した台を計量する。1.0 kg未満なら下記の再計算で条件を確認する。
5. 実機を置く。上端と左右の角を押して滑りや浮きがないことを確認する。
6. 持ち上げて外す操作を繰り返す。受け口の干渉と保護材の剥がれを確認する。

静力学の計算は台1.0 kg・端末0.579〜1.0 kg・画面に垂直な10 N押下を想定。
底の接触範囲は幅216 mm。前後位置は12〜234 mmを用いた。
台の重心はSTLから算出した均一密度の値より10 mm後ろへ移した条件で評価した。
後ろへ倒れるまでの押下力は最悪例で16.79 N。10 Nに対する比は1.68。
滑りについて同じ余裕を得るには摩擦係数0.47以上が必要という計算になる。
実際の机と滑り止めの摩擦は未測定。破断荷重と繰り返し耐久性も未試験。
人が台へ体重をかける用途は想定していない。

## 再生成と検査

```powershell
& 'C:/Program Files/Git/bin/bash.exe' ./run.sh models/tablet-stand-45/model.py
py -3.11 models/tablet-stand-45/verify.py --stand-mass 1.0
& 'C:/Program Files/Blender Foundation/Blender 5.1/blender.exe' --background --python-exit-code 1 --python models/tablet-stand-45/render_preview.py
```

`verify.py` は `numpy` を使用。STLのバイナリを直接読む。
正常な立方体が通ることを先に確認する。
穴のある立方体と裏向きの立方体と空形状が検査で止まることも確認する。
出力の検査結果は `exports/tablet-stand-45/verification.json` に保存する。
閉じた一部品であることと正の体積を検査する。
厚さ16 mmの端末と保護材を想定した6,363点で真上50 mmの取り外し経路を調べる。
これは点による幾何検査。実機の取り外し試験ではない。
印刷姿勢では床以外に45.5度を超える張り出し面がないことを確認する。
最大値は45.23度。曲面の面取りで生じる小面を含む。

ビューワーは [tablet-stand-45](http://localhost:3000/?model=tablet-stand-45)。
出力STLは台のみ。画像のタブレットは寸法確認用の参考形状。
画像の緑色は仕上がりイメージ。実物の色は材料に合わせる。

基準端末の公式資料:

- [iPad Pro 13インチ M4](https://support.apple.com/en-au/119891): 横置き281.6 × 215.5 × 5.1 mm。579 g。
- [Galaxy Tab S10 Ultra](https://www.samsung.com/in/tablets/galaxy-tab-s/galaxy-tab-s10-ultra-silver-256gb-sm-x920nzsains/): 横置き326.4 × 208.6 × 5.4 mm。
