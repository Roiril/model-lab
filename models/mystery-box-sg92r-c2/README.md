# 住人の箱 C2・分割天面

B3 の70mm角と0〜65°の開閉範囲を保ち、現行の検証手順で作り直した別モデル。前側の天面だけを SG92R と4節リンクで開く。後ろ約16.2mmは手で外せる固定天面にした。固定天面は蝶番の荷重を受けない。B3 と C1 は変更しない。

Studio: http://localhost:3000/?model=mystery-box-sg92r-c2

検証レポート: `reports/2026-10-10_mystery-box-c2.html`

## B3 から変えたこと

- 印刷部品を22点から8点へ減らした
- 天面の固定部を約26.8mmから約16.2mmへ縮めた。蝶番付近には分割の溝が見える
- サーボ台を箱と一体にした。底面から工具で外す留め具をなくした
- 壁、底、天面を3mmにした。外形の角はR5とした
- SG92R本体と付属ホーンは `models/sg92r-photo/params.py` から読み込む。ホーンの写真計測値をクランクのポケットへ反映した
- サーボ軸をB3より6mm前へ移した
- 直径25mm、高さ10mmのエキサイターを右壁へ手で固定する場所を設けた。この寸法は仮の包絡である

## 部品

印刷する部品:

| 部品 | 役割 |
|---|---|
| `box` | 箱。サーボ台、クランク受け、エキサイターの案内を含む |
| `lid` | 前側の可動天面。リンクのピンBを受ける耳を含む |
| `roof` | 後ろの固定天面。外側から押せる解除つまみ、45°の一体腕、左右の脚と爪を持つ点検口 |
| `crank` | 付属ホーンを包み、サーボの回転をリンクへ伝える |
| `link` | クランクと可動天面をつなぐ腕 |
| `pin` | 蝶番ピン。左の割り先端だけを軽く圧入する |
| `clip` | SG92Rを一体型の台へ押さえる |
| `speaker_clip` | エキサイターを右壁へ押さえる |

既製部品:

- SG92R本体、付属ホーン、配線。寸法の正本は `models/sg92r-photo/`
- 直径25mm、高さ10mmのエキサイター。型番、接触面、保持力、音量は未確認

## 組み立て

工具、ねじ、結束バンド、接着剤は使わない。

1. エキサイターを上から右壁の案内へ入れる。`speaker_clip` を上から押し込む
2. 箱の外でサーボを90°にする。中央姿勢に合う向きで付属ホーンを付け、`crank` をかぶせる
3. `link` の鍵溝をピンAの爪へ合わせて差す。動作位置まで回す
4. サーボ一式を上から箱へ下ろす。配線を後ろの出口へ通す
5. `clip` を上から押し込み、サーボを留める
6. 可動天面を95°にする。箱の40mm上から下ろして蝶番を合わせる
7. 蝶番ピンを右から入れる。左の割り先端だけを穴へ押し込む
8. `link` の先を3.4mm逃がす。可動天面を中央姿勢へ下ろし、ピンBを耳の穴へ入れる
9. `roof` を上から下ろす。左右の爪が壁内側の溝へ掛かるまで押す
10. サーボを閉じる側へ1°ずつ動かす。可動天面が縁に載った位置を閉位置とする

点検口を外すときは、可動天面を32.5°に開く。正面の開口から左右の解除つまみへ指を入れる。左右のつまみを箱の中央へ1.12mmずつ押す。爪を内側へ逃がしたまま固定天面を上へ引く。つまみの下端はX=±18〜20mm、Z=39〜41mmにある。指の経路は中心X=±24.5mm、Z=45mmで確かめた。蝶番ピンを抜くときは左端を押し、右側へ約3mm出た端をつまむ。

電源を切っても、可動天面には閉じる向きの自重が掛かる。ギアと継ぎ手の抵抗で止まるかは実物で確かめる。

## 刷る向き

| 部品 | 向き | サポート |
|---|---|---|
| 箱 | 口を上。後ろ面をプレートの奥へ向ける | なし |
| 可動天面 | 外から見える面を下 | なし |
| 固定天面 | 外から見える面を下 | なし |

| リンク | 平らに寝かせる | なし |

| サーボ押さえ | 横に寝かせる | なし |

Bambu Lab X1C、0.4mmノズル、PEIプレート用。PLA用とPETG用を各1枚に収める。サポートは使わない。完成プレートは `PLA.gcode.3mf` と `PETG.gcode.3mf`。本体より先に次を刷る。

- `crank-test-PLA`: 付属ホーンの嵌まり
- `joints-test-PLA`: 蝶番、リンク、サーボ押さえ
- `speaker-test-PLA`: エキサイターの保持
- `roof-test-PLA` と `roof-test-PETG`: 固定天面の爪、取り外し、材料差

配置とSHA256は `prints/mystery-box-sg92r-c2/manifest.json` に記録する。推定時間と使用量は `build/plate_report.json` を参照する。

## 要件ごとの結果

- 外形: 70 × 70 × 70mm。壁と底は3mm。外形の角はR5
- 動き: 前側の可動天面を0〜65°で動かす。固定天面は箱本体へ留まり、蝶番の荷重を受けない
- 組み立て: 印刷部品と指定した既製部品だけを使う。工具、ねじ、接着剤は使わない
- 分解: サーボ、エキサイター、蝶番、固定天面を壊さずに外す経路を設けた
- 寸法: SG92Rと付属ホーンは正本を読み込む。エキサイターだけは25 × 10mmの仮包絡
- 印刷: PLA/PETGともX1C用の完成 `gcode.3mf` を用意する。8部品を各材料1枚へ置く
- 検証: 動作、組み立て経路、曲げ近似、質量と慣性、メッシュ、スライス、配置を別々に記録する

## 決めたこと

- 固定天面を点検口にした。外側の解除つまみを箱の中央へ押して上へ外す
- 解除つまみは外側から箱の中央へ押す。45°の一体腕で16mmの脚へつないだ
- 可動天面を95°にして蝶番を組む。固定天面は最後に付ける
- エキサイターは右壁へ向ける。音の良否は実物で判断する
- 開閉は1.2秒から始める。端の衝撃を見て `OPEN_TIME_S` を延ばす

## 譲ったこと

- 天面の分割線と蝶番付近の溝は外から見える。内部へのアクセスと工具なしの分解を優先した
- エキサイターの製品形状は未確定。25 × 10mmの包絡で保持部だけを作った
- 曲げひずみは梁としての近似値である。材料試験と有限要素解析はしていない

## 実物で確かめること

1. 付属ホーン試片を刷る。固い場合は `HORN_CLR` を0.05mmずつ広げる
2. PLAとPETGの固定天面試片を刷る。外側の解除つまみを中央へ押せるか、16mmの脚が安定して造形できるか、爪が保持できるか、白化せず外せるかを比べる
3. 蝶番、リンク、サーボ押さえの試片を刷る。割れと抜けを確かめる
4. エキサイター試片を刷る。接触面、保持力、音量、びびりを確かめる
5. 全体を組む。電圧、摩擦、保持、手での分解、0〜65°の実動作を確かめる

## 検証済みの数値

- 8部品とも非多様体辺は0。1.2mm未満の薄肉リストは空
- 0〜65°を131姿勢で確認し、意図しない衝突は0
- クランクと箱の最小隙間は0.296mm。可動天面と固定天面は0.995mm
- リンク長は40.23014mm。曲げ自由長は29.23mm
- リンク先端を3.4mm逃がす近似ひずみは1.79%。固定天面は自由長16mm、解除変位1.12mm、近似ひずみ1.31%
- 直径10mmの指を中心X=±24.5mm、Z=45mmで前面から入れる経路と、つまみを中央へ1.12mm押す経路の障害は0
- 解除後の爪外端はX=±31.68mm。壁との隙間は0.32mm
- 爪の高さは4.8mm。先端に2mmの厚みを残した
- 曲げたリンクとクランクの交差体積は0mm³
- 外部未支持経路は箱56.91mm、可動天面3.47mm。クリップ溝、爪の受け、蝶番穴、リンクB穴など狭い内側形状に残る。目立つ外装の張り出しは修正済み
