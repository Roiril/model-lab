# 住人の箱 C3・直交格子

SG92R 1台で5×5の格子を動かす80mm角の箱。5本の列キャリアを5個の偏心カムで押し上げる。中央列、隣接列、外側列の順に波が移る。閉状態は80 × 80 × 80mm。最大状態は80 × 80 × 83mm。

Studio: http://localhost:3000/?model=mystery-box-sg92r-c3

物理検証: http://localhost:3000/viewer/lattice/index.html?model=mystery-box-sg92r-c3&mode=physics

組み立て: http://localhost:3000/viewer/lattice/index.html?model=mystery-box-sg92r-c3&mode=assembly

## 部品

印刷部品:

| 部品 | 数 | 役割 |
|---|---:|---|
| `shell` | 1 | 外装、サーボ座、前後ガイド、案内板の棚 |
| `top_frame` | 1 | タイル周囲を面一に整える天面案内板 |
| `carrier_0..4` | 5 | 各5枚のタイルを隠し梁でつないだ格子列 |
| `cam_0..4` | 5 | 半径7mm、偏心5mmの列用カム |
| `camshaft` | 1 | 対辺5mmの六角カム軸 |
| `cam_gear` | 1 | カム軸側の30歯歯車 |
| `drive_gear` | 1 | 付属ホーン受け付き30歯歯車 |
| `cap_left` / `cap_right` | 各1 | 軸方向遊び0.3mmを残す着脱キャップ |
| `servo_clip` | 1 | SG92Rを上から押さえる印刷クリップ |
| `fit_horn` | 1 | ホーン受け試片。本体より先に刷る |
| `fit_bearing` | 1 | 六角軸と丸穴の試片。本体より先に刷る |

既製部品はSG92R本体と付属ホーンだけを使う。ねじ、接着剤、金属軸、結束バンドは使わない。寸法は `models/sg92r-photo/params.py` を直接読み込む。

## 寸法と動き

- 外壁と床は3mm。荷重部も3mm以上
- タイルは10.4mm角。ピッチ11.2mm。隙間0.8mm
- サーボ軸はZ=23.5mm。カム軸はZ=53.7mm。中心距離30.2mm
- 歯車は30歯、module 1、圧力角20°、厚さ4mm。円周方向バックラッシュは0.18mm
- カム位相は左から145°、105°、65°、105°、145°
- 列の高さは `max(0, 5 × (cos(theta - phase) - 0.4))` mm
- サーボ15°が閉状態。カム角は-5°。サーボ165°でカム角145°
- 片道2秒。quintic補間で始動と停止を緩やかにする

停電時に列の重さだけでSG92Rの減速機を逆駆動できるとは限らない。停止角度付近に残る場合がある。復電後は15°へ2秒以上かけて低速復帰する。天面を上にした卓上姿勢だけで使う。

## 最初に刷る試片

1. `print_fit_horn.stl` を刷る。付属ホーンが手で奥まで入り、逆さにして落ちないことを見る
2. 緩い場合は `HORN_CLEARANCE` を0.05mmずつ減らす。固い場合は0.05mmずつ増やす
3. `print_fit_bearing.stl` を刷る。六角軸が丸穴の中で指で回ることを見る
4. 固い場合は `BEARING_D` を0.1mmずつ増やす。ガタが大きい場合は0.1mmずつ減らす
5. PETGは糸引きと穴縮みが出やすい。PLAで合った後に同じ2試片だけをPETGでも確かめる

## 刷る向き

| 部品 | 向き | サポート |
|---|---|---|
| 箱本体 | 底をプレートへ置き、口を上 | なし |
| 天面案内板 | 見える天面を下 | なし |
| 格子列 | 5枚の見えるタイル面を下 | なし。隠し梁の橋渡しは最大5.6mm |
| カム | 最大面を下 | なし |
| 六角カム軸 | 六角の一面を下 | なし |
| 歯車とキャップ | 回転軸を鉛直にして最大面を下 | なし |
| サーボ押さえ | Y-ZのU字平面を下 | なし |
| ホーン試片 | 受け口を上 | なし |
| 軸受け試片 | 丸穴と六角軸を鉛直 | なし |

筐体の配線口は8mmの橋渡し。軸受け穴は6.2mm。天面棚の下面は45°で壁へつなぐ。前後ガイドの分割区間は2mm幅の縦リブで床から支える。詳細は `build/print_review.json` に記録する。

## 90°での角度合わせ

1. SG92Rだけを接続し、`demo/demo.ino` を書き込む。起動後は90°で静止する
2. 付属ホーンの長腕を箱の左側へ向けてサーボへ押し込む
3. 駆動歯車の三角印を長腕の左端側へ合わせる。ホーン受けを奥まで押す
4. 印刷後もSTL名ごとに分けておく。`cam_0/4`が外側、`cam_1/3`が隣接、`cam_2`が中央
5. 5個のカムと従動歯車を90°姿勢にそろえる。偏心方向が異なる3種類を混ぜず、すべての六角穴の面を同じ向きへ合わせる
6. 従動歯車を駆動歯車にかみ合わせる。歯先を押し込まず、歯底との間に隙間が残る位置を使う
7. 右から六角軸を通す。軸が通らないカムだけを60°単位で回し、無理に押さない
8. キャップを付けた後、列を入れる前にシリアルの `h` を送り、15°へ2秒かけて動かして停止する
9. 格子列と天面案内板を組み、15°で25枚が案内板と面一になることを見る
10. 15°で静止させる。シリアルの `g` を送って低速往復を始める

ホーンは20山なので18°単位でしか付け直せない。端角度はホーンをずらさずソフト側の15°と165°で決める。

## 組み立て

1. 箱を口が上になる向きで置く。箱の外でSG92Rを90°に合わせる。電源を切って付属ホーンと駆動歯車を付ける
2. SG92Rを上から着座レールへ入れる。3ピン配線を前面下の8 × 4mm出口へ通す
3. サーボ押さえを上から差して固定する
4. `cam_0..4`の順を守り、5個のカムを左から所定の列へ置く
5. 従動歯車を置く。右側から六角軸を通す
6. 左右の軸端キャップを外から押し込む。軸が左右へ0.3mm動けることを見る
7. 電源を入れて `h` を送り、15°へ低速移動して停止する。5本の格子列を前後ガイドへ上から1本ずつ入れる
8. 天面案内板を格子列の周囲へ下ろす。4辺の棚へ平らに置く
9. 15°で面一を確認する。`g` を送って低速往復を始める

分解は逆順で行う。`h` で15°に止める。案内板と格子列を上へ抜く。格子がない状態で `c` を送り、90°へ低速で戻して電源を切る。左右キャップを外へ引く。六角軸を右へ抜く。カムと従動歯車を上へ抜く。サーボ押さえとSG92Rを取り出す。表示する13工程の位置は `build/assembly.json`。累積した部品との途中姿勢と逆順の検査は `build/assembly_report.json` に保存する。

## 制御

`demo/demo.ino` は起動後に90°で静止する。115200bpsのシリアルモニターから `h` を送ると、15°へ2秒で移動して停止する。`c` は90°へ2秒で戻して停止する。`g` は15°へ戻した後に15〜165°を片道2秒で往復する。`s` は現在角度で停止する。初回は試片を確認し、格子列を外した状態で15〜165°を動かす。Arduino用コンパイラがないためコンパイルと書き込みは未検証。

信号線はD9。サーボは4.8Vの外部電源から給電する。外部電源とArduinoのGNDを共通にする。

寸法を変えて再スライスした場合は、`build/print_path_review.json` の警告判定を新しいSTLと印刷経路でやり直す。最終検査はファイルのハッシュが一致しない旧判定を受け付けない。

`build/motion.json` は15〜165°を1°刻みで151フレーム持つ。変換は組立STLに対する列優先4×4行列。`verify.py` はSTLを直接読む。全210組を2.5°刻みの61姿勢で検査する。外接箱が交わらない組は共通体積0。残りはBlenderのEXACT Booleanで実体積を測る。`assembly.py` は表示と同じ13工程を1mm以下・5°以下の途中姿勢で検査する。移動部品同士と既設部品の全組み合わせが対象。許容する圧入はサーボ押さえの左右0.1mmだけ。接触位置と推定ひずみを制限する。形状のSHA-256を検査前後で照合する。最終位置と逆順の経路も検査する。

物理検証はC1と同じ1自由度の時間積分を使う。STLの体積から質量と慣性を求める。SG92Rのトルク・速度制限と推定摩擦を含む。標準・逆方向・30%トルク・格子4倍・急な指令の5条件を計算する。Pythonとブラウザの全時刻が一致することを検査する。時間刻みは0.00005秒。半分の刻みとの変化も記録する。重さの操作は格子だけに適用する。標準条件の最大トルクは約0.004796N·m。接触境界の相対速度は最大11.145mm/s。衝撃・接触後の跳ね・自由落下は未計算。計算結果は `build/simulate_report.json` に保存する。

## 要件ごとの結果

- 印刷: 外装は80mm角。見える天面はプレートへ接地する。サポートなし。最終スライス値は `build/delivery_report.json` に保存する
- 組み立て: SG92R付属品と印刷部品だけを使う。工具なしで組める。キャップとクリップを外して非破壊で分解できる
- 動作: 15〜165°を2.5°刻みで検査した。全210組の非許容干渉は0。歯車の最大共通体積は0mm³。サーボ押さえには指定した0.1mmの圧入がある
- 力: 列のSTL体積とPLA密度から求めた必要トルクは停動トルクの1/3未満。値は `build/verify_report.json` の `torque` に保存する
- 配線: SG92Rの3ピンコネクタが通る8 × 4mm出口を設けた。可動部から離して前面下へ出す

## 決めたこと

- `CUBE_W/D/H=80mm`: ホーン全角度包絡、3mm床、30.2mmの歯車中心距離を両立するため
- `SERVO_AXIS_Z=23.5mm`: ホーン包絡の下面を床より0.5mm上へ置くため
- `BEARING_D=6.2mm`: 対辺5mm六角軸の頂点に片側約0.21mmを残すため
- `GUIDE_RIB_W=2mm`: スロットで分かれる前後ガイドを床から支えるため
- `HORN_CLEARANCE=0.20mm`: PLA試片から始められる圧入寄りの値
- `CLIP_INTERFERENCE=0.10mm`: サーボ押さえの推定表面ひずみを約0.31%に収めるため

## 譲ったこと

- 70mmの目標より、ホーン包絡、外壁3mm、組立経路を優先して80mmへ広げた
- 部品数より見える天面と印刷再現性を優先し、天面案内板を別部品にした
- 完全な丸軸より平面印刷を優先し、軸受け区間を六角角軸にした
