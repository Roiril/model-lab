# SG92R で天面が開く 80mm 立方体

SG92R 1 個と 4 節リンクで天面を 0〜95° 開閉する。印刷部品 6 点（箱・蓋・クランク・リンク・蝶番ピン・押さえクリップ）。
買う部品は SG92R と付属の十字ホーンだけ。ねじ・結束バンド・接着剤は使わない。
SG92R の寸法は `models/sg92r-photo/params.py`（確定版）を読み込む。ここには書き写さない。

検証の記録と 3D の再生: `reports/2026-10-09_servo-lid-cube.html`

## 流し方

```bash
./run.sh models/sg92r-photo/model.py          # 参考サーボの STL（exports/sg92r-photo-*.stl）
./run.sh models/servo-lid-cube/model.py       # 部品と組んだ姿勢・刷る姿勢の STL
"C:/Program Files/Blender Foundation/Blender 5.1/blender.exe" --background --python models/servo-lid-cube/verify.py
py -3.11 models/servo-lid-cube/simulate.py    # 開閉の運動方程式
py -3.11 models/servo-lid-cube/slice_check.py # Bambu Studio CLI で部品ごとにスライスして浮いた押し出しを数える
py -3.11 tools/plate_3mf.py servo-lid-cube-plate exports/servo-lid-cube-{box,lid,crank,link,pin,clip}.stl
py -3.11 models/servo-lid-cube/export_web.py  # 報告ページを組み直す（LID_CUBE_PLATE_DIR にプレートのスライス結果）
```

`verify.py` と `slice_check.py` は、先に「当たるはず／当たらないはず」の形で計器を校正してから判定する。
校正が `ok: false` のときは、その回の判定を信じない。

## 形の要点

- 蝶番は後ろ上の稜（軸 y=-35, z=75、筒の半径 5mm）。節は箱 2・蓋 1。ピンは頭なしで、右端を角の球面と同じ形にして面一に納める。止まり穴の奥で止まり、割った先端（直径 5.3mm）が穴（5.2mm）に締まる
- サーボは左の壁ぎわに寝かせ、出力軸は +X。台に落とし込み、コの字のクリップで上から押さえる
- X 方向の層: クランク [-6.1, -2.0] ／ リンク [-1.7, 2.3] ／ 蓋の耳とクランク軸の受け [2.6, 5.6]。互いの掃く範囲は重ならない
- ピン A（クランク側）はバヨネット。鍵溝はリンク−クランクの相対角 +75° にあり、動作範囲（-125〜-55°）から 130° 離れている
- ピン B（リンク側）は、リンクの先を 3.4mm 曲げて蓋の耳の穴へ入れる（ひずみ 1.3%）
- クランクの軸は箱の受けの U 溝に入り、クランクが +X へ抜けるのを止める（ホーンがスプラインから外れない）

## 組み立ての順

1. 蓋を箱に載せ、蝶番ピンを右側面から差す
2. サーボを 90° にしてホーンを押し込む（長い腕を配線側へ、本体に沿わせる）。クランクをかぶせる
3. リンクの切り欠きをピン A の爪に合わせて差し、回す
4. 蓋を後ろへ倒し、サーボ一式を上から台へ下ろす。押さえクリップを押し込む
5. リンクの先をサーボ側へ曲げながら蓋を下ろし、ピン B を耳の穴へ入れる
6. 90° から閉じる側へ 1° ずつ動かし、蓋が縁に載った角度を「閉」、そこから 70° 開く側を「開」とする

動かすときは 0.8 秒かけて始めと終わりをゆっくりにする。全速だと閉じるときに蓋が縁に 6.5 rad/s で当たる。

## 刷る

全部品サポートなし。箱は口を上、蓋は天面を下、クランクはポケットを下、リンクはピン B を上、ピンとクリップは寝かせる。
最初にクランク（約 15 分）を刷り、付属ホーンが入るかを確かめる。入らなければ `HORN_CLR` を 0.05mm ずつ広げる。
