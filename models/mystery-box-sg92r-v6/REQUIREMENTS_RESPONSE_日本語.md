# 追加部材と外形についての親レビュー用回答

修正2で購入追加を必須にした判断を撤回し、修正2を配布保留にします。

| 項目 | 修正2での役割と追加理由 | 修正3での扱い |
|---|---|---|
| 圧縮ばね | 右側面キー13と箱01の偏心ポケットの間で、キーを外へ戻して縦溝へ座らせる。振動による回転解除への指摘に対応するため追加 | 除去。底面の厚い回転キー13が04/05の一体足を捕捉。角形頭と床の肩が押上げ、横棒と足が引抜きを止める。0/90度を広い回転端で制限する |
| 結束バンド | 底の配線出口付近の2ポストへ通し、配線を引張り止めする。配線引張り/擦れへの指摘に対応するため追加 | 結束穴と必須部材指定を除去。滑らかな印刷ガイドで位置と余長を案内する。外から引張られても耐えるクランプとしては設計/実証していない |
| 外側のつまみ | 手で押して回すため側面へ突出し、全体77×70.5×70mmになった | 側面穴と突起を除去。底面キー下面をZ0.2mmへ収め、閉状態の全印刷部品は70mm角内。底面に操作窓/配線溝が残る |

縦方向の捕捉を厚い印刷形状で代替できます。市販のばね・結束バンド・ねじ・金属ピンを新たな必須部材にしません。印刷部品数は19点のままです。サーボ・付属ホーン・電源・配線・任意エキサイター接着は別扱いです。

「ばねで自動的に係止角へ戻る」という動作は削除しました。修正3のキーは手動で90度から0度へ回して係止し、同じ回転を逆に行うと解除できます。回転端は範囲外を止めますが、解除方向の逆回転を自動固定するものではありません。輸送/振動ロックの保証はせず、使用前に底の工具溝がX方向であることを確認します。自動的な逆回転防止まで必要な場合は別の印刷保持具などが必要になり、この19点版では未達です。

配線ガイドも結束クランプと同じ引張り強度を代替したとは主張しません。低力の静置デモとして、余長を確保し線を引っ張らない条件を説明します。外部引張りの耐力は、実ケーブル寸法と印刷保持具の設計・実試験が必要です。

修正3試作・実機未検証です。実印刷・組立・通電・購入・外部投稿は行っていません。今回の親指示により、3分割ZIPと組立画像を既存Library IDへ修正3として更新し、底面キー操作図を新規保存します。保存と最終承認は別で、ユーザーへの受け渡しは親レビュー後です。
