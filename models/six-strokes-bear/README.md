# あと6画のくま (Six Strokes, One Bear)

**ふたりの線で、きもちを描く。**

2人でひとつの公開お題を見ながら、異なる描画能力を組み合わせてクマの気持ちを表現する、
完全協力型の制約付きお絵描きゲーム。片方は **まるを描く人**、もう片方は
**線を描く人**を担当する。

- まるを描く人：まんまるい〇を2つ、自由なだ円を1つ
- 線を描く人：直線を2本、1回だけ折れる折れ線を1本

2人合わせて最大6画で1枚を完成させる。個人得点、対戦相手、秘密役割、秘密目標はない。
完成した絵の巧拙や「正解」を競うのではなく、描く場所と順番の相談、相手の意図の確認、
提案・制止・譲り合い、身振りや指差し、限られた能力の配分を遊びの中心にしている。

## 1ゲームの進行

| 手順 | 目安 | 内容 |
|---:|---:|---|
| 1 | 約30秒 | お題を1枚めくり、まる役・線役と能力トークンを準備 |
| 2 | 3分 | 相談しながら、順番自由でクマを描く |
| 3 | 約30秒 | 完成後、3つの達成条件を確認 |
| 4 | — | 役割とペンを交換し、次のゲームへ |

1ゲームは約4分。相談時間も描画の3分に含めるが、6画を使い切る必要はなく、
2人が完成したと判断した時点で早く終了してよい。

初めて遊ぶときは「眠そうなクマ」を時間制限なしで練習し、その後に難度1から始める。
説明と練習を含む約15分のプレイでは、2ゲームが目安。難度3は4種類の能力に慣れた
2回目以降のプレイ向けとする。

## 描画シート

描画パッドは、同じクマ輪郭を印刷したA4シート30枚で構成する。A5版の約2倍の面積があり、
2人が同時に指差したり、描く場所を相談したりしやすい。輪郭の原画
[`assets/bear_outline_ai_source.png`](assets/bear_outline_ai_source.png) は、この制作時に
組み込み画像生成AIで新規生成したもの。正面を向いて座るクマの薄い輪郭だけを含み、
顔、表情、文字、記号、小物、背景、影、装飾は含めない。

頭、耳、胴体、腕、脚の共通土台だけを与えることで、絵の上手さによる差を抑え、
限られた〇・だ円・直線・折れ線を、表情や状態のどこへ配分するかに集中できる。
すべてのラウンドで同じ輪郭を使うため、シートの種類による有利不利も生じない。

## 詳細ルール

### 1. 準備

1. A4のクマ描画シートを中央へ置く。
2. お題カードを1枚公開し、2人とも内容を確認する。
3. `まるを描く人`（`role_circle`）と`線を描く人`（`role_segment`）を分担する。
4. 各自の役割に対応するペンと能力トークンを受け取る。
5. まる役は〇トークン2個とだ円トークン1個、線役は直線トークン2個と1折トークン1個を、
   役割カードの手前へ並べる。
6. 3分砂時計を開始する。練習では砂時計を使わず、目安2分で進める。

役割カードは描画能力の分担を示す公開情報であり、正体や個別目標を隠すカードではない。
各ゲームの終了後は達成条件を確認し、完成した用紙を脇へ置く。次のゲームでは新しい用紙と
別のお題を出し、能力トークンを対応する役割カードの手前へ戻す。役割カードとペンも交換し、
互いに別の制約を担当してから砂時計を再び開始する。

### 2. 1画と能力トークン

ペン先を紙につけてから、紙から離すまでを1画と数える。描く前に使う能力トークンを選び、
紙に触れた時点でその1個を役割カードの手前から中央へ移す。〇と直線は各2回、
だ円と1折れは各1回だけ使えるため、2人合計で最大6画となる。

同じ役割でも能力枠は交換できない。たとえば、だ円を使わなかったからといって〇を3つ
描いたり、1折れを使わなかったからといって直線を3本描いたりはできない。
すべての能力トークンを使い切る必要はない。

シート下部の小さな記号は能力の種類と回数を示す凡例であり、大きなトークンを載せる
マスではない。

### 3. 〇・だ円・直線・1折れの判定

判定対象は、**その1画で新しく描いた線だけ**とする。

| 能力 | 合法な1画 |
|---|---|
| **まんまるい〇** | 始点と終点がつながる、角のない単純な閉曲線。縦と横が見た目にほぼ同じ。手描きの揺れやわずかなつぶれは許容する |
| **自由なだ円** | 始点と終点がつながる、角のない単純な閉曲線。長い軸と短い軸が見て区別できる。大きさ、向き、縦長・横長は自由 |
| **直線** | 始点から終点まで方向を変えない、1本の開いた線 |
| **1回だけ折れる折れ線** | 2本の直線部分が、1つの明確な角でつながる開いた線。ペンを離さず1画で描く |

共通して、塗りつぶし、自己交差、分岐、なぞり直しは不可。〇とだ円に角をつけること、
直線や折れ線を曲線にすることもできない。1折れは「直線部分が2本、角がちょうど1つ」であり、
角がない線や角が2つ以上ある線はその能力に含まれない。

だ円は縦横比を自由にできるが、見た目がほぼ円なら〇の能力として扱う。〇かだ円か迷う
程度の手描き誤差は、描く前に宣言した能力と2人の合意を優先する。

新しい1画がクマの薄い輪郭、自分や相手が先に描いた線へ触れたり交差したりしてもよい。
既存線と組み合わさって囲まれた領域ができても、新しい1画単体が選んだ能力の条件を
満たしていれば合法とする。

誤って紙へ触れた場合や、描き終えてから違反に気づいた場合も、その線は消さず、宣言した
能力トークンを消費する。やり直しや失格にはせず、何を描こうとしたかを2人で確認して
そのまま続ける。細かな合法・違法で迷ったときは2人の合意を最終裁定とする。

### 4. 描く順番と相談

- 手番順は固定しない。
- 次にどちらが描くかを、2人で自由に相談して決める。
- 同じ人が2回、3回と連続して描いてもよい。
- 会話、提案、確認、指差し、身振り、紙の向きを示す行動はいつでも自由。
- 描こうとした相手を止める、順番を譲る、残り能力を確認して待つこともできる。
- すべての能力トークンを使わずに完成を宣言してよい。

制限時間が終わったらペンを置き、その時点の絵を完成とする。

## 3つの達成条件

各ゲームの完成後、2人で次の条件を確認する。達成数は2人で共有し、個人別には記録しない。

| 達成条件 | 判定 |
|---|---|
| **協力して完成できた** | まる役と線役が、それぞれ1画以上描いて完成させた |
| **余裕をもってクリアできた** | 能力を1つ以上残したまま、2人で完成を宣言できた |
| **お題を当ててもらえた** | 完成した絵を2人以外の人に見せ、お題を当ててもらえた |

満たした条件1つにつき達成トークンを1個置く。近くに第三者がいない場合は
「お題を当ててもらえた」を判定しなくてよい。0〜3個の結果は勝敗ではなく、
今回どんな協力ができたかを振り返るための目印である。

## 4能力の表現バランス

以下は、各お題で4種類すべてに表現余地があることを確認するための設計メモ。
カード面には印刷せず、プレイヤーの解釈を固定しない。1つの候補をそのまま採用する必要もない。

| お題 | まんまるい〇×2 | 自由なだ円×1 | 直線×2 | 1折れ×1 |
|---|---|---|---|---|
| 眠そう | 月、鼻 | あくびの口、まくら | 閉じた両目 | 毛布の上端 |
| 寒そう | 雪玉、服のボタン | マフラーの輪、白い息 | 震えを示す短い印 | 折れたマフラー端 |
| お腹が空いた | 食べ物、鼻 | 皿、開いた口 | 食べ物へ向く視線 | お腹を指す角形の印 |
| びっくりした | 大きな両目 | 開いた口 | 左右の驚き線 | 角のある上がり眉 |
| 待ちくたびれた | 時計、鼻 | ため息の吹き出し | 閉じた目、時計の目盛り | 2方向を示す時計の針 |
| 困っている | 両目、考えの点 | 考えごとの囲み | 左右の困り眉 | への字の口 |
| かまってほしい | ボール、両目 | 呼びかけの吹き出し | 左右の呼びかけ線 | ひじを曲げた腕の印 |
| うれしくてたまらない | 風船、丸い飾り | 大きく開いた笑顔 | 左右の輝き | 上げた腕の角 |
| 何かを隠している | 横目、隠す物 | ポケット、袋 | 横へ向く視線 | 背中へ回す腕の印 |
| こわいのに強がっている | 頬、メダル | 胸の飾り、開いた口 | 強く上げた両眉 | 固く結んだ口元 |
| 気まずそう | 赤らんだ両頬 | 言いよどむ吹き出し | そらした両目 | 固い口元 |
| 仲直りしたいのに言い出せない | 両目、贈り物の印 | 言いかけの吹き出し | 相手へ向く視線 | ためらって伸ばす腕の印 |

## アセット生成パイプライン

```text
assets/bear_outline_ai_source.png
  組み込み画像生成AIで作った、クマ輪郭だけの原画
  ↓

gen_textures.py
  AI原画の輪郭を描画シートへ配置
  カード・シート・ルール面のテクスチャを生成
  → exports/six-strokes-bear/tex/

build_glb.py
  Blenderで実寸の薄板、能力トークン、ペン、砂時計を構築
  → exports/six-strokes-bear/glb/（個別）
  → exports/six-strokes-bear/six-strokes-bear.glb（俯瞰一括）

render_preview.py
  俯瞰GLBと協力プレイ例をレンダリング
  → exports/six-strokes-bear/_preview.png
  → exports/six-strokes-bear/_hero.png
```

実行（model-labルート）：

```bash
python models/six-strokes-bear/gen_textures.py
./run.sh models/six-strokes-bear/build_glb.py
./run.sh models/six-strokes-bear/render_preview.py
```

ビューワー：

```bash
node server.js
# → http://localhost:3000/viewer/six-strokes-bear.html
```

ビューワーでは、全部入りの俯瞰、AI生成クマ輪郭の描画シート、難度別のお題カード、
公開役割カード、4種類の能力トークン、描画道具、達成条件、ルールカードを
グループ別に閲覧できる。

## Unityへの取り込み

- `exports/six-strokes-bear/glb/*.glb` をUnityの `Assets` へドラッグして使用する。
- 俯瞰確認には`exports/six-strokes-bear/six-strokes-bear.glb`、配置や操作には個別GLBを使う。
- Blender / GLBとも単位はメートル。Unityでは `1 unit = 1m` として実寸で揃う。
- テクスチャはGLBへ埋め込む想定のため、基本コンポーネントは単体ファイルで移動できる。
- 紙・カードのX/Y寸法は実寸だが、Z方向の厚みは視認性のため誇張している。
- ランタイム読込にはglTF対応ローダー、エディタ取込にはglTFastまたはUnityGLTFを利用できる。

## 対象年齢と安全

- 対象年齢は **8歳以上**。
- 3歳未満向けではない。トークン、ペン部品、砂時計などを口に入れない。
- トークンの最小外形は約30mmだが、誤飲防止規格への適合を保証する製造図面ではない。
- 実物化する場合は、年齢に適した非毒性インクのペン、角を処理したカード、
  破損時に内容物が露出しにくい砂時計を選ぶ。
- GLBは可視化・Unity取込用のモデルであり、そのまま玩具安全認証や量産仕様を満たすものではない。

## 初版に含めないもの

- 個人得点、勝敗、プレイヤー同士の対立要素
- 秘密役割、秘密目標、片方だけがお題を見るルール
- 第三者、アプリ、AI画像認識による正誤判定
- お題カード上の正解絵、推奨構図、表現例
- クマ以外のキャラクター輪郭、追加お題、上級者向け制約
- オンライン対戦、ランキング、キャンペーン
- 専用収納箱、カードトレイなどのパッケージ部品

初版は、公開された共通お題、2つの公開役割、6つの能力枠、役割交換、3つの達成条件という
完全協力型の核だけを収録する。
