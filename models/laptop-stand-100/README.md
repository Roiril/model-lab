# laptop-stand-100

横400 × 奥行330 mm程度のノートPCを水平に100 mm持ち上げるスタンド。
左右に同じフレームを1本ずつ置く。接合や工具は不要。
中央を空けて放熱しやすくした。各部の角を丸めてある。
設計荷重はPC全体で4 kg。印刷品の実測耐荷重ではない。

## 寸法

| 項目 | 値 |
|---|---|
| 想定PCの幅 × 奥行 | 約400 × 330 mm |
| PCを支える高さ | 上下各1 mmのパッド込み100 mm |
| 使用配置の外形 W × D × H | 346 × 245 × 100 mm。パッド込み |
| 印刷する1部品の使用姿勢 | 26 × 245 × 98 mm |
| 左右中心間 | 320 mm |
| 上の梁 | 厚さ16 mm |
| 下の梁 | 厚さ7 mm |
| 前後の柱 | 厚さ18 mm |
| 外側の角 | 半径5 mm |
| 内側の角 | 半径8 mm |
| 側面の縁 | 0.8 mmの面取り |

幅400 mmのPCを中央に置くと左右の張り出しは各27 mm。
奥行330 mmの場合は前後各42.5 mmが張り出す。
底面の丈夫な部分やゴム足を支えるよう左右位置を合わせる。
吸気口と排気口と薄い底面カバーへパッドを当てない。
機種が未指定のため実機の足位置と通気口との適合は未確認。

## 印刷

`exports/laptop-stand-100/frame.stl` を2回印刷する。単位は mm。
側面を下にした姿勢を保存してある。左右の部品は同形状。
`exports/laptop-stand-100.stl` は左右を配置した表示用。
表示用STLをそのまま印刷する用途は想定していない。

| 設定 | 開始値 |
|---|---|
| 材料 | PETG |
| ノズル | 0.4 mm |
| 積層高さ | 0.2 mm |
| 外周 | 5周 |
| 上下面 | 各6層 |
| 内部充填 | 100%。荷重計算は中まで詰める前提 |
| サポート | 無しを想定 |
| ブリム | 4 mm |

印刷姿勢の実外形は約238.40 × 238.40 × 26 mm。
4 mmブリムを含む印刷面は約246.40 mm角。256 mm角の造形範囲を想定。
積層方向は完成時の左右方向。梁の曲げを造形面内で受ける。
PCが発する熱を考慮してPETGを開始材とした。
[PrusaのPETG資料](https://help.prusa3d.com/article/petg_2059)を参照。
温度と冷却と印刷面の処理は材料とプリンターの指定に合わせる。

1個の形状体積は216.81 cm³。2個で433.61 cm³。
PETG密度1.27 g/cm³の換算では2個で約551 g。
ブリムと印刷開始時の排出分は含まない。スライサーの使用量は未確認。

## パッドと使用前の確認

上下へ24 × 45 × 1 mmの保護兼滑り止めを貼る。1本につき上2枚と下2枚。
前のパッドは前端から8〜53 mm。後ろは192〜237 mm。
机の上では左右中心を320 mm離す。底面の支えられる場所に合わせて微調整する。
実機の重心が左右の支えと前後のパッドの間に収まるよう置く。
平らな机で同じ高さにそろえる。滑りと片側の浮きを確認する。
初回は実機を載せる前に4 kgの試験荷重でたわみと24時間後の変形を確認する。
画面を開いた状態でも接触と安定を確認する。熱による変形も使用中に確認する。
ノートPCの底面剛性と材料の長期変形と机との摩擦は未測定。

## 荷重計算と検証

上梁を長さ209 mmの単純支持梁として計算した。断面は26 × 16 mm。
弾性率1000 MPaと曲げ応力の判断値5 MPaを仮定した。
これらは計算条件。使用するPETGと印刷品の測定値ではない。
片側1本へ4 kgを中央集中で載せる厳しい条件のたわみ概算は0.84 mm。
さらに20 Nの下向き操作を加える条件では約1.27 mm。曲げ応力は約2.79 MPa。
梁の破断荷重や長期のたわみを保証する計算ではない。

3 kgと4 kgのPCで左右±30 mmと前後±60 mmの重心ずれを仮定した。
PCの四隅へ20 Nの下向き操作を加える32条件を調べた。
合成荷重の位置はパッドの接地範囲内。最小余裕は約21.1 mm。
この検査は仮定の静荷重のみ。画面を横から押す力や衝撃は含まない。

STLのバイナリを直接読む。正常形状と異常形状で検査を先に校正する。
各部品は閉じた一部品。配置済みの表示モデルは閉じた部品2個として検査する。
印刷姿勢を逆変換して寸法と体積を照合する。肉厚とパッドの接地面も検査する。
床以外の下向き面で45.5度を超える箇所は0。最大値は約45.0001度。
結果は `exports/laptop-stand-100/verification.json` に保存する。
