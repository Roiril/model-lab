# laptop-stand-100

横400 × 奥行330 mm程度のノートPCを水平に100 mm持ち上げるスタンド。
左右に同じ支えを1組ずつ置く。上のフレームを広い底部へ差し込む。
工具は不要。底部へ向かって滑らかに広がる曲面にした。
中央を空けて放熱しやすくした。各部の角を丸めてある。
設計荷重はPC全体で4 kg。印刷品の実測耐荷重ではない。

| 使用配置の外形 W × D × H | 420 × 275 × 100 mm。パッド込み |
| フレーム1個の使用姿勢 | 26 × 245 × 94 mm |
| 底部1個の使用姿勢 | 100 × 275 × 22 mm |
| 左右中心間 | 320 mm |
| 上の梁 | 厚さ16 mm |
| 下の梁 | 厚さ7 mm |
| 前後の柱 | 厚さ18 mm |
| フレーム外側の角 | 半径12 mm |
| フレーム内側の角 | 半径20 mm |
| 底部外側の角 | 最大半径30 mm |
| 底部の床厚 | 4 mm |
| 差し込みの深さ | 18 mm |
| 差し込みの隙間 | 片側0.25 mm |
| 溝入口の面取り | 0.5 mm |
| 側面の縁 | 0.8 mmの面取り |

幅400 mmのPCを中央に置くと上の支えから左右各27 mmが張り出す。
底部はPCより左右各10 mm外側まで広がる。
奥行330 mmの場合は底部から前後各27.5 mmが張り出す。
底面の丈夫な部分やゴム足を支えるよう左右位置を合わせる。
吸気口と排気口と薄い底面カバーへパッドを当てない。
機種が未指定のため実機の足位置と通気口との適合は未確認。

## 印刷

`exports/laptop-stand-100/frame.stl` と `foot.stl` を各2個印刷する。
合計4部品。単位は mm。左右の部品は同形状。
フレームは側面を下へ向ける。底部は底面を下へ向ける。
それぞれ印刷面内で45度回した姿勢を保存してある。
`exports/laptop-stand-100.stl` は4部品を組み立てた表示用。
表示用STLをそのまま印刷する用途は想定していない。

| 設定 | 開始値 |
|---|---|
| 材料 | PETG |
| ノズル | 0.4 mm |
| 積層高さ | 0.2 mm |
| 外周 | 5周 |
| 上下面 | 各6層 |
| 内部充填 | 100%。荷重計算は中まで詰める前提 |
| サポート | 無しを想定 |
| ブリム | 4 mm |

フレームの印刷外形は約229.77 × 229.77 × 26 mm。
底部の印刷外形は約240.31 × 240.31 × 22 mm。
4 mmブリム込みで最大248.31 mm角。256 mm角の造形範囲を想定。
フレームの積層方向は完成時の左右方向。梁の曲げを造形面内で受ける。
底部を分けることで広い裾の下にサポートを入れずに印刷できる。
PCが発する熱を考慮してPETGを開始材とした。
[PrusaのPETG資料](https://help.prusa3d.com/article/petg_2059)を参照。
温度と冷却と印刷面の処理は材料とプリンターの指定に合わせる。

フレーム1個の形状体積は217.93 cm³。底部1個は280.52 cm³。
4部品で996.91 cm³。PETG密度1.27 g/cm³の換算では約1,266 g。
広い底部を追加したため前版より材料が増える。
ブリムと印刷開始時の排出分は含まない。スライサーの使用量は未確認。

## パッドと使用前の確認

上へ24 × 45 × 1 mmの保護パッドを貼る。底へ92 × 35 × 1 mmの滑り止めを貼る。
片側につき上2枚と下2枚。全体では8枚。
上のパッドはフレーム前端から16〜61 mmと184〜229 mm。
下のパッドはフレーム前端と同じ基準で3〜38 mmと207〜242 mm。
底部の前端から測る場合は18〜53 mmと222〜257 mm。
フレームを溝の床まで差し込む。床から上梁までを圧縮で支える。
隙間による理論上の傾きは最大約1.6度。実機のガタは未確認。
ガタがあれば0.2 mm程度のPETシートを溝の両側へ入れて調整する。
シートは別途用意する。底まで入ることと容易に外せることを確認する。
机の上では左右中心を320 mm離す。PC底面を支えられる場所に合わせる。
実機の重心が左右の支えと前後のパッドの間に収まるよう置く。
平らな机で同じ高さにそろえる。滑りと片側の浮きを確認する。
初回は実機を載せる前に4 kgの試験荷重でたわみと24時間後の変形を確認する。
画面を開いた状態でも接触と安定を確認する。熱による変形も使用中に確認する。
ノートPCの底面剛性と材料の長期変形と机との摩擦は未測定。

## 荷重計算と検証

上梁を長さ209 mmの単純支持梁として計算した。断面は26 × 16 mm。
弾性率1000 MPaと曲げ応力の判断値5 MPaを仮定した。
これらは計算条件。使用するPETGと印刷品の測定値ではない。
片側1本へ4 kgを中央集中で載せる厳しい条件のたわみ概算は0.84 mm。
さらに20 Nの下向き操作を加える条件では約1.27 mm。曲げ応力は約2.79 MPa。
梁の破断荷重や長期のたわみを保証する計算ではない。

3 kgと4 kgのPCで左右±30 mmと前後±60 mmの重心ずれを仮定した。
PCの四隅へ20 Nの下向き操作を加える32条件を調べた。
合成荷重の位置はパッドの接地範囲内。最小余裕は約36.6 mm。
全体の接地範囲を囲む面積は前版より約25.2%増加した。
左右の支えがPCへ同時に接触することと滑らないことを前提とする。
高さ125 mmの本体へ10 Nの水平力を加える32条件の最小余裕は約46.4 mm。
片側ずつ5 Nを受ける8条件も検査した。軽い側の荷重も重心ずれから計算した。
置き方と溝のガタへ3 mmの余裕を引いた後の最小余裕は約7.6 mm。
横方向の計算と下向き操作の計算は別条件。自重は充填100%の体積換算値。
画面の高さで押す力と力の片側集中と衝撃は含まない。
材料強度と長期変形と摩擦は実物で確認する必要がある。
