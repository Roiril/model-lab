# 住人の箱 D1

閉じた外形は80 × 80 × 80mm。六面に角丸と貫通穴を設けない。SG92Rと4節リンクで天面を0〜65°開く。後ろ側には固定天面がある。D1は広い蓋。D2は前側の蓋。D1はC1の全面蓋とは異なる。

Studio: http://localhost:3000/?model=mystery-box-sg92r-d1

## 要件と寸法

- 外装の壁と底は3mm。天面は基本3mm。蝶番の上の逃げだけ最薄1.2mm。
- 蝶番は外装内に収める。ピンは箱の外で組み付ける。外面に組立穴を作らない。
- サーボ位置と4節リンクはC1を基にする。SG92Rの寸法を正本からimportする。
- 固定天面と可動天面の境目は内部で円弧にする。閉じた外面は平ら。可動のための継ぎ目は残る。
- 配線口は設けない。電源と制御基板は箱の中へ置く前提。搭載製品と保持形状は未確定。
- 開閉時間は1.2秒。始めと終わりをゆっくりにする。閉位置より先へ押し込まない。

## 部品

印刷部品はbox、lid、roof、crank、link、pin、clip、speaker_clipの8点。

| 部品 | 役割 |
|---|---|
| box | 外箱。サーボ台とホーンの受けを含む |
| lid | 動く天面。内側へ回り込む腕と蝶番を含む |
| roof | 後ろの固定天面。内側の爪で外箱へ留める |
| crank | SG92Rの付属ホーンを包む |
| link | サーボから蓋へ力を伝える |
| pin | 外から見えない蝶番ピン |
| clip | サーボを台へ押さえる |
| speaker_clip | エキサイターを右壁へ押さえる |

既製品はSG92Rと付属クロスホーン。Cと同じエキサイター用の保持部を残す。エキサイターは直径25mmと高さ10mmの仮寸法。型番と接触面は未確定。ねじと接着剤は使わない。

## 組み立て

1. roofを付ける前に、単独のlidへリンクのピンBを鍵溝から通す。蓋75°相当の向きでリンクを回して爪を掛ける。
2. クランクのピンAへリンクを通す。鍵溝から外れる向きへ回す。
3. 蓋を65°相当の姿勢へ戻す。箱の外でlidとroofの蝶番を合わせる。右からpinを通す。
4. 蓋を65°開いた姿勢にする。サーボを電気的な中央90°へ動かす。その姿勢で付属ホーンとクランクを合わせる。
5. 蓋を開き、天面とサーボの一式を上から外箱へ下ろす。配線は可動部から離して内側へ折り返す。
6. clipを上から差してサーボを留める。
7. roofの内側の爪を掛ける。外すときは蓋を開け、内側のつまみで解除する。
8. 閉じる角度を1°ずつ探す。蓋が縁に触れた位置を閉位置とする。

経路の計算結果はbuild/verify_report.jsonのassemblyを見る。SG92Rのスプラインは18°刻みなので最後はソフトの角度で合わせる。slow_open/slow_open.inoは65°開いた姿勢でサーボ90°に合わせる設定。oで開く。cで閉じる。mで中間へ動く。<と>で1°ずつ合わせる。電源断時の摩擦保持は保証しない。開いた蓋は自重で動く可能性がある。

蝶番はCから9mm上げて高さ74mmにした。リンクBの閉位置とサーボ位置は維持した。蓋の腕を下へ回して固定天面を避ける。既製SG92R軸とホーンの相互嵌合は検証対象外。参照メッシュの交差体積が計算順序で変わるため診断値を記録した。印刷部品との干渉は除外せず検査する。

サーボ押さえの幅は5.15mm。取付耳の柵との隙間は0.40mm。A継手の鍵角はCと同じ75°。引き抜き時の接触を開閉27姿勢で調べる。丸軸の残り長さも記録する。

## 印刷

X1C。ノズル0.4mm。基本層厚0.2mm。PLAを先に合わせる。PETGは穴と爪の固さを再確認する。

外箱は底を下。lidとroofは外面を下。クランクとリンクは平らに寝かせる。ピンは削った平面を下にする。サポートは外から見えない蝶番の裏面に限定する。実際の必要箇所と使用量はスライス結果で確認する。

prints/mystery-box-sg92r-d1/ に部品別STLとプレートを保存する。形状変更後は必ずスライスをやり直す。manifestのハッシュと現行STLが一致することを確認する。

最終プレートの見積もりはPLA 2時間56分30秒・142.36g。PETG 3時間17分46秒・136.91g。クランク試片は約14.7分。継手試片は約10.7分。スピーカー試片は約32分で15分の目安を超える。

サポートは蓋の内側に限定した。箱の内部には最大6.1mmの短い渡りが残る。サポートを使った部分は解析器の未支持量に含まれるため、実G-codeのサポート位置を別に測定した。build/print_review.jsonに数値と検査の限界を保存した。

## 実物で確かめること

SG92Rの正本で未実測の値は、ホーンの長腕左右18/16mm、ギアカバー径12mm、出力軸高3.5mm、ホーン穴の位置と径、ソケット形状、配線の太さと出口高さ。正本READMEを参照する。D1はC1と同じ寸法を使う。C1の実物成功はD1全体の組立成功を保証しない。

最初にcrank単体を刷ってホーンの向きを合わせる。固ければHORN_CLRを0.05mm刻みで広げる。次にピンとリンクの接合試片を試す。HINGE_HOLE_LID_DとPIN_HOLE_Rを0.05mm刻みで調整する。最後に固定天面の爪を試す。ROOF_HOOKとROOF_PRESS_DELTAを調整する。

## ビルドと検証

Blenderは C:/Program Files/Blender Foundation/Blender 5.1/blender.exe 。model.pyとverify.pyはBlenderのbackground実行。simulate.py、plate.py、slice_check.py、deliver.py、export_web.pyはpy -3.11で実行する。render_preview.pyはBlenderで実行する。

順序はmodel → verify → simulate → render_preview → plate/slice_check → deliver → export_web。最後にnode tools/catalog.js checkを実行する。詳細の機械検査はbuild内JSONとreportsのHTMLに残る。

最終検査は8部品の閉じたメッシュを確認。六面38318点が通過。27姿勢・999組の干渉は0件。組立経路は55/55項目が通過。納品24ファイルのSHA-256が一致。ファームウェアの実コンパイルと実機書込みは未確認。
