# 旗が起き上がる箱

閉じた外形は 68 × 68 × 68mm。旗の板は 15 × 35 × 3mm。SG92R 1台で0度から90度まで起こす。
起こした旗は箱の外へ出る。90度で全高83mm。途中の最大高さは約88.3mm。

## 部品と刷る向き

| 部品 | 個数 | 印刷姿勢 |
|---|---:|---|
| `box.stl` 箱 | 1 | 底をベッドへ。天面を開けた向き |
| `roof.stl` 天板 | 1 | 外から見える天面をベッドへ |
| `flag.stl` 旗とホーン受け | 1 | 円板の平らな面をベッドへ。ホーンのくぼみを上へ |
| `bearing_button.stl` 軸受けボタン | 1 | 大きい頭をベッドへ |
| `key_left.stl` 左の留め具 | 1 | 平らな面をベッドへ。二本の腕は層に沿って曲がる |
| `key_right.stl` 右の留め具 | 1 | 同上 |
| SG92R | 1 | 既製部品。印刷しない |
| 付属クロスホーン | 1 | 既製部品。印刷しない |

ねじを使わない。接着剤と結束バンドも使わない。
本体の壁と天板は3mm。天板の留め具を受ける脚は4mm。
留め具の弾性腕だけは厚さ1.2mm。設計撓み0.3mm。自由長5.75mmとして表面ひずみは1.6333%。
腕厚1.2mmは共通条件の下限。印刷誤差の余裕はない。試片で割れと薄肉の欠けを先に確かめる。

## 組み立て

座標と向きは `build/assembly.json` と専用プレビューで確認できる。

1. SG92Rを外部の角度信号で中央の90度にする。作業中は負荷をかけない。
2. ホーンの長い18mm側を確認する。プレビューの「ホーンを押し込む」と同じ45度の姿勢でスプラインへ付ける。
3. 旗を45度に保持する。十字のくぼみをホーンへ軸方向から差す。180度逆には付けない。
4. 六角の軸受けボタンを旗の外側から差す。
5. 箱を底面を下にして置く。サーボ一式を上から座へ下ろす。取付耳を溝へ入れる。
6. 配線を箱の後ろへ逃がす。コネクタを穴へ通さず、線だけを上開きの切欠きへ置く。
7. 天板の軸受けをボタンへかぶせる。天板を垂直に下ろす。
8. 左右の側面窓から留め具を差す。頭が外面より内側に収まるまで指で押す。
9. 旗を2秒かけて寝かせる。基準の指令角45度が旗の0度。135度が旗の90度。

スプラインの刻みのずれは実機で角度信号を補正する。45度と135度は基準値。
初回は低速で両端を合わせる。接触した位置へサーボを押し続けない。
分解は電源を切って左右の留め具を指で引き、天板を上へ外す。続きは逆順。
留め具の頭の周囲に指を掛ける窓がある。爪の着脱力と繰り返し寿命は実物で未確認。

## 動かし方と力

0度から90度まで2秒。軌道は `build/trajectory.csv`。
始めと終わりの角速度と角加速度を0にする五次曲線を使う。
2秒の移動で最大角速度84.375度/秒。SG92Rの電源と角度信号は箱の外から供給する。
電源を切った位置の保持は保証しない。減速機の摩擦次第で旗が自重で動く可能性がある。

`build/physics_report.json` は中実PLAの体積積分による重心と慣性を使う補助計算。
10mm立方体の体積と慣性で校正する。これはmechgateの代わりにはしない。
ホーンも密度1240kg/m³と仮定した。実物のホーン重量と軸受け摩擦は未測定。
重力と慣性に加えて0.01N·mの抵抗を仮定しても必要トルクは約0.01034N·m。
停動トルクの1/3にあたる0.08167N·mを下回る。
0.01N·mを受けの半径14mmで伝えると接線力は約0.72N。
ホーンから旗の片側の遊びは計測例1.718度。旗からボタンは4.211度。直列に足すとボタンの角度には約5.929度の遊びがある。
旗の角度に関わる印刷部品側の遊びは前者。サーボ本体の歯車の遊びは含まない。
軸方向の保持はボタンと箱が0.500mm、ボタンと天板が0.250mmで接触する。
旗の盲穴底の0.250mmも足した最悪の外向き移動は約0.750mm。スプラインの嵌合長3mmより小さい。

## 嵌め合いと未確認寸法

SG92Rとホーンの寸法は `models/sg92r-photo/params.py` をimportする。
参照メッシュも同モデルの関数定義から作る。正本のスクリプトの出力処理は実行しない。
耳の溝は実物成功値の片側0.25mm。ホーンのポケットも片側0.25mm。
ホーンの腕穴を使わない。スプラインを印刷しない。
配線の切欠きは幅14mm。上へ開いているのでコネクタの寸法に嵌合しない。

先に `flag-box-fit-PLA.gcode.3mf` を刷る。ホーン受けとサーボ座の試片を含む。
ボタンと右の留め具も同じプレートにある。試片は本体と同じ形状から切り出している。
ホーン受けがきつければ `HORN_FIT` を0.05mmずつ増やす。
サーボ座がきつければ `FIT` を0.05mmずつ増やす。
軸高とカバー径は正本でも仮値が残る。試片が通るまで本体の実物適合は未確認。

判定の正本は `build/gate_report.json` と `build/gate_summary.md`。

最終判定はmechgateの終了コードで確認する。

`plate.py` はX1C標準プロファイルの継承を展開する。

サポートは使わない。全6部品を1枚に配置する。重なりとはみ出しと除外域を検査する。
本体は2時間9分。材料106.46g。試し刷りは31分43秒。材料15.28g。
配置とスライスの数値は `build/flag-box-PLA-slice.json`。
内部の橋渡しと充填は外周の支えなし判定から分けている。
見える面の仕上がりは計算だけでは確定しない。試し刷り後の目視を残す。

## 決めたことと譲ったこと

小さな旗を直結で動かす。複数リンクを使わず、取り外せる留め具を含め印刷6部品にした。
旗の天面からの持ち上がりを増やすため、回転中心を後ろへ8mm寄せた。
天板には16.1 × 57mmの開口が残る。閉じた状態でも受けとサーボの一部が見える。
70mm以下は閉じた箱の外形に適用した。起立時は旗がその外へ出る。
通常のStudio登録とexportsへの出力は今回の変更境界に含めない。確認用HTMLをprints内に置く。

## 実物で確かめる順番

1. ホーン受け試片を既製ホーンへ合わせる。左右の向きと腕長を確認する。
2. サーボ座試片へ本体と取付耳を下ろす。軸高とギアカバーの隙間を確認する。
3. 本体を組む。留め具を工具なしで着脱できることを確認する。
4. 配線を逃がして低速で0度と90度を合わせる。保持と摩擦を確認する。
5. 天面と旗の見える面を確認する。3回着脱して割れと永久変形を確認する。

実際の印刷と実機の駆動はこの作業では実施していない。
コマンドは起動中のBlenderへ接続しない。このブランチからpushしない。
専用プレビューのブラウザーによる目視は未確認。CUAに利用できるブラウザーが無い。
形状はBlenderのバックグラウンド描画で確認している。
