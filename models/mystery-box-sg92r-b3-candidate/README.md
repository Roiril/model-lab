# 住人の箱 B3-integrated-3

試験片から進める設計・印刷用候補。70 mm角、SG92R、主機構22点。実物未検証。

まず B3_print_assembly_guide.html をブラウザーで開いてください。STLはmm。
印刷 stl/、段階的試験片 coupons/、200 mm級の配置 plates/。
編集原本 editable_cube_B3.blend（Blender5.1.1）。params.py と model.py から再構築可能。
旧版の底パーツと混ぜないでください。20/22の押上げは共に1.8 mmです。
付属ホーン使用、独自スプラインや無理な圧入は不可。

G-codeは収録せず、実機に合わせて再スライスします。診断設定JSONはユーザープリンター指定ではありません。
