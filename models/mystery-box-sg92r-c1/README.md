# 住人の箱 C1・70mm 全面蓋

SG92R 1個と4節リンクで70mm角の箱の全面蓋を0〜65°開閉する。印刷部品は7点。工具なしで組んで外す構成にした。ねじと結束バンドと接着剤は使わない。実物の嵌まりと強度は未確認。

Studio: http://localhost:3000/?model=mystery-box-sg92r-c1

検証レポート: `reports/2026-10-10_mystery-box-c1.html`

## 部品

印刷する部品:

| 部品 | 役割 |
|---|---|
| `box` | 70mm角の箱。サーボ台、クランク受け、エキサイターレールを含む |
| `lid` | 全面蓋。中央にリンクのピンBを受ける耳がある |
| `crank` | 付属ホーンを包み、サーボの回転をリンクへ伝える |

| `speaker_clip` | エキサイターをレールへ押さえる |

既製部品:

- SG92R本体、付属ホーン、配線。寸法の正本は `models/sg92r-photo/`

## 形と機構

- 閉じた外形は70 × 70 × 70mm。外装の壁と底は3mm
- 蝶番軸HはY=-30mm、Z=65mm。サーボ軸OはY=3mm、Z=30.6mm
- クランク長は24.6mm。閉じたときのクランク角は222.6°。リンク長は38.7516mm
- 蓋32.5°を中央姿勢とする。この姿勢でサーボを90°にしてホーンを取り付ける
- 中央から閉じる側は+29.6°相当。開く側は-24.0°相当。全体の使用角は約53.7°
- リンクのピンAはバヨネットで抜けを止める。ピンBはリンク先を3.4mm曲げて蓋の耳へ入れる
- サーボとエキサイターは別々の印刷クリップで留める。接着剤を使わない

## 組み立て

C1は蓋を先に付けると、サーボ一式が途中で蓋に当たる。旧80mm版と順番を変え、サーボを先に入れる。

1. エキサイターを上からレールへ入れる。`speaker_clip` を上から差して留める
2. 箱の外でサーボを90°にする。蓋32.5°の姿勢に合う向きでホーンを付け、クランクをかぶせる
3. リンクの切り欠きをピンAの爪に合わせて差し、動作位置まで回す
4. 蓋のない箱へサーボ一式を上から下ろす。クランクの軸を受けへ入れ、配線を台の切り欠きへ通す
5. `clip` を上から押し込み、サーボを留める
6. 蓋を125°開いた姿勢にする。箱の40mm上から下ろし、蝶番の節をそろえる
7. 蝶番ピンを右から入れる。抜くときは左端を押し、右へ出た端をつまむ
8. リンクの先を3.4mm曲げる。蓋を125°から32.5°へ下ろし、ピンBを蓋の耳の穴へ入れて離す
9. サーボを閉じる側へ1°ずつ動かす。蓋が縁に載った位置を「閉」とする

開閉には1.2秒かけ、始めと終わりをゆっくり動かす。実物の衝撃を見て時間を調整する。「閉」より先へ押し込まない。

## 刷る向き

| 部品 | 向き | サポート |
|---|---|---|
| 箱 | 口を上。後ろ面をプレートの奥へ向ける | なし |
| 蓋 | 外から見える天面を下 | なし |
| クランク | ホーンのポケットを下 | なし |
| リンク | 平らに寝かせる | なし |
| 蝶番ピン | 平らな面を下にして寝かせる | なし |
| サーボ押さえ | 横に寝かせる | なし |
| スピーカー押さえ | 平らに寝かせる | なし |

PLAとPETGの全7部品を1枚のプレートへ置く。X1Cの0.4mmノズル用。部品間を6mm空ける。箱の蝶番付近と蓋の蝶番付近だけ積層を0.08mmにする。他は0.2mm。スライサーのサポート使用量は両材料とも0。穴の天井と内部の溝には橋渡しが残る。G-code上の支えがない経路長は `build/slice_report.json` に記録した。実印刷の成功を表す値ではない。

完成ファイルは `prints/mystery-box-sg92r-c1/`。PLA用とPETG用の `gcode.3mf` を含む。先に試すPLAプレートは3種類。

- `crank-test-PLA`: ホーンを包むクランク。約15分。
- `joints-test-PLA`: リンク。蝶番ピン。サーボ押さえ。約15分。
- `speaker-test-PLA`: エキサイター保持部の切り出しと押さえ。約32分。

印刷時間はスライサーの推定値。ファイルのSHA256と配置は `manifest.json` にある。

## Arduinoの開閉例

`slow_open/slow_open.ino` を使う。サーボ信号はD9。サーボ用の5V電源とArduinoのGNDを共通にする。起動時は90°。箱の外でこの位置へ合わせて組む。シリアル入力の `o` は開く。`c` は閉じる。`m` は90°。`<` と `>` は1°ずつ調整する。

例の閉119°と開66°は計算上の目安。付属ホーンの歯は18°ごとの位置になるため実物では端の角度を合わせ直す。箱の縁へ押し続ける角度を使わない。実機での動作とArduinoのコンパイルは未確認。

## 要件ごとの結果

- 外形: 70mm角の全面蓋。蓋は0〜65°
- 印刷: 7部品を1枚へ配置する。見える面にサポートを付けない
- 組み立て: 印刷部品と指定した既製部品だけを使う。工具、ねじ、接着剤は使わない
- 分解: サーボ押さえとスピーカー押さえを外せる。蝶番ピンは押し出してつまめる
- 動作: 0〜65°の全範囲を2.5°以下の刻みで検証する。1.2秒の滑らかな開閉を推奨する
- 配線: サーボの配線を台の切り欠きから後ろの出口へ通す
- 音: エキサイターの包絡寸法だけ確認した。保持力、音量、びびりは未検証

## 決めたこと

- 全面蓋を採用した。部品数と組み立ての確実さを優先した
- 蓋32.5°をサーボ90°へ合わせる中央姿勢にした。閉じる側と開く側の余裕を分けるため
- エキサイターは上からレールへ入れる。接着剤を使わず、交換できるようにするため
- 動作時間は1.2秒から始める。実物で端の衝撃を確認して変更する。定数は `OPEN_TIME_S`

## 譲ったこと

- 旧版の分割天面と隠れた蝶番は残していない。工具なしで組めること、部品を減らすこと、サポートなしで刷ることを優先した
- 全面蓋を開くとサーボとリンクが見える
- エキサイターの製品形状は確定していない。直径25mm、高さ10mmの包絡寸法で場所だけ確保した
- 蝶番ピンの端を押すため後ろの両角に小さなくぼみがある。外形の70mm角は維持した
- 外装の壁は3mm。蝶番穴の天井は最小1.7mm。レールの爪受けは最小1.3mm。リンクは3mm
- リンクの曲げでは両端の太い部分を除く27.75mmを長さとして計算した。3.4mm曲げたときの推定ひずみは1.99%。2%の目安に近い。試験プレートで白化と割れを確かめてから全体を刷る

## 実物で確かめること

1. クランクだけを先に刷り、付属ホーンが入るか確かめる。固い場合は `HORN_CLR` を0.05mmずつ広げる
2. 蝶番ピン、リンクのバヨネット、二つの押さえを試す。割れ、抜け、手で外せるかを見る
3. エキサイターの接触面と保持力を確かめる。音量とびびりを実際に鳴らして確かめる
4. 全体を組み、0〜65°で当たらないかを見る。電源を切ったときの蓋の動きも見る
5. 1.2秒の開閉で端の衝撃を見る。強い場合は `OPEN_TIME_S` を延ばす

全7部品の推定印刷時間はPLA約2.55時間。PETG約3.12時間。使用量はPLA105.49g。PETG101.46g。動作27姿勢の意図しない接触は0。組み立て中の意図した圧入と曲げは別に記録した。リンクは動作3姿勢とも約1.25mm引くと爪へ当たる。鍵溝に向きを合わせた経路では7.5mmまで引いても当たらない。
