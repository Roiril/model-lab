# SG92R サーボとホーン（写真寸法）

ユーザー提供写真 `92-1.png` と `92-2.png` を基にした確認用モデルです。追加の上面写真 `PXL_20261007_091023165.jpg` と、全長14 mmを記入した訂正画像も反映しています。共有の `servo_core` には値を書き戻しません。

## 寸法の出典

写真の本体長は23 mmです。ケース上面の高さは16 + 2 + 4 = 22 mmです。取付耳の全長は32 mmです。耳の厚みは2 mmです。上面カバーの全長は、ユーザーの訂正画像に基づき従来の19 mmから14 mmへ訂正しました。細い部分の幅4 mmは追加の上面写真の寸法です。円形部分φ12 mmは、本体奥行12 mmと写真の比率からの推定です。カバーの高さは5 mmです。ホーンは34 × 17 mmです。ギアカバー上面からホーン上面までの5 mmを加え、全高は32 mmです。

奥行12 mmとホーンの腕厚1.5 mmは、今回のユーザー指定です。

既存個体の計測値は軸径4.6 mmです。軸中心は本体中心から5 mmずれています。取付穴ピッチは28.84 mmです。追加写真から取付穴径2 mmと、最寄りの外端へ開く幅1 mmの直線溝を反映しました。取付耳は32 × 12 mmの矩形です。

写真で決められないため仮置きした値はセンター穴径2.4 mmです。腕穴径は1 mmです。穴の中心位置と左右の長さ配分も写真の比率からの推定です。出力軸の高さ3.5 mmはホーン位置に合わせた仮値です。軸用ソケットは径4.6 mmの円筒です。実物のスプライン歯は再現していません。

配線の全幅4 mmと、軸に近い+X側から出る向きは追加写真に基づきます。配線は本体と別の閉じた部品です。表示長8 mm、1本の直径1.6 mm、出口中心高さZ=5 mmは仮置きです。実物の線全長、厚み、出口高さは未確定です。

## 座標と外形

出力軸を XY 原点にしています。本体中心は X=-5 mmです。取付耳と取付穴も本体中心を基準に配置しました。この関係を保つと、ホーンを含む組立外形は 37 × 17 × 32 mmです。指定の 34 mm幅はホーン単体のX寸法です。取付耳を軸中心へ移すと左側の取付穴がケースへ食い込むため採用していません。

出力は本体の `sg92r-photo-body.stl`、ホーンの `sg92r-photo-horn.stl`、配線の `sg92r-photo-wire.stl` です。組立は3部品を含む `sg92r-photo.stl` です。Blenderの編集用ファイルも同名で保存します。

STLを保存した後は `verify_stl.py` で直接読み取ります。閉じた四面体と面を欠いた四面体で検査を校正します。外形と断面寸法を検査します。腕厚1.5 mmと耳厚2 mmも検査します。ホーンの腕穴17個と中心穴の通り道を確認します。結果は `exports/sg92r-photo-verification.json` へ保存します。
