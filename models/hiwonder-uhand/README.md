# Hiwonder uHand 再現（表示用）

Hiwonder の 5 本指ハンド uHand（LFD-01 サーボ 6 個）を、寸法図と写真から再現した形。印刷用ではない。
資料は `ref/uhand参考資料/`（git 管理外）。中身と要点は同じフォルダの `INDEX.md`。

## 寸法の出し方（2026-11-10 に全面的に読み直した）

`params.py` は実寸の mm。正本は寸法図（`02_寸法図_拡大.png`）の正面と側面。

- 縮尺は 0.3853 mm/px。全高 174mm の寸法線が入った 01 と、拡大版の 02 で同じ線（指先の上端・手のひらの下端・台座の上面）の行を拾って求めた
- 正面は `x = (列 - 146.5) * 0.3853`、`z = (454.5 - 行) * 0.3853`。x = 0 は手首の首の中心、z = 0 は台座の上面
- 側面は `y = (列 - 497.3) * 0.3853`。y = 0 は手のひらの板の中心で、-Y が手のひら側

### 図から分かった構造

- 板は手前から順に、サーボ板（y = -14.5）、手のひらの板（y = 0）、甲の板（y = 26）
- 手のひらの板は大きい 1 枚で、上端が指ごとの段になり、親指側に翼が出る。小指側の縁は下へ向けて内に寄る
- 指の付け根の軸は手のひらの板の後ろ（y = 11）にある。基節が板の上端をまたいで前へ傾く
- 指の板の層は小指側から、S 字の銀の板、中節の板、基節と末節の板、銀の連結板
- S 字の銀の板は、手のひらの板の手前の受け（黒い台と横向きの軸）から板の上端をまたいで中節の尾へ上がる
- 親指の板は右下がりに 21 度傾き、正面からは縁だけが見える。基節は上下 2 枚、末節は 1 枚でその間に挟まる

### 甲の板は写真から

甲の板は寸法図の側面に高さ（z = 21〜86）と奥行きしか出ないので、形は `04_甲_後ろから_別コマ.png` から読んだ。
板の下辺を水平、親指側の縁を鉛直として平行投影で直す。

- 親指側の縁は鉛直。小指側の縁が上へ向けて外に開く（約 12 度）。`09_スケッチ_甲の板_初版.png` の向きが正しい
- 写真の中では板全体が約 6 度回っているので、写真の縦横のまま読むと「親指側が斜め、小指側が縦」に見える。以前のモデルはこの読みで作っていた
- こうして読んだ甲のねじ 4 本は、寸法図の正面のねじと 2mm 以内で重なる（別の資料どうしの一致）
- 下から出る舌は L 字の金具の縦の板。写真から読んだ幅（x = -10.8〜12.8）が寸法図の首の幅と一致する
- 側板は写真に合わせて全高に立てた。寸法図の側面では z = 51〜75.5 だけに描かれている（版の違いと見ている）

## 読み切れていない所

- 指の連結の仕組み。側面図は 1 姿勢だけなので、どの板がどの板に留まるかは写真と合わせた推定。見た目の位置は図に合わせてある
- 親指の銀のクランクの両端の位置（側面図の高さと奥行きは読めるが、正面の位置は推定）
- 甲の板の小指側の上の角の高さ。写真が平行投影でない分、数 mm の幅がある
- 写真の親指は図と姿勢が違う。モデルは寸法図の姿勢

## 作るときの注意

- `box()` で作った物に回転を入れると原点まわりに飛ぶ。斜めの板は `plate()` に基底を渡して作る
- `plate()` の穴が輪郭からはみ出すと面が張れず、縁の線だけが残る（はみ出しは例外で止めている）
