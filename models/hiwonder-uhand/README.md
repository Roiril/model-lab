# Hiwonder uHand 再現（表示用）

Hiwonder の 5 本指ハンド uHand（LFD-01 サーボ 6 個）を、寸法図と写真から再現した形。印刷用ではない。
資料は `ref/uhand参考資料/`（git 管理外）。中身と要点は同じフォルダの `INDEX.md`。

## 寸法の出し方（2026-11-10 に全面的に読み直した）

`params.py` は実寸の mm。正本は寸法図（`02_寸法図_拡大.png`）の正面と側面。

- 縮尺は 0.3853 mm/px。全高 174mm の寸法線が入った 01 と、拡大版の 02 で同じ線（指先の上端・手のひらの下端・台座の上面）の行を拾って求めた
- 正面は `x = (列 - 146.5) * 0.3853`、`z = (454.5 - 行) * 0.3853`。x = 0 は手首の首の中心、z = 0 は台座の上面
- 側面は `y = (列 - 497.3) * 0.3853`。y = 0 は手のひらの板の中心で、-Y が手のひら側

### 図から分かった構造

- 板は手前から順に、サーボ板（y = -14.5）、手のひらの板（y = 0）、甲の板（y = 26）
- 手のひらの板は大きい 1 枚で、上端が指ごとの段になり、親指側に翼が出る。小指側の縁は下へ向けて内に寄る
- 指の付け根の軸は手のひらの板の後ろ（y = 11）にある。基節が板の上端をまたいで前へ傾く
- 指の板の層は小指側から、S 字の銀の板、中節の板、基節と末節の板、銀の連結板
- S 字の銀の板は、手のひらの板の手前の受け（黒い台と横向きの軸）から板の上端をまたぎ、板の後ろで中節の尾に留まる
- 親指の板は右下がりに 21 度傾き、正面からは縁だけが見える。基節は上下 2 枚、末節は 1 枚でその間に挟まる

### 実物の写真から（2026-11-10 に 3 枚追加）

`20_実物_親指側.jpg` `21_実物_小指側.jpg` `22_実物_甲.jpg`。台座から外した手を机に寝かせて、真横と真後ろから撮ったもの。指は握った姿勢。

甲の板（`22`）:

- 縮尺は、手首の取り付け穴 3 つを寸法図のねじに重ねて決めた（11.0 px/mm）。板の下端は z = 17.5 で、手のひらの板の下端とほぼ同じ
- 親指側の縁は鉛直。上辺は親指寄りの頂点から小指側へ下がる。小指側の縁は上半分が鉛直で、その下は内へ約 4mm 寄る
- 側板は左右とも上半分だけ（z = 50〜77）。寸法図の側面（z = 51〜75.5）と一致する。上辺に折れた縁は無い
- 小ねじは 3 本で、小指側の上はねじの無い穴（奥に真鍮の柱が見える）
- 以前は `04_甲_後ろから_別コマ.png` を平行投影で直して読み、下端を z = 21、側板を全高、小指側の縁を全体に斜めとしていた

指（`20` `21`）:

- 付け根の軸は手のひらの板の約 11mm 後ろ（寸法図の読みと一致）
- 基節は付け根の後ろへ約 10mm の腕が出て、そこに引き棒の上端が留まる。寸法図のナット (19.5, 78.5) がこの点。引き棒はここから下へ、サーボの白いホーンへ降りる
- 指のサーボの本体は手のひらの板を貫いて後ろへ出る。ホーンは板の約 12〜17mm 後ろ、側板のすぐ下に見える
- S 字の銀の板の下端は、手のひらの板の約 7mm 手前、上端の約 4.5mm 下（寸法図の読みと一致）。上端は中節の板の尾の先で、尾は中節の軸の延長に約 9mm 出る
- 写真の姿勢は、付け根が約 43 度、次の関節が約 74 度。動きの計算はこの比に合わせた
- 指先側の銀の連結板は弓なり（弦 26mm に対して約 3.5mm ふくらむ）
- 板どうしをつなぐ柱は真鍮

`ovl_front.png` / `ovl_side.png` に、寸法図の線（黒）とモデルの面（薄赤）・縁（赤）が重なる。位置合わせで動かさない（縮尺と原点は固定）。

面の外に出る線の大半は、図にだけある台座と寸法線。側面の内側の割合は、甲の側板を上半分だけにして中の詰め物を外したぶん下がった。

## 動かす（2026-11-10）

手順と決まりは `.claude/skills/uhand-animation/SKILL.md`。入口は `py -3.11 models/hiwonder-uhand/anim.py`。

- 動かせる量は実物のサーボと同じ 6 個（指 4 本・親指・手首）。クリップは `anim/clips/*.json` に、時刻ごとの量を書く
- 指は 4 節リンクとして解く（`kin.py`）。量 1 個から 3 つの関節と銀の板の姿勢が決まり、握りきりで関節は 45 / 約 81 / 約 65 度
- 指のサーボのホーンと引き棒も動く。引き棒の長さが変わらない角度までホーンが回る（握りきりで約 70 度）
- `anim.py build` が `exports/hiwonder-uhand-rigged.fbx`（Unity 用）・`.glb`（ブラウザ用）・`.json`（目録）を書く。骨 35 本、部品は骨ごとに 1 メッシュ、スキン無し
- ブラウザは http://localhost:3000/viewer/uhand-anim.html
- Unity は `unity/Assets/UHand/` のスクリプトが、読み込み設定・Animator の組み立て・実行時の操作（`UHandDriver`）を受け持つ。
  2022.3.62f2 の batchmode で、クリップの再生と量からの姿勢を目録の目印 56 か所と比べて、外れ 0（`anim.py unity-test`）

S 字の銀の板の上端は、中節の板の尾の先（関節から 11.4mm。実物の写真では約 9mm）に置いた。
写真の姿勢（付け根 43 度で次の関節 74 度）に合う位置を計算で選んでいる。付け根が 52 度を超えると板が届かなくなるので、曲げは 45 度まで。
銀の連結板は図の位置のままで成り立った。

## 読み切れていない所

- 指のサーボの出力軸の位置、ホーンの腕の長さと向き。写真では白いホーンの位置しか分からず、推定で置いた（`params.py` の `FINGER_SHAFT_DZ` `FINGER_HORN_R` `FINGER_HORN_REST`）
- 親指の銀の長い板。実物の写真で、親指の上の板から手のひらの板の約 10mm 後ろへ渡る（長さ約 38mm）ことは分かった。後ろの端が何に留まるかは読めていない
- 手のひらの板とサーボ板のあいだの、親指のサーボを抱える段になった板。写真には写っているが作っていない
- 写真の親指は図と姿勢が違う。モデルは寸法図の姿勢

## 作るときの注意

- `box()` で作った物に回転を入れると原点まわりに飛ぶ。斜めの板は `plate()` に基底を渡して作る
- `plate()` の穴が輪郭からはみ出すと面が張れず、縁の線だけが残る（はみ出しは例外で止めている）
