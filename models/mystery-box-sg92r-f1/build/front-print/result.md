# 蓋カセットの局所印刷修正試験

蓋だけを局所修正しました。crank・support・servo_capの不合格な試行変更は全て戻しました。
`plates/` と `slice.json` は最終の蓋1個を実スライスした記録です。全体の合格を示すものではありません。
`experiment-01-slice.json` は撤回済みの4部品試行です。`print/` と `assembly/` は最終の局所形状です。

## 最終の蓋

B側の外耳をピン最下面d=3.5mmより下の足でベッドへ支えます。足はd=0〜1.5mmです。
H外周半径を5.0mmから5.1mmへ増やし、半径2.7mmの円形座を含む45°屋根をH穴とB穴へ付けました。
H屋根は中心+3.78mmで残肉1.32mmです。B屋根は中心+3.1mmです。
外支えなしは1.38mm、サポートなし、951秒、PLA3.63g、非多様体0です。

共有計器の校正後、動作70姿勢・55組で干渉0、駆動3界面の12標本が全て3°以内、抜け止め12界面が全て0.5mm以内です。
組立14工程も全て合格しました。`verify_envelopes.envelope_violation` を同じ70姿勢・製造余裕0.25mmで実行し、蓋の超過は0mmでした。
詳細は `mechanics.json` です。合成後の全体ゲートは親が再実行します。

## 撤回した試行

| 部品 | 元の外支えなし | 試行の外支えなし | 不採用理由 |
|---|---:|---:|---|
| crank | 96.69mm | 60.72mm | ホーン索引床の下面webと軸ワッシャの円錐補強を追加したが、非多様体495辺。外支えなしも上限を超える |
| lid | 29.38mm | 32.44mm | 横穴を小さいteardropへ変更しても改善しない。円穴の余裕も変わるため撤回 |
| support | 868.72mm | 686.12mm | 背面床の裏打ちが深さ29〜34mmの規格UV±15mm（公差込み±14.75mm）を越える |
| servo_cap | 821.58mm | 821.02mm | この試行では形状変更なし。配置の違いによる測定差 |

全試行は既存PLAプロファイル、壁2、充填15%、サポートなし、0.20mmでスライスしました。
共有 `inspect_sliced_3mf` を使い、計器・閾値・allowancesは変更していません。

## 局所修正を妨げる形

- crankのホーン索引床はu=7.75mmで始まり、18mm側の逆向きホーンを止める位置まで延びます。
  その下面を単純にベッドへ伸ばすと、正本ホーンの占有空間へ入ります。
  正本のポケットを再度抜くと張り出しが残ります。分割または支持経路の変更が必要な候補です。
- lidの横穴は半径2.7mm、外側は半径5mmです。
  円穴を包む45°接線屋根の頂点は中心から`2.7*sqrt(2)=3.818377mm`となり、残肉は`1.181623mm`で1.2mmを下回ります。
  最終案ではH外周を5.1mmへ増やして残肉を確保しました。小さい切欠きだけでは元の外支えなしを解消できませんでした。
- supportの現印刷姿勢はd方向を反転します。d=26.75mmの床は、小さいd=31.5mmの背面台から張り出しています。
  床をそのままd=31.5mmまで裏打ちする案は、階段状の内部規格を越えます。
  深さ29mmでUV±14.75mmへ収める支持リブと、それに続くサーボ耳・前側固定腕の支持経路を同時に組み直す必要があります。
- servo_capはd=0mmの左右の蝶番押さえから、d=2.3mmの枝とd=8.25mmの遮蔽壁へ続きます。
  左枝u=[-27,-20.75],v=[-6,12]は約18mmの片持ち、遮蔽壁は37mm幅です。
  下側へ単純に埋めると、蓋・リンク・サーボの組立経路と動作空間へ入るため、微小面取りだけでは解決しません。

crank・support・servo_capは未解決です。支持構造の組み替えや印刷部品の追加は、親の設計判断が必要です。
