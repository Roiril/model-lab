# 正面の蓋カセット

局所XYZは(u,v,d)、形状と行列はmm。寸法定数はparams.pyのm。骨格と他の面のコードをimportしません。取付部はinterface.jsonの数値レシピをこのディレクトリのrecipe.pyが読みます。

印刷9点は面板、交換キー2個、支持座、遮蔽兼サーボ押さえ、ホーン受け兼クランク、リンク、蓋、蝶番ピンです。既製部品はSG92Rと付属ホーン1個ずつです。ホーン形状は正本の関数定義を呼び出して作ります。

蓋は36×30×2mm。回転中心H=(-12,3)mm、サーボ中心O=(-3,17.5)mm、クランク12mmです。リンク長は閉姿勢から計算した19.4909mmの丸め前の値を使います。kinematics.diagnostics()で正確な端点と閉路誤差を読めます。サーボ90度で蓋約27.4775度を組立基準にし、2秒の五次補間で端点へ動かします。停電時の角度保持は保証しません。

頭なしのØ5mm蝶番軸をØ5.4mmの穴へ通します。軸はu=-27.65〜26.2mmにあり、平らな側を表側に向けます。最後に付ける面板裏の両端壁が抜け止めです。左の支持軸受けはu=-28〜-25mmに置き、SG92R本体のu=-24.5mmより負側へ逃がしています。

ホーン受けは中央ハブと短腕を掴みます。18mm側と16mm側の長腕は囲いません。中央軸の余分なフランジは設けません。リンクはu=15.15〜18.15mm、蓋の耳はu=18.45〜21.45mmです。関節はØ5mmとØ5.4mmの穴、軸方向の隙間0.3mmを維持します。

16mm側の先に1.2 × 1.2mm角のストッパを設けます。α=0の局所姿勢で、Oからの相対位置はv=-17.5〜-16.3mm、d=-1.8〜-0.6mmです。ストッパのu=5.75〜8.05mmを、Oの半径3.8mmの円と矩形の凸包から作るu=7.75〜10.75mmの床で支えます。

正向きでは公称0.3mmの隙間を残し、180°逆向きの18mm側はストッパに当たります。正本ホーンを使いストッパ方向へ-0.25/0/+0.25mmずらした局所診断では、正向きの共通体積は0〜0.0000132mm³で計器の判定床以下でした。逆向きは1.714〜2.093mm³で全3姿勢を拒否しました。horn_fit試片はこのストッパを含む本体の複製です。試し刷りによる適合は未確認です。

Aピンの頭はu=18.45〜19.65mm、座金はu=13.15〜14.85mm、Bピンの頭はu=21.75〜22.95mmです。押さえ側のクランク支持部はu=12.85mmまでとします。支持座の接続部は、深さd=16.74mm以上でv<-24.75mmを使わない形です。蝶番穴の切削は軸受けに限定し、他の接続部を切り離しません。

面板は開口端u=±27.75mmからキー窓まで1.5mmの帯を残します。左の帯はu=-29.25〜-27.75mm、右の帯はu=27.75〜29.25mmです。支持座を留める爪の中心はu=±28.4mmで、爪頭はv=-2.9〜-1.1mm、根元の通し部はv=-3.5〜-0.5mmです。交換キーの先端より下で留め、キーの挿入経路を空けます。

組立経路はassembly.pyに順序と0.5mm以下の並進を記録しています。以下は現在のソースと同じ順序です。ストッパ追加版を含む全体ケースと正面専用ケースの組立66工程がmechgateに合格しています。

1. 支持座を置きます。別の場所で蓋を組立角27.4775°に置きます。
2. 蓋の耳へリンクのBピンをu負側から差します。
3. 別の場所でSG92Rを90°に合わせ、電源を切ります。付属ホーンとホーン受けをu正側から差します。
4. 蓋とリンクをまとめてu正側から動かし、クランクのAピンへ接続します。
5. サーボ・ホーン・クランク・リンク・蓋を一式でd負側から支持座の開放溝へ入れます。
6. 押さえ兼遮蔽壁をv=+50mmからv=0へ滑らせます。クランク軸受けの下側はd=14.6mmの平底で閉じます。
7. 頭なし蝶番軸をu負側から通します。平らな側を表側に向けます。
8. 面板を最後に留め、裏の両端壁で蝶番軸を保持します。
9. 90°から閉指令124.337319°へ戻します。開指令は55.662681°です。

キーは単体の組立から除きます。カセットを骨格へ着座させてから、1.86°の解除角でキーを挿入して戻します。キー頭の中心は(u,v)=(±31,-22)mmです。交換時はキーを解除して抜き、他の面を残してカセットを40mm引き出します。内部の分解は、面板を外して蝶番軸の両端を開放してから逆順で行います。

Aピンの頭は半径2.85mm、必要な片側撓み0.15mmです。割り幅1.8mm、自由長4.8mm、片脚厚1.6mm以下として、ひずみの上限は1.563%です。Bピンも片側撓み0.15mmで、自由長4.5mmと厚1.6mmからひずみ1.778%です。実物で押せることと永久変形を確認してください。

試片はtrials.pyで本体から複製・切り出します。horn_fitは非対称受けと軸方向の遊びを確認します。servo_fitは耳溝、ケース、配線の取り出しを確認します。connector_nestは仮外形の開放置き場です。STLの存在は実物適合を意味しません。

刷る向きはgeometry.pyのprint_rotationに記録します。面板と蓋は外面を下。クランクとリンクは局所Y軸まわり-90°として広い面を下にし、ピンを積層方向へ伸ばします。支持座はX軸まわり180°で背面を下にします。キーは局所姿勢のまま、蝶番ピンは平らな側を下にします。

段1では印刷プレートとスライスを作りません。print.sliceのみ依頼に基づく限定免除で、印刷可能とは未判定です。実物の摩擦と遮蔽も未確認です。局所診断debug_link_lid.pyはゲートの代わりにはなりません。

ストッパ追加版は通常の全体ゲートと正面専用ゲートが双方合格しました。全34部品・561組を48姿勢で検査し、駆動3界面と閉位置の抜け止め40件が合格しました。中間の蓋30°と開端60°へ全34部品を焼き直した補助検査も、それぞれ抜け止め40件が合格しました。

矩形ストッパ版の密な包絡検査は26/26部品が合格しました。可動部を691姿勢、最大0.099529°刻みで測定し、製造余裕0.25mmと保存契約の区間移動上界を含めています。計器校正も合格です。実物適合と遮蔽は未確認で、元の非線形運動学の連続証明と任意の面の同時動作の証明は未完了です。印刷プレートとスライスも未作成です。
