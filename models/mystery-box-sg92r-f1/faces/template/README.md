# 面モジュールのひな形

このフォルダだけを新しい名前へ複製します。`module.json` の `module` をフォルダ名へ合わせます。
このままでも3部品の固定面として動きます。底面へ機構を追加してはいけません。

共通規格は `resident-face-v1` です。共通データは関数の `interface` と `common_params` から受け取ります。
他の面や骨格のモデルコードはimportしません。同じ面の中では相対importを使えます。
SG92R正本は `common_params.SG` です。長腕18mm側と16mm側を区別します。
寸法定数は `params.py` にmで書き、形を作るときにmmへ換算します。

`geometry.build(interface, common_params)` は部品IDをキーにした辞書を返します。
各部品は `object`、`print_rotation`、`label`、`color` を持ちます。既製部品は `purchased: true` を付けます。
頂点は局所 `(u,v,d)` のmmで、閉じた組立姿勢へ焼きます。外から見てu右、v下、d内側の右手系です。
`print_rotation` は並進を含まない行優先4×4回転行列です。合成側が接地と配置を行います。

`kinematics.transforms(servo_deg, interface, common_params)` は全ローカル部品の4×4行列を返します。
固定部品も既製部品も省略しません。行列の並進単位はmmです。
閉状態へ焼いた形に対する相対変換で返します。世界座標への配置は合成側の仕事です。

任意で `kinematics.retention_poses(interface, common_params)` を定義できます。
`mid` と `open` の2姿勢を `[{"id":"mid","label":"中間","servo_deg":90}, ...]` の形で返します。
中間は検査するサーボ範囲の内部、開端は `module.json` の開指令と一致させます。`output_deg` などの補足値は記録用に追加できます。
省略した可動面はサーボ範囲の中央と開端を使います。出力の中間角を使いたい面は、その計算をこの関数の中に置きます。
合成側は指定姿勢へ全組立部品のSTLを焼き直し、他面を閉状態に保ちます。既製部品も除きません。
通常の運動検査と同じ静止部品の分類を引き継ぎ、校正済みのゲート計器で抜け止めだけを追加測定します。
補助結果は `build/retention_report.json`。全体ゲートとは別の結果で、認証では両方の成功が必要です。

`assembly.steps(interface, common_params)` は `id`、`title`、`instruction`、`moving`、`frames` を持つ工程の配列です。
`frames` はローカル部品IDから4×4行列への辞書です。新しく入れる部品か動かす部品だけを含めます。
前工程の残りの部品は合成側が補います。移動刻みは1mm以下、回転刻みは5°以下です。
最後は全部品を単位行列へ戻します。サーボがあれば90°の組付けから閉角への復帰も工程へ含めます。
骨格への面法線挿入、固定キー、他面を残した40mmの交換経路は合成側が生成します。

`module.json` の全参照はローカルIDで書きます。骨格の `frame` やスロット名の接頭辞を書きません。
`interfaces` は駆動と保持を宣言します。保持には `direction`、`max_free_mm`、`engage_depth_mm` を書きます。
`allowances` は本当にしなる場所のスナップだけに限定します。静止干渉を許すための一括除外は使いません。
可動面は `motion` に `actuator`、`servo`、閉角、開角、組付け90°、1°刻み、2秒の動作を記録します。
必要なら `motion.range_servo_deg: [60,120]` のように検査する指令範囲を指定できます。厳密に2要素の有限数値の配列で、boolは受け入れません。
`0 <= lo < hi <= 180` とし、閉角・開角・組付け角をすべて含めます。省略時は閉角と開角の小さい方から大きい方までを検査します。
両端を含めて `step_deg` 以下で掃引し、個体補正後の全指令も0〜180°内であることを確認します。閉状態の基準と物理的なhomeは `closed_servo_deg` のままです。
閉角90°・開角120°・範囲[60,120]・刻み1°なら61姿勢です。補助保持検査は、姿勢関数を省略した場合は範囲中央90°と開角120°を使います。
選択面のソースと設定を依存ハッシュへ含めます。`build/`、`__pycache__/`、`_local/` の検証生成物は走査しません。
仮寸法は `unknowns` と、実形状から作る `trials.build(parts, interface, common_params)` の試片で扱います。
試片が生成された状態と、実物で適合した状態は別です。

共通取付は `mount_geometry.parts` のCSG数値レシピから作ります。
schemaは `csg-mm-v1` です。プリミティブは `box` と `cylinder`、演算は順序付きの `union` と `difference` です。
このフォルダの `geometry.py` に独立した解釈処理があります。`build_mount()` は panel/key_l/key_r を返します。
前板を切り抜く場合も、3個の座面、丸穴、長穴、キー、解除窓は残します。
キーの全長通し溝も残します。根元穴と先端窓だけでは、キーの腕が面法線方向の挿入中に面板へ当たります。
`mount_geometry.frame_receivers` は全スロットの実占有物です。機構は片側0.25mmを空けて避けます。

内側の使用可能領域は深さごとに92/76/64/50/40/30/24mm角へ狭まります。
外側の動作は76×76×32mmに収めます。製造公差は片側0.25mmです。
固定92mm面板は浅い外装として公称形状を判定し、幅の製造公差は92.5mmと92.6mmの開口の比較で別に扱います。
d=0やd=3を跨ぐ一律膨張だけで固定外装を違反にしません。可動形状と内部機構にはこの扱いを広げません。

新しい面では、7段の占有領域と骨格のkeepoutを全角度で検査します。
停止点だけでなく、刻み間の掃引量も回転半径から上限を出します。
単独スロットで全ゲートを通してから、他面を変更せず別スロットへ配置して確認します。

面を足したら `certify.py` を実行します。合成時と認証の最後に `lattice_export.py` がStudioの物理・組立データも再生成します。代表面だけを再生し、追加した可動面の実STLによる質量・駆動計算は検査一覧に併記します。
認証では `plate.py --if-stale` も実行します。面を差し替えたらプレート内の全部品と試片を更新し、全スライスを `spec.base.json` の `slice.files` に含めます。サポートなし・外側の未支持押出し2mm以下を確認し、免除で置き換えません。
