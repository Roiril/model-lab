# 3画素の面カセット

指掛けはu=±36mmの2×2mm、深さ0.95mmの45°くぼみです。爪先でキー頭の外縁を内側へ押して解除します。操作感と繰り返し着脱は実物で確かめます。

共通取付は `resident-face-v2`（`csg-mm-v2`）です。面板は87.4×87.4×2mm。キー頭は7.2×4.8×1.2mmで、d=1.2〜3.3mmの3断面テーパーで根元へつなぎます。キーはd=8mmの面を床にしてX軸まわり180°で印刷します。頭の隙間0.2mmと爪の隙間0.25mmを足した保持方向の遊びは0.45mmです。

`resident-face-v2` の独立モジュール。印刷13部品とSG92R・付属ホーンで構成します。
外形は面板87.4×87.4mm、内側36.5mm、外側の突出は最大3mmです。
形状と行列は局所 `(u,v,d)` のmm。寸法定数は `params.py` のmです。

## 合成担当への申し送り

`slots.json` の `slots.top` は次の指定です。

```json
{"module":"three_pixels","rotation_deg":0,"calibration_deg":0}
```

対応は `top / front / right / back / left`。底面は対象外です。面内回転は0度で検査します。
サーボは90度に合わせ、付属ホーンの18mmの長腕を局所uの正方向へ向けます。
90度で全画素が面一です。組付け姿勢と閉姿勢が同じなので最終行列は単位行列です。

閉角90度と開角120度だけでは60〜90度を検査できません。
`motion.range_servo_deg: [60,120]` と `stop_servo_deg: [60,90,120]` を追加しました。
`compose.sample_angles()` は `range_servo_deg` を読み、60〜120度の61姿勢を生成します。`stop_servo_deg` は表の停止位置を説明する値で、掃引範囲は `range_servo_deg` が決めます。
90度を閉姿勢とする意味を変えて、この不足を隠す指定にはしていません。
`_local/` の検証生成物は、合成側の依存ハッシュから除外されます。

## 表からカムを作る

`patterns.json` の高さを変え、`geometry.build()` を呼び直します。上下カムを両方刷り直します。
実行時に3画素へ別々の高さを指令する構造ではありません。

| サーボ | 画素1 | 画素2 | 画素3 |
|---|---:|---:|---:|
| 60° | 3mm | 0mm | 1.5mm |
| 90° | 0mm | 0mm | 0mm |
| 120° | 0mm | 3mm | 1.5mm |

停止角の前後5度は一定高さ。残る20度は五次曲線です。従動子の位相は1 / 121 / 241度です。
半径2.2mmの有限長ピンの包絡面を求め、Ø4mmピンへ法線方向0.2mmずつの隙間を作ります。
高さ曲線を上下へ単純に2.2mmずらす方法ではありません。
表の範囲は0〜3mm。90度の行は組付け基準のため `[0,0,0]` を保ちます。

## 設計書から変えた配置

- サーボ軸u=-5mm、本体底d=36.5mm。正本を反転し、骨格の長穴側の受けと製造公差を避けました。
- 画素中心は `(30.3,5.5) / (12.2,30.5) / (12.2,-30.5)` mm。従動ピンの120度間隔を保ち、画素2・3へはカム外周の3mm厚の腕でつなぎます。
- 最大幅14×14mm。画素2・3の角を3mm落としてカムを避けました。裏には全周1.2mm厚、長さ8mmのスカートがあります。
- 4×4mmの案内茎をカム内径側へ移しました。案内はd=16.75〜19.75mm。3mm突出時にも3mmの案内長が残ります。
- 上カム外周の150〜255度に1.9mmの逃げを設けました。内径側を半径23mmまで延ばし、この区間にも1.6mmの肉厚を残します。最大外径53mmは維持します。
- カム結合キーは75 / 181度。二股脚1.2mm厚、片側変位0.15mm、計算ひずみ0.67%です。
- 押さえの右腕は22mm長・1.2mm厚です。先端を5mm開いて案内板を越え、着座後に戻します。中心線の長さを保った曲げの最大ひずみは1.938%以下。左腕の変位は0.6mm、ひずみは0.471%以下です。

## 力と印刷

最大勾配16.1144mm/rad。半径25mmでの圧力角32.8049度。
最小接触半径22.8945mmを含む保守的な圧力角は35.1400度です。
1画素0.4N、効率0.55、摩擦0.005N·m、加速0.001N·mでの上限は0.041159N·m。
停動0.245N·mの1/3の0.081667N·m以下です。0.4Nは実測済みの摩擦値ではありません。
回転部品の体積重心から求めた自重の追加上限は0.000237N·m、合計は0.041396N·m以下です。計算は `_local/check.json` の `mass_properties` に記録します。
60〜120度は2秒の五次補間。最大指令速度56.25度/秒、停止時の指令速度0です。
無通電で位置を固定するブレーキはありません。指で押された状態での保持力は未測定です。

面板と画素は表をベッド側にし、下カムと支持枠は裏返します。
カム結合キーは横向きにして脚が層に沿ってしなるようにします。
結合キーの頭は5×2.2mmをベッドへ接地します。上カムの頭用くぼみの天井は45度に傾斜させ、キーを内側へ押した実メッシュの停止量は0.462427〜0.464917mmです。
上下カム・案内板・カム結合キーはサポートなしの局所スライスで合格しました。画素・支持枠・押さえを含む最終段の印刷結果はルートREADMEと `build/gate_summary.md` を参照します。
`print_rotation` はこの向きを返します。全体のスライスは合成担当の工程です。

## ローカル検証

PowerShellで実行します。合成スクリプトは呼びません。

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.1/blender.exe' --background --python-exit-code 1 --python 'models/mystery-box-sg92r-f1/faces/three_pixels/check_local.py' -- --contracts
```

結果は `_local/check.json`。試片と各部品のSTLも `_local/` だけに書きます。
`--quick` は5度刻みの調整用、通常は1度刻みです。
共有の `solid_meter` を校正して共通体積を測ります。既製サーボとホーンの円筒近似以外に一括除外はありません。
`--contracts` は駆動と抜け止めの接触を調べ、共有の組立経路検査を呼びます。
試片生成は実物の適合確認と別です。
全体の機構ゲート、他面との合成、スライス、実物の摩擦・着脱、斜めからの遮蔽確認は別工程です。

- 左の支持経路を座面の手前 `v=-29.5〜-26.5mm` に移しました。面板の左側の爪穴も移し、18mm長・1.6mm厚の腕はフレームのラッチに届く前で終わります。

## 最終段の印刷検査で変えたところ

案内板の保持舌は先端を1.5mm短くし、下面を傾斜させました。先端にも1.73mmの厚さが残ります。サーボ押さえと接する部分を残し、61姿勢で案内板と他部品の干渉0、5姿勢の関連する保持検査が合格しました。専用の局所STLによる実スライスは外側の未支持押出し0mm、サポートなしです。印刷方向と案内穴は変更していません。結果は `build/top-print/guide2-mechanics.json` と `build/top-print/plate-top-guide2.json` に記録しました。上面の他部品は同じ形状で印刷合格になったわけではありません。

上カムは、中央の半径0〜23mmを厚さ2mmの円盤とし、外周のカム面と単一の閉じたメッシュでつなぎました。中央の円盤と3本のスポークをBooleanで重ねる方式から変更しています。キー頭の周囲は最低1.2mmを残し、頭のくぼみから軸穴へ45度で縮む天井にしました。181度側は交換キーの逃げを優先し、穴を外径側へ開きます。75度側の角穴は閉じたままです。150〜255度の外縁の逃げは、キー受けを付けた後に切り直します。

下カムのキー受けは、下面を傾斜させ、内径側を開いたU字にしました。内側の爪掛かりを除き、外側1爪で保持します。名目掛かりは0.15mm、接触面積は0.45mm²で、元の両側保持の半分です。上カム75度側の閉じた角穴と、上下に残した径方向の壁が相補的にキー位置を支えることが成立条件です。キー形状・スナップひずみ・許容値は変更していません。実物の保持力と繰り返し着脱での強さは未確認です。

検証済みの上下カムを組み合わせ、5姿勢の接触105件と組立16工程790フレームが合格しました。下カム単独の関連する駆動・保持は60〜120度の61姿勢976件で合格しました。外側1爪の抜け止めは0.252319mm、キーから下カムへの両方向の遊びは0.494824度です。上カムの61姿勢の干渉は0、連続占有も合格し、交換キーと挿抜経路5398組も非接触でした。上下カムとも1連結成分・非多様体辺0で、外側未支持押出し0mm・サポートなしです。ソースから局所再生成したSTLは、これらの検証済み候補とバイト単位で一致しました。記録は `build/top-print/lower-u-mechanics.json`・`combined-mechanics.json`・`collar-u-mechanics.json` と対応する `plate-top-*.json` です。

カム結合キーは、頭の接線方向の片側を2.5mmから1.5mmへ切り詰め、軸と同じ底面で接地する形にしました。頭の残る3辺は穴より広いままです。軸の3mm角、自由長、爪、軸方向の停止位置は変更しません。印刷方向も維持し、弾性腕は層に沿って曲がります。実STLの2本を同条件でスライスした局所検査は、外側の未支持押出し0mm・サポートなしでした。全体に戻した保持とスライスの結果は各ゲートへ記録します。

`trials.py` の `lower_cam_fit` と `upper_cam_fit` は、全周カムの複製から画素1の1区間へ変更しました。製品メッシュを `u=軸+18.7〜33mm、v=±17.5mm` で切り出し、サーボ60〜120°の接触域を端の余白ごと残します。ガイドも画素1のU溝だけを切り出します。切出し後は各1連結成分・閉じたメッシュです。カム固定キーの試片は印刷方向を合わせた本体STLを使います。

カム変更後のソースから9試片を生成し、合成時と同じ `clean_object` と `export_binary` を通しました。9個すべて1連結成分・非多様体辺0で、退化三角形による書き出し失敗もありません。上下カムの1区間試片もこの出口を通過しています。結果とSTLのハッシュは `build/top-print/source-trials.json` に記録しました。
