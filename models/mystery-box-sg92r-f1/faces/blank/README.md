# 空の面

指掛けはu=±36mmの2×2mm、深さ0.95mmの45°くぼみです。爪先でキー頭の外縁を内側へ押して解除します。操作感と繰り返し着脱は実物で確かめます。

共通取付は `resident-face-v2`（`csg-mm-v2`）です。面板は87.4×87.4×2mm。キー頭は7.2×4.8×1.2mmで、d=1.2〜3.3mmの3断面テーパーで根元へつなぎます。キーはd=8mmの面を床にしてX軸まわり180°で印刷します。頭の隙間0.2mmと爪の隙間0.25mmを足した保持方向の遊びは0.45mmです。

`resident-face-v2` の面板と固定キー2個です。6スロットで使用できます。底面にはこの面を使います。
サーボは使いません。部品IDは `panel`、`key_l`、`key_r` です。

形は `interface.json` の `mount_geometry.parts` を読みます。`csg-mm-v2` はmmのCSGです。
`base` のプリミティブへ `operations` を順に適用します。`op` は `union` または `difference` です。
`box` は `size_mm` と `center_mm` を持ちます。`cylinder` は `radius_mm`、`depth_mm`、`center_mm`、`axis` を持ちます。
`loft_box` は `sections` の `d_mm`、`center_uv_mm`、`size_uv_mm` を順に四角形で結びます。`center_mm` と `size_mm` は全断面のAABBです。
軸は `u`、`v`、`d` です。実装は `geometry.py` の `primitive`、`boolean`、`build_mount` にあります。
各面はこの小さな解釈処理を自分のフォルダへ複製できます。他の面のコードはimportしません。

すべての頂点は局所 `(u,v,d)` のmmで、閉じた組立位置へ焼いてあります。原点は外面中央です。
外から見てuは右、vは下、dは内側です。印刷姿勢は外面をベッドへ向けます。
固定キーはd=8mmの面をベッドへ置きます。弾性腕は積層面内でu方向へ曲がります。
腕の造形長は19.7mmで、根元の固定区間を除く自由長は18mmです。
ひずみは `1.5*1.6*0.6/18**2*100=0.4444%` です。爪の深さ方向の掛かりは2.4mmです。

面板を3個の座へ置き、非対称の丸穴と長穴を骨格のピンへ合わせます。
固定キーを外側から差します。キー先端の4×5mmの窓から腕を中央へ押し、爪を通して離します。
剛体の組立表示では根元 `(±31.2,-23)` を中心に右+1.86°、左−1.86°回し、爪を中央へ約0.6mm寄せてから挿抜します。
頭穴は7.6×5.2mmから3断面のテーパーで絞り、キー頭に片側0.2mmを空けます。
d=3.3mm以深の根元穴は3.5×3.5mmです。幅3.5mm・長さ22mmの通し溝をv=−25〜−3mmへつなぎます。
この溝は、内側の腕と爪が面法線方向の挿入中に面板を通り抜ける経路です。先端の解除窓だけで代用しません。
取り外すときも同じ窓から爪を解除します。キーを12mm引き、面全体を40mm引き出します。
可動面が途中で止まっていても、この窓とキーの頭は中央の可動領域に重なりません。

`trials.build()` は実寸キーと面板の40×30×12mm以下の切出しを作ります。
骨格側は本体と同じ `mount_geometry.frame_receivers` から切り出して組み合わせます。
最初は位置決め隙間片側0.20 / 0.25 / 0.30mmを比較します。20回着脱して割れと残留変形を見ます。
外向き10Nで外れないこと、窓から指で爪を解除できることを実物で確かめます。

固定の87.4mm面板は公称形状で浅い外装領域を検査します。製造公差込みの幅は87.9mmで、88mmの開口へ入ります。
d=0やd=3を跨ぐ一律膨張で、この固定外装を動作領域違反にしません。
可動形状と内部の機構は片側0.25mmを膨張した形で7段の領域に照合します。
骨格の受けは `mount_geometry.frame_receivers` に列挙した占有物です。機構はこの受けを避けます。
座面、穴、爪の接触は `mount.contacts` の場所へ限定します。

未確認はPLA/PETGの実物でのキー操作と10N保持です。生成した試片を、適合を確認した実物として扱いません。

`build/check_keys.py` は実キーの挿入・回転・解除・抜去を共通の `solid_meter` で測ります。
挿抜は0.25mm刻み、回転は0.093度刻みです。空の面板と、実STLへ同じ窓を適用した正面板を検査します。
正面の支持部との接触は編集範囲外として別に記録し、`build/key_path_report.json` へ局所座標で出します。

骨格の中央トレーはXY中心に置き、z中心は−10mmです。外形24×24×44mm、内形20×20×40mmです。
z範囲は−32〜12mmで、上面の最深領域z=13mmより1mm下に退きます。
初回組立では、面カセットを入れる前に35度の姿勢で下ろし、座った高さで0度へ戻して底の棚へ掛けます。
35度の回転は中央の24mm予約を超えるため、側面カセットを取り付けた状態では行いません。
他の4側面を残して保守するときは上面カセットを取り外し、トレー内から2本の腕を中央へ0.6mm押して、トレーを上へまっすぐ引き出します。
配線予約56×40×8mmの中心はz=−40mmです。配線案内の床z=−43.75〜−41.75mmと5本の6×3mm溝を置きます。
トレーを支える4本の止め柱と2本の爪が中央のz=−41.75〜−28mmを使います。基板用の20×20×40mm空間には入りません。
配線案内は左右の腕で下枠へ掛けます。自由長13.5mm、厚1.2mm、幅5mm、解除0.6mm、計算ひずみ0.5926%です。
配線案内は上枠より先に入れます。支持足はx=±36.75mm・y=40mmに置き、下枠の内側の梁で受けます。
後ろへ1.5mmずらした位置で下ろし、座ったら前へ1.5mm戻して左右の爪を掛けます。
この経路とトレーの35度経路では腕を曲げないため、組立の接触許可は付けません。
中央トレーの爪は自由長13.75mm、厚1.6mm、解除0.6mm、ひずみ0.7617%です。
骨格の柱の爪は掛かり1.8mmです。組付け時の接触は終端2mmに限り、面の交換キーの掛かり2.4mmとは別の寸法です。
