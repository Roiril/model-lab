# 歯車で起き上がる旗

`resident-face-v1` の面カセット。旗を0〜60度起こします。旗室と歯車室を固定壁で分け、壁を通る結合部は重ねたカラーで覆います。
単体の数値結果は [RESULTS.md](RESULTS.md)。合成ゲート・スライス・実物の嵌合は合成担当へ引き継ぎます。

## 合成への組込み

`slots.json` の `slots.right` を次の値にします。

```json
{"module":"sector_flag","rotation_deg":0,"calibration_deg":0}
```

対応スロットは `front / right / back / left / top`。底面は非対応、面内回転は0度です。
サーボは閉60度、開120度。組付けは90度、旗は30度です。
組付け時の付属ホーンの18mm腕は、局所+vから外側（d負）へ14度傾けます。スプラインの刻みは個体ごとに `calibration_deg` で補正します。
サーボ一式、旗室の底、旗一式、ピン、左右の押さえ、面板の順に組みます。旗一式は面外で組み、噛合位置からv方向へ2.8mm離れた位置へ運んでから両軸を結ぶ方向へ寄せます。
分解はサーボ90度に戻して逆順。面板の窓から爪を解除すると押さえとピンを取り出せます。
交換キーの操作と骨格への40mm直進挿入は、合成側の交換工程で生成してください。

## 設計値と変更理由

- 旗板は14×28×2mm。閉時の表面はd=0mmです。面板は92×92mm、閉じたカセットの奥行きは33.65mmです。
- m1.5、18歯相当、圧力角20度、歯幅3mm、軸間27mm、歯先R14.6mm、歯車対のバックラッシュ0.2mmを維持しています。
- 設計書のサーボ軸 `(v,d)=(0,17.5)` を `(6.7,14.9)` mmへ、旗軸 `(-22.776,3)` を `(-20.2953701,14.4)` mmへ変更しました。歯を固定屋根の下に収めるためです。
- 旗板を偏心した3mm厚の腕で支えます。u方向へ1mmずらし、範囲を `[-13,1]` mmにしました。固定壁と付属ホーンの間に必要な隙間を取るためです。
- 開角60度は維持。軸を奥へ移した結果、最大せり出しは22.749mmから17.049mmへ減り、旗の根元は開く間にv方向へ12.471mm移動します。
- 入出力とも使う部分だけを残した扇形歯車です。出力の歯中心は2/22/42/62度、入力は `INPUT_PHASE_DEG + 100/120/140/160` 度。使わない入力歯を除くことで屋根の厚さを確保しています。
- 遮蔽カラーはR8.75mm。旗側の円弧は閉時-110〜110度で、開閉中に固定壁の穴を覆います。右の固定壁はu=1.5〜3.25mm、左は-15.25〜-13.5mm、前屋根は1.2mm。左右ともカラーを壁の段付きの穴へ重ねます。左軸受けの支持長は3mmを残し、ピン頭を左へ0.5mm移しました。結合キーの穴は旗の中で止めます。軸押さえを分割し、印刷部品は12点になりました。
- 回転軸はØ3.4mm、穴Ø3.8mm。抜け止め溝の断面はØ3.0mmです。固定された押さえと溝の半径方向隙間だけ0.1mmとし、Ø3.4mmの肩を確実に捕まえます。ここは実形状の試片で確認します。
- ホーン受けは片側0.25mm、旗の駆動キーは片側0.2mm。軸受けの荷重を受ける壁は3mm以上です。薄い遮蔽壁は1.2mm以上で、軸受けの代わりには使いません。
- 旗室の奥壁は軸とカラーを避けて段を付け、段の端も1.25mm厚の壁でつないでいます。斜めからサーボの耳が見える隙間を塞ぐためです。
- 面板の爪は自由長17.8mm・厚さ1.6mm。0.6mm曲げるときの表面ひずみの計算値は0.454489%です。
- コネクタ置き場は局所u/v/dで14×8×18mm、範囲は `[-23,-9] / [15,23] / [3.25,21.25]` mm。サーボの耳を避ける向きです。配線溝は表から入れられ、仮の配線束の周りに3×6mmの断面を確保します。
- 2秒の五次補間。最大56.25度/秒、最大加速度86.603度/秒²。停止端の速度と加速度は0です。

部品は `panel / key_l / key_r / support / servo_cap / input_gear / sector_gear / flag / flag_cover / bearing_bridge / input_bridge / hinge_pin`。既製部品はSG92Rと付属ホーンだけです。
面板と旗は見える面を下にします。ピンは頭の平面を下、歯車とカラーは平らな軸方向の面を下にします。支持座と旗室の底は裏返して配置します。見える面へのサポートは許可していません。スライスによる確認は未実施です。

## 検査の入口

リポジトリ直下から実行します。Blender付属Pythonだけを使い、出力先はこの面の `_local/` に限ります。

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.1/blender.exe' --background --factory-startup --python-exit-code 1 --python models/mystery-box-sg92r-f1/faces/sector_flag/check_local.py -- --step .25 --all --compare
```

`--quick` は3姿勢の切り分け用。最終確認には使いません。`run_checks.ps1` も同じ検査を呼びます。
共有の接触計器を変更せず、通る例・落ちる例で校正してから測ります。形状・規格・SG92R正本が変わると後続の検査は再生成を要求します。

残す検査用スクリプトの役割は次のとおりです。

- `check_local.py`：形状生成、241姿勢の占有・部品干渉・骨格受け・トルク・試片、および全検査の入口。
- `check_features.py`：閉時の面一、ピンの実断面と左軸受けの支持長、配線とコネクタの空間。
- `check_interfaces.py`：manifestの両方向駆動・抜け止め検査を起動。
- `interface_checks.py`：実メッシュを回転・平行移動させ、接触までの遊びを測る共通処理。
- `check_assembly.py`：導入済みの部品を残した累積組立姿勢で全組合せを検査。
- `check_shield.py`：既定の585,225本に加え、0.1mm格子・複合した斜めと診断画像の方向を含む11視点の31,851,655本を検査。
- `shielding.py`：全候補で共有する格子・5視点・最初の交点の判定。
- `compare_shields.py`：同心円弧60度、固定屋根45度、深い軸60度の3案を再生成して比較。
- `render_local.py`：検査済みSTLの正面・斜め画像を生成する診断用。合否は画像で決めません。
- `evidence.py`：後続検査が古いSTLを使わないためのハッシュ照合。
- `candidates/arc60/`：比較用に固定した旧案の形状・寸法・歯形・運動。合成からは読み込みません。

遮蔽対象は歯車、サーボ、ホーン、内部の駆動キーと旗軸ピンです。交換規格が外面に指定する `key_l / key_r` の操作用の頭は外装として残します。
視点間・格子間を含む全方向の不可視を証明する検査ではありません。仮値のホーン・配線・コネクタは試片で実物を確認してください。摩擦、60mmサービス長、指での解除、20回着脱、他面を残した交換は未検証です。
