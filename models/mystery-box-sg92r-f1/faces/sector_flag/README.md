# 歯車で起き上がる旗

指掛けはu=±36mmの2×2mm、深さ0.95mmの45°くぼみです。爪先でキー頭の外縁を内側へ押して解除します。操作感と繰り返し着脱は実物で確かめます。

共通取付は `resident-face-v2`（`csg-mm-v2`）です。面板は87.4×87.4×2mm。キー頭は7.2×4.8×1.2mmで、d=1.2〜3.3mmの3断面テーパーで根元へつなぎます。キーはd=8mmの面を床にしてX軸まわり180°で印刷します。頭の隙間0.2mmと爪の隙間0.25mmを足した保持方向の遊びは0.45mmです。

`resident-face-v2` の面カセット。旗を0〜60度起こします。旗室と歯車室を固定壁で分け、壁を通る結合部は重ねたカラーで覆います。
単体の数値結果と合成時の修正は [RESULTS.md](RESULTS.md)。全体の印刷不合格は合成側の `PRINT_RESULTS.md` に記録します。実物の嵌合は未確認です。

## 合成への組込み

`slots.json` の `slots.right` を次の値にします。

```json
{"module":"sector_flag","rotation_deg":0,"calibration_deg":0}
```

対応スロットは `front / right / back / left / top`。底面は非対応、面内回転は0度です。
サーボは閉60度、開120度。組付けは90度、旗は30度です。
組付け時の付属ホーンの18mm腕は、局所+vから外側（d負）へ14度傾けます。スプラインの刻みは個体ごとに `calibration_deg` で補正します。
面外でサーボ・ホーン・ホーン受け・入力歯車・固定軸を組み、支持座へ載せます。旗室の底と別足も面外で半ラップを合わせてから一緒に入れます。その後は旗一式、ピン、左右の押さえ、面板の順です。旗一式は噛合位置からv方向へ2.8mm離れた位置へ運んでから両軸を結ぶ方向へ寄せます。
分解はサーボ90度に戻して逆順。面板の窓から爪を解除すると押さえとピンを取り出せます。
交換キーの操作と骨格への40mm直進挿入は、合成側の交換工程で生成してください。

## 設計値と変更理由

- 旗板は14×28×2mm。閉時の表面はd=0mmです。面板は87.4×87.4mm、閉じたカセットの奥行きは33.65mmです。
- m1.5、18歯相当、圧力角20度、歯幅3mm、軸間27mm、歯先R14.6mm、歯車対のバックラッシュ0.2mmを維持しています。
- 設計書のサーボ軸 `(v,d)=(0,17.5)` を `(6.7,14.9)` mmへ、旗軸 `(-22.776,3)` を `(-20.2953701,14.4)` mmへ変更しました。歯を固定屋根の下に収めるためです。
- 旗板を偏心した3mm厚の腕で支えます。u方向へ1mmずらし、範囲を `[-13,1]` mmにしました。固定壁と付属ホーンの間に必要な隙間を取るためです。
- 開角60度は維持。軸を奥へ移した結果、最大せり出しは22.749mmから17.049mmへ減り、旗の根元は開く間にv方向へ12.471mm移動します。
- 入出力とも使う部分だけを残した扇形歯車です。出力の歯中心は2/22/42/62度、入力は `INPUT_PHASE_DEG + 100/120/140/160` 度。使わない入力歯を除くことで屋根の厚さを確保しています。
- 遮蔽カラーはR8.75mm。旗側の円弧は閉時-110〜110度で、開閉中に固定壁の穴を覆います。右の固定壁はu=1.5〜3.25mm、左は-15.25〜-13.5mm、前屋根は1.2mm。左右ともカラーを壁の段付きの穴へ重ねます。左軸受けの支持長は3mmを残し、ピン頭を左へ0.5mm移しました。結合キーの穴は旗の中で止めます。軸押さえ、底の保持足、入力部を分割し、印刷部品は15点です。
- 回転軸はØ3.4mm、穴Ø3.8mm。抜け止め溝の断面はØ3.0mmです。固定された押さえと溝の半径方向隙間だけ0.1mmとし、Ø3.4mmの肩を確実に捕まえます。ここは実形状の試片で確認します。
- ピンを横に寝かせて刷るため、軸中心からd負方向へ1.5mmの位置で底を平面にしました。軸の厚さは3.2mm、頭を含む高さは4mmです。抜け止め溝は3.0×3.0mmのままです。
- 骨格受けは閉姿勢だけでなく、カセットを法線方向へ40mm入れる全行程を避けます。支持座の受け逃げを奥へ延ばしました。交換キーも規格の1.86度解除と引抜きの掃引を片側0.25mm空けています。
- 左軸押さえの2段に斜面を付け、右軸押さえは既存の挿入用空間内で底面をd=2.25mmまで延ばしました。出力歯車のカラーを円錐台で支え、右カラーのキー穴は接触壁を保ったまま奥の天井を斜めにしています。
- 旗室の底と保持足を法線肉厚1.2mmの斜め半ラップで分けました。合わせ面の隙間は0.2mm、側面は片側0.25mm。足には3×3mmのサーボ止めを設け、panelまでの足の移動を含むサーボの累積遊びを0.475196mm以下にしています。
- 入力部はホーン受け、歯車、固定軸の3部品です。中央孔R2.75mmと歯車の外周R5.75mmで軸受壁3mmを確保。R8mm・位相136度の3×3mmキーと3.5×3.5mm孔で結合します。ホーン受けの天井は1.3mm、歯幅は3mmです。
- ホーン受けの後退は厚さ3mmの支持座の肩で止めます。肩はホーン全掃引と挿入経路を0.3mm空けます。固定軸はR2.5mm・u=7.75〜15.75mm、頭R3.8mm・u=15.75〜17.8mm。頭の正側は支持座と0.2mm、負側は押さえと0.25mmの隙間です。軸先端がホーンの前進も止め、部品ごとの遊びを累積させても0.5mmを超えません。
- ホーン受けは片側0.25mm、旗の駆動キーは片側0.2mm。軸受けの荷重を受ける壁は3mm以上です。薄い遮蔽壁は1.2mm以上で、軸受けの代わりには使いません。
- 旗室の奥壁は軸とカラーを避けて段を付け、段の端も1.25mm厚の壁でつないでいます。斜めからサーボの耳が見える隙間を塞ぐためです。
- 面板の爪は自由長17.8mm・厚さ1.6mm。0.6mm曲げるときの表面ひずみの計算値は0.454489%です。
- コネクタ置き場は局所u/v/dで14×8×18mm、範囲は `[-23,-9] / [15,23] / [3.25,21.25]` mm。サーボの耳を避ける向きです。配線溝は表から入れられ、仮の配線束の周りに3×6mmの断面を確保します。
- 2秒の五次補間。最大56.25度/秒、最大加速度86.603度/秒²。停止端の速度と加速度は0です。

部品は `panel / key_l / key_r / support / servo_cap / cap_foot / input_cup / input_gear / input_spindle / sector_gear / flag / flag_cover / bearing_bridge / input_bridge / hinge_pin`。既製部品はSG92Rと付属ホーンだけです。
面板と旗は見える面を下にします。ピンは軸と頭の共通の平面を下、入力3部品と右カラーはu正側の面を下にします。支持座は裏返し、旗室の底はd=5.65mmの床面、保持足はu=-27mm面を下にします。見える面へのサポートは許可していません。底・保持足・入力3部品・入力軸押さえは局所スライスで支えの無い外部押し出し0mm。左軸押さえも0mm、出力歯車は0.42mmです。支持座1516.02mmと旗70.82mmは未達です。規格の面板と交換キーを含む合成全体の値は合成側 `PRINT_RESULTS.md` に記録します。

## 検査の入口

リポジトリ直下から実行します。Blender付属Pythonだけを使い、出力先はこの面の `_local/` に限ります。

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.1/blender.exe' --background --factory-startup --python-exit-code 1 --python models/mystery-box-sg92r-f1/faces/sector_flag/check_local.py -- --step .25 --all
```

`--quick` は3姿勢の切り分け用。最終確認には使いません。`run_checks.ps1` も同じ検査を呼びます。
共有の接触計器を変更せず、通る例・落ちる例で校正してから測ります。形状・規格・SG92R正本が変わると後続の検査は再生成を要求します。

残す検査用スクリプトの役割は次のとおりです。

- `check_local.py`：形状生成、241姿勢の占有・部品干渉・骨格受け・トルク・試片、および全検査の入口。
- `check_features.py`：閉時の面一、ピンの実断面と左軸受けの支持長、配線とコネクタの空間。
- `check_interfaces.py`：manifestの両方向駆動・抜け止め検査を起動。
- `check_retention_stack.py`：部品を順に動かして最悪の累積遊びを測る必須検査。`--all`から実行。歯の噛合と摩擦を止めに数えず、足→panel、底→足、サーボ→足、固定軸→押さえ、ホーン→固定軸、受け→歯車→押さえの実接触を調べます。個別保持が通ってもホーンの前進が0.700146mmになった旧試行を検出した検査です。

- `interface_checks.py`：実メッシュを回転・平行移動させ、接触までの遊びを測る共通処理。
- `check_assembly.py`：導入済みの部品を残した累積組立姿勢で全組合せを検査。
- `check_shield.py`：既定の585,225本に加え、0.1mm格子・複合した斜めと診断画像の方向を含む11視点の31,851,655本を検査。
- `shielding.py`：全候補で共有する格子・5視点・最初の交点の判定。
- `compare_shields.py`：同心円弧60度、固定屋根45度、深い軸60度の3案を再生成して比較。
- `render_local.py`：検査済みSTLの正面・斜め画像を生成する診断用。合否は画像で決めません。
- `evidence.py`：後続検査が古いSTLを使わないためのハッシュ照合。
- `candidates/arc60/`：比較用に固定した旧案の形状・寸法・歯形・運動。合成からは読み込みません。

累積保持の結果は `_local/retention_stack.json`。生成JSONは面の直下へ置かず、合成契約が追跡するPython/JSON入力へ混入させません。

遮蔽対象は歯車、サーボ、ホーン、内部の駆動キーと旗軸ピンです。交換規格が外面に指定する `key_l / key_r` の操作用の頭は外装として残します。
視点間・格子間を含む全方向の不可視を証明する検査ではありません。仮値のホーン・配線・コネクタは試片で実物を確認してください。摩擦、60mmサービス長、指での解除、20回着脱、他面を残した交換は未検証です。
