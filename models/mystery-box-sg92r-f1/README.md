# 面を交換できる住人の箱 F1

100 × 100 × 100mmの骨格に、正面の蓋・上面の3画素・右面の旗のカセットを取り付けます。各面をSG92Rで駆動し、背面・左面・底面は空の面です。
正本は `interface.json`。面の選択と個体別の指令補正は `slots.json` で管理します。
寸法は `params.py` がm、面の形状と運動・組立契約はmmです。

現在は共通取付と骨格を更新するv2-Aです。側面の受けを4個に分け、面板とキー、配線案内、中央トレーの取付を更新しています。v2-Aの最終統合検査は未測定です。生成した3mfを印刷合格の完成版として扱わないでください。
共通取付の局所スライスではキーが0mm、空面・上面・右面の面板が各1.87mmで、既存基準の2mm以内でした。正面の面板は面固有の蝶番まわりを含め28.79mmが残っています。面固有形状は変更しておらず、全ての面板を支えなしで刷る段目標は未達です。局所値は `build/v2-mount-results.md`、v2の最終値は再生成後の `build/plate-summary.json` と各 `build/gate_summary.md` を参照します。[PRINT_RESULTS.md](PRINT_RESULTS.md) のv1実測とは分けて扱います。

## 規格と面の追加

- 局所座標は外から見てu右・v下・d内向きの右手系です。完成位置は `slot_transforms_mm` で決めます。
- 規格は `resident-face-v2`、CSGは `csg-mm-v2` です。87.4mm角・厚さ2mmの面板を88mm角の開口へ入れ、3座面、非対称の丸ピンと長穴、爪先で解除するキー2本で取り付けます。v1との互換性はありません。
- 固定キーの頭の中心は `(u,v)=(±31.2,-22.1)mm`、頭は7.2×4.8×1.2mm。解除回転の中心は `(u,v)=(±31.2,-23)mm` です。頭の片側隙間0.2mmと爪の隙間0.25mmを足した保持方向の遊びは0.45mmです。
- 頭と根元はd=1.2〜3.3mmの3断面テーパーでつなぎます。キーはd=8mmの面を床にしてX軸まわり180°で印刷します。u=±36mmの指掛けは2×2mm、深さ0.95mmです。実物で爪先の操作感を確認します。
- 内部は `internal_envelope` の階段状占有域、外部動作は76 × 76 × 32mm。フレームの受けは占有物です。
- `faces/template/` を複製し、その面の `.py` と `module.json` だけに機構を実装します。同じ面の参照には相対importを使います。
- `geometry.build(interface, common_params)` は完成閉状態の部品をmmで返します。各部品に日本語名・色・印刷回転を指定します。
- `kinematics.transforms()` は局所部品IDを漏れなく返します。形状へ適用するのは完成閉状態からの相対変換です。
- `assembly.steps()` に箱の外で組む経路、90°でのホーン装着、閉位置への復帰を入れます。各フレームには動く部品・新しく置く部品を入れます。
- `trials.build()` は本体と同じ形から試片を作ります。`module.json` の `$trial/名前.stl` は合成時に各スロットの試片へ解決します。
- `slots.json` の面を変更して再合成します。非対称位置決めのため段1の回転指定は0°です。底面は可動機構禁止です。
- 付属ホーンの物理的なhomeは変更せず、交換した面の `calibration_deg` だけを指令角へ加えます。

合成時に部品と界面へ `front/` などの接頭辞を付けます。運動変換は `S Tlocal S⁻¹`。
各 `checks/<slot>/` は全部品を残し、その面だけを動かします。ルートの代表は正面です。
掃引範囲は `motion.range_servo_deg` があればその2端を使います。省略時は閉角から開角までです。
上面は閉角・組付け角90°を維持し、60〜120°の全域を1°以下で検査します。
右面は閉角60°、組付け90°、開角120°です。旗は0〜60°動き、検査刻みは0.25°です。

## 刷るものと組み方

部品表は `build/manifest.json`、印刷STLは `prints/mystery-box-sg92r-f1/<slot>/`、試片は同 `trial/<slot>/` に出ます。
印刷姿勢は各面が指定する回転を局所形状へ適用し、Z=0へ接地します。既製品はSG92Rと付属ホーンです。
面の詳しい部品表・刷る向き・初期角度は `faces/link_lid/README.md`、`faces/three_pixels/README.md`、`faces/sector_flag/README.md` を参照します。空の面は `faces/blank/README.md` です。
`plate.py` は製品4枚と試片1枚を生成する構成です。v2-Aの最終配置とスライス結果は再生成後の出力で確認します。X1C 256 × 256mmの手前左18 × 28mmを避け、部品同士の距離を6mm確保します。Z軸の90°回転だけで配置し、部品の接地面は維持します。
印刷条件はX1C 0.4mm、Textured PEI、PLA、0.20mm Standard、初層補正0.15mm、壁2周、充填15%、サポートなしです。継承を展開した設定を `prints/mystery-box-sg92r-f1/profiles/` に保存します。
`print.slice` の免除はありません。製品4枚と試片1枚を同じゲートへ渡し、外側の未支持押出し2mm以下を判定します。結果と見積時間・材料量は `build/plate-summary.json`、配置の実寸と部品一覧は `build/plate-*.json` です。

| プレート | v2-Aの配置 |
|---|---|
| 01-frame | 上枠・下枠・柱4本、背面と左面の面板・キー（12点） |
| 02-front | 正面9点、底面の面板・キー3点、配線案内、中央トレー、正面と左面の受け（16点） |
| 03-top | 3画素カセット全13点、背面と右面の受け（15点） |
| 04-right | 旗カセット全15点（15点） |
| 05-fit-trial | 正面の受けの切出し・空面の角・交換キー、サーボ座・押さえ・ホーン受け・コネクタ枠、カム上下の1区間・画素1・ガイド・カム固定キー（12点） |

v2の見積時間・材料量・CLIと検査の終了コードは `build/plate-summary.json` と `build/certification.json` の生成値を確認します。v1の時間・重量や終了コードをv2の結果として引き継ぎません。

試し刷りのカムは製品の実形状から、画素1のサーボ60〜120°に対応する区間と端の余白を切り出しています。上下の試片は別々に刷ります。取り外したハブや他2区間の駆動確認には使えません。形状の上下位置を合わせてピンの隙間と滑りを確認し、全周の回転・保持は製品カムで確認します。
試片名 `frame_corner` はv2では正面の受け `carrier_front` の実形状から切り出し、共通取付と同じ-d方向で刷ります。面の角は共通の空面から切り出します。試片ではキーの挿入・解除・保持を確認し、位置決めピンを含む面全体の着脱は本体でも確認します。

1. 下枠に4本の柱を差します。
2. 正面と右面の受けを下枠の溝へ合わせ、上から下ろします。下面板と背面の受けはまだ付けません。
3. 配線案内を前へ4mmずらして下ろします。座ったら後ろへ4mm動かし、T字の足を下枠へ入れます。
4. 背面の受け、左面の受けを上から下ろします。上枠を付けて側面の受けと配線案内を固定します。
5. 中央トレーを上から見て35°回した姿勢で下げ、底が座ったら0°へ戻します。剛体のバヨネット式で、外すときは35°回して上へ抜きます。
6. カセットは箱の外で組みます。SG92Rを90°にして付属ホーンを付けます。正面内部の順序は下記、上面と右面は各面のREADMEを確認します。
7. 各面を閉指令へ戻し、専用配線の余長60mmを確保します。右面は60°、上面は90°です。
8. 非対称位置決めを合わせて面法線方向へ差し込み、3座面に着座させます。
9. 固定キー2本を1.86°の解除角で差し、キー頭を戻して固定します。
10. 交換時は電源を切り、キー頭を1.86°回して抜きます。側面の受けと他面を残して40mm引き出します。
11. コネクタ本体をつかんで切り離します。再装着は逆順です。

側面の受け自体を外すときは対象カセットと上枠を外し、受けを上へ抜きます。配線案内の取り外しには上枠と背面の受けを外す工程が必要です。通常のカセット交換ではこれらを残します。骨格と配線・トレーの経路の正本は `frame.py` と `frame_wiring.py` です。

全行程は `build/assembly.json` に記録します。面を外で組む工程は100mm外に置き、直線挿入は1mm以下の刻みです。
動作は2秒の五次曲線で始めと終わりの速度・加速度を0にします。電源断時の姿勢保持は保証しません。

## 正面カセットの構造と組立

蝶番はØ5mmの頭なし平底軸をØ5.4mmの軸穴へ通します。最後に取り付ける面板裏の両端壁が軸の抜け止めです。
大きな頭を軸穴へ通す構造は使いません。面板を外してから軸を抜きます。
ホーン受けは中央ハブと短腕を掴みます。18mm側と16mm側の長腕は外殻で囲いません。
16mm側の先に1.2 × 1.2mm角のストッパを設け、公称0.3mmの隙間を残します。180°逆に付けた18mm側はこのストッパに当たり、逆装着を拒みます。
v1の正本ホーンを使った局所診断では、ストッパ方向への±0.25mmの位置ずれを含め、正向きの共通体積は0〜0.0000132mm³、逆向きは1.714〜2.093mm³でした。これはv2統合検査の結果ではなく、実物適合も未確認です。
リンクの軸方向位置は `u=15.15〜18.15mm`、蓋の耳は `u=18.45〜21.45mm`。関節の径5mm、穴5.4mm、軸方向の隙間0.3mmは維持します。

以下は `faces/link_lid/assembly.py` と同じ順序です。全体の工程数・姿勢数・判定は `build/assembly.json` と `build/gate_report.json` に記録します。

1. 支持座を置きます。別の場所で蓋を組立角27.4775°に置き、蓋の耳へリンクのBピンを差します。
2. 支持座とは別の場所でSG92Rを90°に合わせます。付属ホーンと、中央ハブ・短腕を掴むホーン受けを取り付けます。
3. 蓋とリンクをまとめて横から動かし、クランクのAピンへリンクを接続します。
4. サーボ・ホーン・クランク・リンク・蓋を一式で支持座の開放溝へ下ろします。
5. 押さえ兼遮蔽壁を局所v=+50mmの位置からv=0へ滑らせます。頭なし蝶番ピンをu負側から軸穴へ通します。
6. 面板を最後に留め、裏の両端壁で蝶番ピンを保持します。90°の組立姿勢から閉指令へ戻します。

固定キーはカセット単体の組立から除きます。骨格の座面へカセットを差した後に取り付けます。

右面はサーボ90°・旗30°で組みます。付属ホーンの18mm腕を局所+vから外側へ14°傾けます。箱の外でホーン受けを被せ、入力歯車の136°側の角形キーを合わせて、固定軸をu正側から差します。このサーボ一式を支持座へ載せます。
旗室の底と保持足も箱の外で斜めの継ぎ目を合わせ、旗より先に一緒に入れます。その後は旗一式・ピン・左右の軸押さえ・面板の順です。旗一式を箱の外で組んでから噛合位置へ寄せます。分解は90°に戻して逆順です。部品ごとの経路は `faces/sector_flag/assembly.py`、接合部の遊びを合算した検査は `faces/sector_flag/check_retention_stack.py` に記録します。

## 面を交換・追加する手順

1. 電源を切り、対象面のキー2本を解除して40mm引き出し、コネクタを切り離します。側面の受けと他面はそのまま残します。
2. 新しい面は `faces/template/README.md` に従って独立したフォルダに実装します。共通規格と骨格は変更せず、単体で組立・占有・駆動を確認します。
3. `slots.json` の対象を変更し、`certify.py` を実行します。対応する `checks/<slot>` と表示データを再生成します。
4. 変わった部品のプレートと試片が更新されたことを `build/plate-summary.json` で確認し、全ケースとルートのゲートが合格してから印刷します。
5. 実物の試片で適合を確認してからカセットを組み、逆順で差し戻します。個体差は対象スロットの `calibration_deg` に保存します。

## ビルドと検査

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.1/blender.exe' --background --python-exit-code 1 --python models/mystery-box-sg92r-f1/model.py
py -3.11 models/mystery-box-sg92r-f1/verify_contract.py
py -3.11 models/mystery-box-sg92r-f1/plate.py --if-stale
py -3.11 tools/mechgate.py check mystery-box-sg92r-f1/checks/right
py -3.11 tools/mechgate.py check mystery-box-sg92r-f1/checks/top
py -3.11 tools/mechgate.py check mystery-box-sg92r-f1/checks/front
py -3.11 tools/mechgate.py check mystery-box-sg92r-f1
py -3.11 models/mystery-box-sg92r-f1/verify_envelopes.py
py -3.11 models/mystery-box-sg92r-f1/certify.py
py -3.11 models/mystery-box-sg92r-f1/certify.py --retention-only
node tools/catalog.js check
```

`certify.py` はslotsで選択した全ての面のPython/JSON、規格、スロット、共通コード、SG92R正本、ライブラリのSHAを比較します。
未選択の面の並行更新は現在の合成入力に含めません。`slots.json` 自体を追跡するため、面を選び直した場合は新しい面も対象になります。
選択面でも `build/`・`_local/`・`__pycache__/` 内の生成物は追跡しません。診断結果を更新しても入力の鮮度判定は変わりません。
変更があればBlenderで再合成してから各可動面のゲートとルートのゲートを実行します。いずれか非0なら全体も非0です。
ゲートの前に `plate.py --if-stale` でプレートも更新します。入力STL・展開後の印刷条件・スクリプトと、出力3mfのSHAが一致するときだけ既存スライスを再利用します。直接ゲートを実行するときは先にこのコマンドを実行します。
`--no-blender` は途中確認専用で、常に未完了として非0になります。
`--retention-only` は生成済み入力が最新のときだけ、中間・開端の抜け止め補助検査を実行します。再合成や全体ゲートは実行しません。

中間・開端は `kinematics.retention_poses()` で指定できます。正面は蓋30°と60°を使います。
全64部品を実姿勢へ焼き直したSTLを `build/retention_cases/<slot>/{mid,open}/` に置きます。既製部品も残します。
補助ケースは通常の運動検査と同じ静止部品の分類を使い、抜け止めの宣言をそれぞれ測ります。
計器は `tools/mechgate_lib/bl_job.py` をCLI実行し、各回の校正と全件の結果を確認します。
結果は `build/retention_report.json` に別記します。補助検査を全ゲートの合格とは扱わず、通常の `certify.py` は両方の成功を要求します。

`verify_contract.py` は識別子・変換・運動学・依存鮮度、`verify_envelopes.py` はSTL三角形と占有域を検査します。
包絡検査は実運動学を0.1°以下で標本化します。保存した運動契約も同じ刻みに剛体分割します。
各区間では、回転軸から形状までの実半径による円弧長と軸方向移動の上界を製造余裕0.25mmへ加えます。
保存した契約の補間範囲を覆う検査です。実運動学との偏差はサンプルで測りますが、非線形運動そのものの微分上界と連続証明は未完了です。
固定面板とキー頭の表面帯は規格の公称座面として扱い、公差込みの面板87.9mmと開口88mmの比較を別記します。
これらの補助検査の合格はmechgateの代わりになりません。最終結果は `build/gate_summary.md` を確認します。

## Studio の物理検証・組み立て

Studioの「物理検証」は正面の蓋を代表として再生します。上面の3画素と右面の旗は他面を閉じた条件で別に計算し、検査一覧に可動部質量・角度範囲・必要トルク・往復到達の結果を表示します。全体にはサーボが3台あります。タブの「SG92R 1台」は代表計算の対象です。同時駆動の検証ではありません。
v2-Aの最終統合検査は未測定です。ゲートが古い・未実施・不合格の状態では物理再生を無効にし、v1や局所検査の結果をv2の合格表示へ置き換えません。

`lattice_export.py` は各検査ケースの組立STLを四面体積分し、体積・重心・慣性を求めます。保存した運動行列をラジアンで微分し、等価慣性と重力トルクを計算します。グラフは各可動部の世界Zの重心高さです。密度はゲートと同じ中実PLAの1.24g/cm³で、付属ホーンも同密度と仮定します。再生のサーボ摩擦・制御幅・内部慣性・速度は既存計算器の仮定値です。拘束リンクの接触力、実機の保持力と追従を保証するものではありません。

合成時に表示用データを更新します。ゲートが古い・未実施・不合格の場合は操作を無効にします。`certify.py` は面別ゲートから組立の測定結果を写した後にルートゲートを実行し、最後に表示データを更新します。組立タブは全工程を扱い、姿勢数と判定は実際の `assembly.path` 検査から写します。

表示だけ更新する手順は次です。新しい形は先に合成してください。

```powershell
py -3.11 tools/mechgate.py check mystery-box-sg92r-f1/checks/front
py -3.11 tools/mechgate.py check mystery-box-sg92r-f1/checks/top
py -3.11 tools/mechgate.py check mystery-box-sg92r-f1/checks/right
py -3.11 models/mystery-box-sg92r-f1/lattice_export.py --prepare-assembly
py -3.11 tools/mechgate.py check mystery-box-sg92r-f1
py -3.11 models/mystery-box-sg92r-f1/lattice_export.py
py -3.11 tools/lattice_web.py mystery-box-sg92r-f1
node models/mystery-box-sg92r-f1/verify_lattice.mjs
```
