# スマホ板ロボット

Pixel 7a を体にして、左右の脚を STS3215 で 1 個ずつ動かす板状のロボットです。
中央の板の足は脚より 3mm 短く、脚を交互に振って進みます。

**実機では未確認です。** 形はゲート、歩きは MuJoCo、ファームはコンパイル、画面は模擬の機器で確かめただけです。

## 配線

```
スマホ USB-C ──データ線── Leonardo micro-B（Leonardo の 5V はスマホから）

Leonardo            74HC125
  5V ─────────────── VCC（14 番）、0.1µF で GND へ
  GND ────────────── GND（7 番）、未使用の入力（4,5,9,10,12,13 番）も GND へ
  D1 (TX1) ───────── 1A（2 番）
  D2 ─────────────── 1/OE（1 番）、10kΩ で 5V へ

  1Y（3 番）───────── サーボの DATA
  D0 (RX1) ──1kΩ──── サーボの DATA
  5V ──10kΩ───────── サーボの DATA

12V 電源の + ────── サーボの V（470µF を + と GND の間へ）
12V 電源の − ────── サーボの GND ── Leonardo の GND
```

- **12V を Leonardo へつながないでください。** 共通にするのは GND だけです
- サーボのつなぎ方は 2 個を数珠つなぎです。右のサーボは +Y 側、左のサーボは −Y 側のコネクタを使うと尻の間に収まります
- IC の基板はトレイの上の部屋（マイコンの上の仕切りより上）に置きます

## 電源

1. **最初は線です。** 背中の下の口から 12V の線を通します。追加の費用はかかりません
2. 歩くのを確かめてから電池にします。3S の LiPo 450〜500mAh と充電器は模型店で買います（秋月では見つけていません。目安は電池 ¥1,500、充電器 ¥2,500〜4,000）。上の部屋に入ります
   - 満充電は 12.6V です。SO-101 の一部のサーボは上限電圧が 12.0V の個体があったので、先に `mycobot-lab/scripts/so101_check_voltage_limits.py` で見てください
   - 転倒で電池を潰さないよう、歩く試験は机の上でなく床で行います

## 組み立て

1. トレイの背中を下にして置きます
2. 2 個のサーボを尻が向かい合う向きで前から落とします。線は尻の間から柱の前を通して下へ出します
3. Leonardo を 4 本の軸へ入れます。USB を下へ向けます
4. 仕切り板を棚へ落とします
5. 前枠を下から滑らせます。両側の舌が溝へ入り、上の爪が頭の受けへ入って止まります
6. USB の線を挿してから、スマホを下から差します
7. 足のふたを下から押し込みます。爪が窓に入るまで押します。外すときは窓から爪を押します
8. 脚を付ける前に下の「まっすぐを合わせる」を行います
9. 脚をホーンへ当て、付属のねじを 4 本ずつ穴の奥から締めます

## ファームを入れる

Arduino IDE で `firmware/slab_walker/` を開き、ボードを Arduino Leonardo にして書き込みます。

```bash
arduino-cli compile --fqbn arduino:avr:leonardo models/phone-slab-walker/firmware/slab_walker
```

ファームはサーボの番号と EEPROM を書き換えません。可動範囲の設定は電源を切ると元に戻ります。
脚を外して SO-101 へ戻すときは、ホーンを外した場合だけ腕の校正をやり直してください。

## 画面を開く

パソコンの Chrome で動かすのが最初です。

```bash
py -3.11 -m http.server 8765 --directory models/phone-slab-walker/app
```

`http://localhost:8765` を開き、「ロボットとつなぐ」を押します。

スマホでは一度だけパソコンから配ります。開発者向けの USB デバッグを有効にしてパソコンとつなぎ、次を打ちます。

```bash
adb reverse tcp:8765 tcp:8765
```

スマホの Chrome で `http://localhost:8765` を開くと手元に保存されます。そのあとパソコンの線を抜いて Leonardo へつなぎます。
スマホは WebUSB で話します。ここは実機で未確認です。つながらなければパソコンから動かして歩きだけ先に確かめられます。

## まっすぐを合わせる

1. サーボに電源を入れ、脚を付けずに画面の「調整」を開きます
2. 左右の「生の値」を見ます。676〜3419 の外なら、ホーンを外して付け直すか腕の校正を見直します
3. 脚をまっすぐ下へ向けて付けます
4. 「今の脚をまっすぐと覚える」を押します
5. 「両脚を前へ 10° 振る」を押します。足先が前へ動かない脚は「回る向きを逆にする」で直します

## 動かし方

- 「前へ」「後ろへ」「左へ」「右へ」「止める」を押します
- 歩いている間はスマホが 2 秒ごとに命令を送り直します。途絶えると 3 周期で止まります
- サーボが 65℃ を超えるか、過負荷などの異常を返したらファームが力を抜きます
- 「気分で言うことを聞かないことがある」を切ると必ず言うことを聞きます。止める操作は常に効きます

ファームへ直接送る命令は `firmware/slab_walker/slab_walker.ino` の先頭にあります。

## 歩きの計算

MuJoCo で 12 秒歩かせた結果です（`build/gait_report.json`）。比べるための値で、実機の距離は保証しません。
波形はファームの表（24 キー、1 周期 2.74 秒、1° 単位）をそのまま流しています。

| 条件 | 前へ | 向きのずれ | 一番傾いた角度 | 転倒 |
|---|---|---|---|---|
| 基準（隙間 3mm、194g、摩擦 0.5、ジャイロあり） | 96mm | -4° | 8.4° | なし |
| 隙間 1.5mm | 78mm | -5° | 9.8° | なし |
| 隙間 4.5mm | 107mm | -4° | 14.4° | なし |
| 174g、摩擦 0.35 | 103mm | -4° | 8.9° | なし |
| 230g、摩擦 0.8 | 87mm | -5° | 8.1° | なし |
| 脚のゼロ 左 +3° 右 -3° | 88mm | -1° | 14.6° | なし |
| 脚のゼロ 左 -3° 右 +3° | 99mm | -11° | 5.5° | なし |
| 右が 40ms 遅れる | 97mm | -5° | 8.2° | なし |
| ジャイロなし | 77mm | -15° | 10.2° | なし |
| 操舵 +6°（ジャイロなし） | 68mm | +18° | 9.4° | なし |
| 操舵 -6°（ジャイロなし） | 66mm | -69° | 7.6° | なし |

- 基準の条件を 40 秒続けると 172mm でした。最初の 12 秒より遅くなります
- 指令なしでは進まず転ばないことを校正に入れています
- 左右の曲がり方は同じではありません。実機で曲がりにくい側は `T` 命令の値で詰めます
- 脚を左右同時に振る歩き方は、中央の足が短い形では進みませんでした。左右交互を選んでいます
- 中央の足を持たない形（左右の足だけ）は、同じ探索で進む距離がずっと短くなりました
